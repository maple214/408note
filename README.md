| 项目 | 内容 |

## 三、建议的使用顺序

1. **一轮（现在 ~ 10 月）**：按章过王道 → 读对应笔记的「概念详解」→ 做「例题精练」→ 用「自测清单」打勾。
2. **二轮（10 ~ 11 月）**：按专题刷大题（`Cache`/流水线/`P`/`V`/页面置换/`CIDR`/滑动窗口），错题回填到该章的「常见坑」下面。
3. **三轮（12 月）**：真题套卷（严格 180 分钟）+ 考前只翻两份东西——各章的「易混对比表」和 [`跨科交叉点.md`](跨科交叉点.md) 第 2 节的术语黑名单。首套建议用 [真题/2013-408](真题/2013-408.md)（已附标准答案与错题表）。
