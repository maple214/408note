1. 一章一份，文件名 `01-` ~ `06-`，按「体系结构 → 物理层 → 数据链路层 → 网络层 → 传输层 → 应用层」自底向上。
2. 每份结构固定：**知识框架 → 概念详解 → 易混对比表 → 例题精练（3 道）→ 自测清单**。
3. VS Code 按 `Ctrl+Shift+V` 预览；公式写成**纯文本/行内代码**（如 `发送时延 = 数据长度 / 发送速率`），**故意不用 LaTeX**。
4. 计网只有 25 分、题量最少，但**记忆量最大**：把它当"协议清单"背，用对比表区分层次与协议，别陷进细节。

## 1. 计算机网络在 408 里的位置

| 项目 | 内容 |
| --- | --- |
| 分值 | **25 分**（四科中最少） |
| 题量 | 约 8 题：7~8 道单选（每题 2 分）+ 0~1 道综合应用题（约 9 分） |
| 科目性格 | 概念与协议细节多、计算量小；**性价比靠"背得准"**，不要在这里钻牛角尖 |

**五类高频计算/综合题**（占分不多但每年必有）：

1. 性能指标计算：发送时延、传播时延、时延带宽积、往返时间 `RTT`、有效数据率
2. 奈奎斯特定理与香农定理（码元速率、极限数据率、信噪比与 `dB` 换算）
3. 滑动窗口与信道利用率（`GBN`/`SR` 的窗口大小限制、利用率与吞吐量计算）
4. 子网划分与 `CIDR`（地址块划分、可用地址数、路由聚合、最长前缀匹配、转发表）
5. `TCP` 可靠传输与拥塞控制（序号与确认号、`cwnd` 变化曲线、发送窗口取最小值）

## 3. 复习策略：三层记忆法

1. **层**：每层解决什么问题、`PDU` 叫什么、有哪些典型设备（中继器/集线器 → 交换机 → 路由器）。
2. **协议**：每个协议属于哪层、`TCP` 还是 `UDP`、端口号、报文首部关键字段。
3. **流程**：从"输入网址到页面显示"这一条主线，把 `DNS` → `ARP` → `TCP` 三次握手 → `HTTP` 请求响应 → 四次挥手串起来（第 6 章例题里会走一遍）。
