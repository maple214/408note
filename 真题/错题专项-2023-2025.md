## 2. 专项包 · 第一批（5 个，覆盖 23 道错题）

### 专项 1 · 进程 / 线程 / 调度 / 上下文切换

> 对应错题：23-27、23-29、24-24、24-25、24-28、25-23 ｜ 回链：[操作系统/02-进程与线程](../操作系统/02-进程与线程.md)

**① 判定口诀**

1. **状态转换一句话**：*"缺东西 → 阻塞；能跑没 CPU → 就绪"*。
   - 等 I/O、等信号量 `P` 失败、申请内存失败 ⇒ **阻塞**
   - 时间片用完、被高优先级抢占、I/O 完成、事件到来 ⇒ **就绪**（注意"I/O 完成"是**阻塞→就绪**，不是→运行）
   - 只有被调度程序选中才 **就绪→运行**
2. **周转时间三步**：① 抄下"到达时间、服务时间"；② 按算法**画时间轴**（抢占式要逐时刻检查新到达者是否抢断）；③ 周转 = 完成 − 到达，带权周转 = 周转 ÷ 服务时间。
3. **上下文切换换什么**：
   - 进程 ↔ 进程：PC、通用寄存器、**页表基址寄存器**（`PDBR`/`CR3`）、内核栈指针
   - 同进程内线程 ↔ 线程：**不换页表基址**（共享地址空间），只换 PC/寄存器/栈指针
   - **中断向量表基址寄存器**（如 `IDTR`）任何时候都**不必**换（所有进程进内核都走同一套）
4. **线程共享三件套**：代码段、数据段（全局变量）、打开文件表 **共享**；**栈、寄存器、PC、线程 ID 私有**。
5. **进程终止的"必做/不必做"**：必做 = 回收主存、关闭打开文件、撤销 PCB；**不一定做** = 把页面写回磁盘（未被修改的页无需写回）。

**② 易混对比表**

| 事件 | 正确结果 | 常见错选 |
| --- | --- | --- |
| 执行 `P(wait)` 失败 | 运行 → **阻塞** | 选"就绪" |
| I/O 请求发出后 | 运行 → **阻塞** | 选"就绪" |
| I/O 完成 | 阻塞 → **就绪** | 选"运行" |
| 时间片到 / 被抢占 | 运行 → **就绪** | 选"阻塞" |
| 进程切换 vs 线程切换 | 前者要换**页表基址** | 以为两者一样 |
| 中断向量表基址 | **不必**随进程切换更新 | 以为必须更新 |
| 同进程线程 | 共享数据段、打开文件表 | 以为共享栈 |

**③ 同类变式**

**变式 1.** 下列事件中，会使进程从**运行态**变为**就绪态**的是（　）
A. 等待的 I/O 操作完成　B. 时间片用完　C. 执行 `P` 操作失败　D. 申请内存失败
> **答案 B**。A 是"阻塞→就绪"，C、D 是"运行→阻塞"。

**变式 2.** 三个进程 P1、P2、P3 同时（t=0）到达，服务时间分别为 3、5、2（单位 ms），采用**非抢占式短作业优先**，则平均周转时间是多少？
> **答案 17/3 ≈ 5.67ms**。执行序 P3(2)→P1(3)→P2(5)，完成时刻 2、5、10 ⇒ 周转 2、5、10 ⇒ 平均 17/3。

**变式 3.** 同一进程内的两个线程之间切换时，**不需要**更新的是（　）
A. 程序计数器　B. 通用寄存器　C. 页表基址寄存器　D. 栈指针
> **答案 C**。线程共享地址空间，页表不变——这正是"线程切换比进程切换开销小"的根本原因。

**变式 4.** 同一进程内的多个线程**不共享**的是（　）
A. 代码段　B. 全局变量　C. 打开文件表　D. 栈
> **答案 D**。每个线程有独立栈（否则函数调用会互相踩）。

**变式 5.** 进程终止时，下列操作**不属于**操作系统必做回收动作的是（　）
A. 释放进程占用的主存　B. 关闭进程打开的文件　C. 撤销进程的 PCB　D. 把进程所有页面立即写回磁盘
> **答案 D**。未修改的页面无需写回；"进程终止"不等于"把整个地址空间刷盘"。

**④ 回链**：[操作系统/02-进程与线程](../操作系统/02-进程与线程.md) → 自测清单里的"状态转换图能默画""周转时间能算"两条。

### 专项 2 · IP 地址 / 子网 / CIDR / NAT / DHCP

> 对应错题：23-38、23-39、23-40、25-36、25-37 ｜ 回链：[计算机网络/04-网络层](../计算机网络/04-网络层.md)

**① 判定口诀**

1. **子网三问**：① 掩码 → **块大小 = 2^(32−前缀)**；② 网络地址 = 地址按位与掩码（块大小的整数倍）；③ **可用地址 = 网络地址+1 ～ 广播地址−1**（要减掉网络地址和广播地址两个）。
   例：/20 ⇒ 块 4096，第三字节按 16 分组（0-15、16-31、32-47…）。
2. **最长前缀匹配**：多条都匹配时取**前缀最长**的，不是路由表里第一条。
3. **NAT / NAPT 改什么**：出方向改**源 IP + 源端口**（NAPT；纯 NAT 只改 IP），入方向改**目的 IP + 目的端口**；**IP 首部校验和与 TCP/UDP 校验和都必须重算**。私有地址永不出现在公网。
4. **DHCP 四步**：Discover（源 `0.0.0.0` → 目的 `255.255.255.255`）→ Offer → **Request（同样是广播，源 `0.0.0.0`）** → ACK。
5. **IPv6**：128 位、首部固定 **40B**、**取消首部校验和**、路由器不分片（源端 PMTU）、`Hop Limit` 对应 IPv4 的 `TTL`、过渡技术 = 双协议栈 / 隧道 / 翻译。

**② 易混对比表**

| 项目 | 正确口径 | 常见错解 |
| --- | --- | --- |
| /20 子网可用地址数 | 2¹² − 2 = 4094 | 忘减网络/广播地址 |
| 最小可用地址 | 网络地址 + 1 | 直接用网络地址 |
| NAT 转发表 | 私有 IP:端口 ↔ 公网 IP:端口 | 以为只换 IP |
| 校验和 | IP 与 TCP/UDP **都**要重算 | 只改 IP 不动 TCP |
| DHCP Request | 广播（源 0.0.0.0） | 以为是单播给服务器 |
| IPv6 首部 | 无校验和、无分片字段 | 照搬 IPv4 结构 |

**③ 同类变式**

**变式 1.** 某主机地址 172.16.35.9，掩码 255.255.240.0。写出其网络地址、广播地址与可用地址范围。
> **答案**：网络地址 **172.16.32.0**、广播地址 **172.16.47.255**、可用范围 **172.16.32.1 ~ 172.16.47.254**（共 4094 个）。第三字节掩码高位 4 位有效 ⇒ 每 16 一段。

**变式 2.** 内网主机 192.168.1.5:3000 访问 202.1.1.1:80，`NAPT` 路由器公网地址 203.1.1.1（分配端口 4000）。转换后的（源 IP, 源端口）与（目的 IP, 目的端口）分别是？哪些字段需要重算校验和？
> **答案**：源变成 **203.1.1.1:4000**，目的保持 **202.1.1.1:80**；**IP 首部校验和与 TCP 校验和都要重算**。

**变式 3.** 主机首次用 DHCP 获取地址时，`DHCPREQUEST` 报文的源 IP 与目的 IP 分别是（　）
A. 0.0.0.0 与 255.255.255.255　B. 本机地址与服务器地址　C. 0.0.0.0 与服务器地址　D. 本机地址与 255.255.255.255
> **答案 A**。Request 也是广播——此时主机还没拿到地址，也不知道哪个服务器会确认。

**变式 4.** 路由表：10.0.0.0/8→R1、10.1.0.0/16→R2、10.1.2.0/24→R3、0.0.0.0/0→R4。目的地址 10.1.2.7 从哪条转发？
> **答案 R3**（/24 前缀最长）。

**变式 5.** 下列关于 `IPv6` 的叙述中，**错误**的是（　）
A. 地址长度 128 位　B. 首部中包含校验和字段　C. 用 `Hop Limit` 代替 `TTL`　D. 可通过隧道技术实现与 IPv4 共存
> **答案 B**。IPv6 取消了首部校验和（把差错检测交给上下层，减少路由器开销）。

### 专项 3 · 排序算法的性质与过程反推

> 对应错题：23-10、24-8、24-11、25-10 ｜ 回链：[数据结构/08-排序](../数据结构/08-排序.md)

**① 判定口诀**

1. **稳定性口诀**："**插冒归基**"稳定（插入、冒泡、归并、基数）；其余（**选择、希尔、快排、堆**）不稳定。
2. **过程反推——看"谁就位/哪里有序"**：
   - **快速排序**：每趟至少一个元素**落到最终位置**，且它**左边全 ≤ 它、右边全 ≥ 它**（"块间有序 + 一个就位"）
   - **堆排序（大根堆）**：序列**尾部逐渐有序**，前面的部分是堆
   - **直接插入**：**前缀有序**（前 i 个已排好）
   - **冒泡**：**后缀有序**（末尾 i 个已就位）
   - **希尔**：整体不有序，但**每个增量分组内有序**
   - **归并**：出现长度 2、4、8… 的**有序块**，块与块之间无序
3. **移动/比较次数**：
   - 元素移动次数**与初始序列无关**的是 **基数排序**（分配+收集，不比较）
   - 简单选择排序移动次数最少（≤ n−1 次），但**比较次数**恒为 n(n−1)/2
   - 比较次数与初始序列无关的是**简单选择**与**归并**
4. **败者树**：每个内部结点存**败者**的段号，**冠军（最终胜者）另存在根之上**。

**② 易混对比表**

| 算法 | 一趟后的特征 | 稳定 | 与初始序列无关的量 |
| --- | --- | --- | --- |
| 直接插入 | 前缀有序 | 是 | — |
| 冒泡 | 后缀有序（最大值到位） | 是 | — |
| 简单选择 | 前缀就位（最小值到位） | 否 | 比较次数 n(n−1)/2 |
| 快速排序 | **轴枢就位**，左右分块 | 否 | — |
| 堆排序 | 尾部有序（堆顶逐次到末尾） | 否 | — |
| 希尔排序 | 组内有序、整体无序 | 否 | — |
| 归并排序 | 长度 2^k 的有序块 | 是 | 比较次数（近似） |
| 基数排序 | 按位稳定收集 | 是 | **移动次数** |

**③ 同类变式**

**变式 1.** 对序列 {49,38,65,97,76,13,27,49} 采用快速排序（取第一个元素为轴枢）进行**一趟划分**，结果序列是什么？这一趟保证了几号元素就位？
> **答案**：{**27,38,13,49,76,97,65,49**}；轴枢 49 落到**第 4 个位置**（下标 3），它左边全 ≤49、右边全 ≥49。识别技巧：看"有没有一个元素左边都比它小、右边都比它大"。

**变式 2.** 下列排序算法中，**一趟结束后一定能确定至少一个元素最终位置**的是（　）
A. 直接插入排序　B. 冒泡排序　C. 快速排序　D. 堆排序
> **答案 B、C、D**。冒泡把最值送到端点、快排让轴枢就位、堆排序把堆顶送到末尾；**直接插入排序每一趟都不保证任何元素在最终位置**。

**变式 3.** 判断"简单选择排序不稳定"的一个具体反例（用三个元素说明）。
> **答案**：对 {2, 2', 1} 做简单选择排序——第一趟选最小值 1 与首元素 2 交换 ⇒ {1, 2', 2}，原来的 2' 跑到了 2 前面 ⇒ 不稳定。

**变式 4.** 下列排序方法中，元素**移动次数与初始排列次序无关**的是（　）
A. 直接插入排序　B. 起泡排序　C. 快速排序　D. 基数排序
> **答案 D**。基数排序靠分配与收集，不做元素比较，移动次数只与位数和元素个数有关。

**变式 5.** k 路归并中的败者树，其每个内部结点保存的是（　）
A. 胜者的归并段号　B. 败者的归并段号　C. 该段的最小关键字　D. 该段的最大关键字
> **答案 B**。结点里记"输家"，一路比上去，**冠军**在根上方单独保存——所以叫"败者树"。

**④ 回链**：[数据结构/08-排序](../数据结构/08-排序.md) → "各排序算法性质对比表" + 稳定性口诀。

### 专项 4 · 存储系统：Cache / TLB / MMU / 虚存

> 对应错题：23-15、24-16、24-17、24-18 ｜ 回链：[计组/03-存储系统](../计组/03-存储系统.md)

**① 判定口诀**

1. **算地址位数的固定顺序**：**先块内偏移，再索引（组号），最后标记**。
   - 块内偏移位 = log2(块大小)
   - 直接映射：索引位 = log2(行数)；组相联：组数 = 行数 ÷ 路数，索引位 = log2(组数)
   - **标记位 = 地址位数 − 索引位 − 偏移位**
2. **`TLB` 的组相联**：把**虚页号**再切一刀——**组号 = 虚页号低 log2(组数) 位**，**标记 = 虚页号高位**（标记位数 = 虚页号位数 − 组号位数）。别把它和"物理地址算 Cache"混起来。
3. **访存次数判定**：
   - `TLB` **命中 ⇒ 不访存页表**；`TLB` 缺失才去遍历页表（多级页表要多次访存）
   - `Cache` 命中 ⇒ 不访主存
   - **直写（Write Through）**：每次写都要写主存 ⇒ 访存次数多；**回写（Write Back）**：需要**修改位（脏位）**，Cache 每行多 1 位
4. **谁触发异常**：**缺页 ⇒ 异常**（OS 处理）；**TLB 缺失、Cache 缺失 ⇒ 不是异常**（硬件/固件处理）；保护位违规 ⇒ 越权异常。
5. **主存-CPU 连接**：先由"容量比"定片数，再定片内/片间地址划分；**`ROM` 在高地址区**时从后往前排地址。

**② 易混对比表**

| 项目 | 正确口径 | 常见错解 |
| --- | --- | --- |
| 标记位 | 地址位数 − 索引 − 偏移 | 忘记减偏移位 |
| TLB 标记 | 虚页号高位（虚页号 − 组号位数） | 用物理地址算 |
| TLB 命中 | **不**访存页表 | 以为仍要访存一次 |
| 缺页 vs TLB 缺失 | 前者是异常，后者不是 | 混为一谈 |
| 回写方式 | 每行要加 1 位修改位 | 只算"有效位" |
| Cache 总容量 | 数据 + 标记 + 有效位（+修改位） | 只算数据位 |

**③ 同类变式**

**变式 1.** 主存地址 32 位、按字节编址，Cache 数据区 32KB、块大小 64B、**4 路组相联**。求块内偏移位数、组索引位数与标记位数。
> **答案**：块数 = 32KB/64B = 512，组数 = 512/4 = **128** ⇒ 偏移 **6 位**、索引 **7 位**、标记 = 32 − 7 − 6 = **19 位**。

**变式 2.** 虚页号 20 位，`TLB` 采用 **8 组 4 路**组相联，则 TLB 的组号与标记各是多少位？
> **答案**：组号 = log2 8 = **3 位**，标记 = 20 − 3 = **17 位**。

**变式 3.** 承变式 1、2：该 Cache 采用**回写**方式，则其总容量（按位）是多少？
> **答案**：每行 = 数据 64×8 + 标记 19 + 有效位 1 + 修改位 1 = **533 位**；总 = 533 × 512 = **272896 位 ≈ 266.5 Kb（≈ 32.75 KB）**。

**变式 4.** 下列事件中，**会触发异常**（需要操作系统介入处理）的是（　）
A. `TLB` 缺失　B. `Cache` 缺失　C. 缺页　D. 分支预测失败
> **答案 C**。缺页由 OS 的缺页处理程序完成调页；A/B/D 都可以由硬件处理。

**变式 5.** 若某次取数时 `TLB` 命中且 `Cache` 也命中，则至少需要访问主存几次？
> **答案 0 次**。TLB 命中免去了页表访存，Cache 命中的数据直接从 Cache 取。

**④ 回链**：[计组/03-存储系统](../计组/03-存储系统.md) → "Cache 映射与地址划分""TLB 与页表"两节。

### 专项 5 · MAC / 以太网（退避 / VLAN / ARP / NAV）

> 对应错题：23-36、24-35、24-36、25-35 ｜ 回链：[计算机网络/03-数据链路层](../计算机网络/03-数据链路层.md)

**① 判定口诀**

1. **二进制指数退避**：第 i 次冲突后从 {0,1,…,2^k−1} 中随机取一个时隙，其中 **k = min(i, 10)**；**最长等待 = (2^k − 1) × 争用期(2τ)**。
   - 10Mbps 以太网的**争用期 = 51.2µs**（512 bit 时间，即 64B 的最小帧长）
   - **连续 11 次冲突 ⇒ k 封顶 10 ⇒ 上限 1023 个时隙**（23-36 与 25-35 考的就是这个"封顶"）
2. **VLAN**：用来**划分广播域**；同一交换机上**不同 VLAN 之间通信必须经路由器或三层交换机**；802.1Q 标签插在**源 MAC 之后**。
3. **ARP**：请求用**广播帧**（目的 MAC = `ff-ff-ff-ff-ff-ff`）、应答用单播；表项是 **IP → MAC**；**跨网段时解析的是默认网关的 MAC**（数据帧的目的 MAC 永远是下一跳的 MAC）。
4. **`NAV`（`CSMA/CA`）**：站点收到 `CTS` 后按其中时长设置 `NAV` 并静默。总时长按图算：**SIFS + 数据帧 + SIFS + ACK**（2024-36 的官方口径即 28+296+28+2 = **354µs**）。

**② 易混对比表**

| 项目 | 正确口径 | 常见错解 |
| --- | --- | --- |
| 退避窗口上限 | k = min(i,10)，11 次后封顶 1023 时隙 | 以为一直翻倍 |
| 争用期 | 10Mbps 以太网 = 51.2µs | 记成 5.12µs |
| ARP 请求的目的 MAC | 广播 ff-ff-ff-ff-ff-ff | 写成目的主机 MAC |
| 跨网段数据帧目的 MAC | **默认网关**的 MAC | 写成目的主机 MAC |
| VLAN 隔离的域 | 广播域 | 说成"冲突域" |
| 不同 VLAN 互通 | 必须经三层设备 | 以为交换机自动通 |

**③ 同类变式**

**变式 1.** 10Mbps 以太网上某站点连续发生 5 次冲突后，第 6 次冲突时的退避窗口最大是多少个时隙？最长等待时间是多少？
> **答案**：k = min(6,10) = 6 ⇒ 窗口 = 2⁶ = **64 个时隙**，最大等待 = 63 × 51.2µs = **3225.6µs ≈ 3.23ms**。

**变式 2.** 同一台交换机上属于不同 VLAN 的两台主机要通信，必须经过（　）
A. 该交换机　B. 路由器或三层交换机　C. 集线器　D. 网桥
> **答案 B**。VLAN 隔离的是广播域，跨 VLAN 属于三层转发。

**变式 3.** 主机 A 与主机 B 同网段，A 的 ARP 表为空。A 发往 B 的**第一个以太网帧**的目的 MAC 是（　）
A. B 的 MAC　B. ff-ff-ff-ff-ff-ff　C. 网关 MAC　D. 00-00-00-00-00-00
> **答案 B**。ARP 请求必须广播；B 的应答才是单播。

**变式 4.** 主机 A 访问 Internet 时，其 IP 分组被封装的以太网帧的**目的 MAC** 是（　）
A. 目的服务器的 MAC　B. 默认网关的 MAC　C. 广播地址　D. 本机 MAC
> **答案 B**。跨网段转发靠网关，目的 MAC 始终是"下一跳"的 MAC。

**变式 5.** 在 `CSMA/CA` 中，某站点收到 `CTS` 后设置 `NAV`。若数据帧传输时间 296µs、ACK 传输时间 2µs、`SIFS` = 28µs，则 `NAV` 应设为多少？
> **答案 354µs**（28 + 296 + 28 + 2）。这正是 2024 年第 36 题的官方口径——**记住"两个 SIFS 夹一个数据帧，再加 ACK"**。

**④ 回链**：[计算机网络/03-数据链路层](../计算机网络/03-数据链路层.md) → "退避算法""VLAN""ARP 与 MAC 帧"三节。

### 专项 6 · 内存管理（页框分配 / 置换 / 映射文件）

> 对应错题：23-25、23-28、23-30、25-30 ｜ 回链：[操作系统/03-内存管理](../操作系统/03-内存管理.md)

**① 判定口诀**

1. **位图开销**：页框数 = 内存容量 ÷ 页大小 ⇒ **位图位数 = 页框数** ⇒ 字节数 = 位数 ÷ 8 ⇒ **位图占的页框数 = ⌈字节数 ÷ 页大小⌉**。
2. **虚拟地址空间大小只由"地址位数"决定**，与页大小、页框数、物理内存、交换区大小**全都无关**（后几者只影响"能同时容纳多少页"）。
3. **共享页**：物理**页框号相同**，各进程的**虚拟页号可以不同**——"同一块数据、两套虚拟编号"。
4. **置换算法口径**：
   - `OPT` 最优（理论）；`FIFO` 会出现 `Belady` 异常；`LRU`/`OPT` 是栈式算法不会；
   - **固定分配 + 全局置换 不能组合**（固定分配要求页框数不变，全局置换却要抢别人的）；
   - 缺页次数模拟：先列页框，再逐次比较；**命中也要更新 LRU 的"最近使用"顺序**（最容易错的一步）。
5. **内存映射文件**：把文件页映射进虚拟地址空间 ⇒ ①可用于**进程间通信**（映射同一文件）、②建立**文件页↔虚拟页**映射、③访问像访问内存，缺页时从磁盘对应块调入。

**② 易混对比表**

| 项目 | 正确口径 | 常见错解 |
| --- | --- | --- |
| 虚拟地址空间 | 由**地址位数**决定 | 以为由物理内存/交换区决定 |
| 位图占的页框数 | ⌈页框数/8/页大小⌉ | 直接把位数当字节数 |
| 共享内存 | 页框号同、页号可不同 | 以为页号也必须相同 |
| 固定分配 × 全局置换 | 不能组合 | 以为可以 |
| LRU 命中时 | 要更新该页为"最近使用" | 以为命中不用动顺序 |

**③ 同类变式**

**变式 1.** 某系统主存 4GB、页大小 4KB，用位图管理空闲页框。求位图占多少字节、需占多少个页框。
> **答案**：页框数 = 4GB/4KB = 2²⁰ = 1048576 ⇒ 位图 = 2²⁰ bit = **128KB** ⇒ 占 **32 个页框**（128KB/4KB）。

**变式 2.** 决定一个进程虚拟地址空间大小的因素是（　）
A. 物理内存容量　B. 机器地址位数　C. 页面大小　D. 交换区容量
> **答案 B**。虚拟地址空间 = 2^(地址位数)，其余三项只影响"实际能装下多少"。

**变式 3.** 两个进程共享同一物理页面，则（　）
A. 页号相同、页框号相同　B. 页号不同、页框号相同　C. 页号相同、页框号不同　D. 都不同
> **答案 B**。页框是物理的、必然同一个；虚拟页号由各进程自己的页表映射，可以不同。

**变式 4.** 页框数 = 3，页号序列 1,2,3,4,1,2,5,1,2,3,4,5。分别用 `FIFO` 与 4 个页框的 `FIFO` 模拟，说明 `Belady` 异常。
> **答案**：3 个页框时缺页 **9** 次；4 个页框时缺页 **10** 次（序列末尾 `5` 在 4 框时被淘汰后又要访问）⇒ **页框变多、缺页反而变多**，即 `Belady` 异常，只有 `FIFO` 会出现。

**变式 5.** 关于内存映射文件，下列叙述正确的是（　）
Ⅰ. 可用于进程间通信　Ⅱ. 建立文件页与虚拟页的映射　Ⅲ. 访问时按内存方式访问，缺页时调页
A. 仅Ⅰ、Ⅱ　B. 仅Ⅱ、Ⅲ　C. Ⅰ、Ⅱ、Ⅲ　D. 仅Ⅰ、Ⅲ
> **答案 C**。三条都是内存映射文件的基本性质。

**④ 回链**：[操作系统/03-内存管理](../操作系统/03-内存管理.md) → "页框分配""置换算法""内存映射"三节。

### 专项 7 · 查找与散列 + `KMP`

> 对应错题：23-9、24-5、24-6、25-9 ｜ 回链：[数据结构/07-查找](../数据结构/07-查找.md)、[数据结构/04-串](../数据结构/04-串.md)

**① 判定口诀**

1. **折半查找**：只适用于**顺序存储 + 有序**（链表不行）；判定树高度 = **⌈log₂(n+1)⌉**，这也是**查找失败的最多比较次数**（600 个元素 ⇒ ⌈log₂601⌉ = **10**）。
2. **散列的平均查找长度**：
   - 成功 `ASL` = Σ(每个元素的比较次数) ÷ 元素个数
   - **失败 `ASL` = Σ(每个散列地址开始的探测次数) ÷ 散列地址个数**（探测到"空单元"才算一次失败查找结束，**空单元那次也算 1 次**）
   - **线性探查会产生堆积**（一次冲突连带影响后面），二次探查/再散列能缓解；**装填因子越大，冲突概率越大**
3. **`KMP` 最大右滑**：`next[j]` = 模式串 `t[0..j−1]` 的**最长相等前后缀长度**；失配在 `t[j]` 时，模式串右滑 **`j − next[j]`** 位，**主串指针 i 不动**；"最大右滑"= 对所有 j 取 `j − next[j]` 的最大值。
   ⚠ 先确认题目用的是哪种 `next`（从 0 起 / 从 −1 起），两者差 1。

**② 易混对比表**

| 项目 | 正确口径 | 常见错解 |
| --- | --- | --- |
| 折半查找适用 | 顺序存储 + 有序 | 以为链表也能折半 |
| 失败比较次数 | ⌈log₂(n+1)⌉ | 记成 log₂n |
| 失败 ASL 的"探测到空" | 空单元那一次**要计入** | 少算一次 |
| 堆积（聚集） | 主要由**线性探查**引起 | 归因于装填因子 |
| KMP 失配后 | 主串指针**不回溯** | 以为 i 要回退 |

**③ 同类变式**

**变式 1.** 有序表含 600 个元素，折半查找失败时最多需要比较多少次？
> **答案 10 次**（判定树高度 ⌈log₂(600+1)⌉ = 10）。

**变式 2.** 模式串 `t = "abaabc"`，若采用"`next[j]` = `t[0..j−1]` 最长相等前后缀长度"的定义，求其 `next` 数组与失配时的最大右滑距离。
> **答案**：`next = [0, 0, 0, 1, 1, 2]`；右滑 `j − next[j]` 依次为 1、2、2、3、3 ⇒ **最大右滑 = 3**（在 j=4 或 j=5 失配时）。

**变式 3.** 散列表长 11，`H(k) = k mod 11`，用**线性探查**依次插入 {22,41,53,46,30,13,1,67}。求查找**失败**时的平均查找长度。
> **答案**：表内分布为 0:22、1:1、2:46、3:13、4:67、8:41、9:53、10:30，空位 5、6、7。各散列地址的失败探测次数：0→6、1→5、2→4、3→3、4→2、5→1、6→1、7→1、8→9、9→8、10→7，合计 47 ⇒ **ASL失败 = 47/11 ≈ 4.27**。

**变式 4.** 下列关于散列的说法中，正确的是（　）
A. 装填因子越小，冲突越多　B. 二次探查一定不会产生堆积　C. 线性探查会产生堆积，且堆积会拉长查找失败的平均查找长度　D. 散列查找的比较次数与装填因子无关
> **答案 C**。A 说反；B 只能说"缓解"（且二次探查可能找不到空位）；D 说反。

**变式 5.** 对 `n` 个元素的有序顺序表做折半查找，其判定树的高度是（　）
A. ⌊log₂n⌋　B. ⌈log₂(n+1)⌉　C. n/2　D. log₂n − 1
> **答案 B**。

### 专项 8 · 树与 `B 树` + 图 + 复杂度

> 对应错题：23-7、25-8、23-6、25-6、25-1 ｜ 回链：[数据结构/07-查找](../数据结构/07-查找.md)、[数据结构/06-图](../数据结构/06-图.md)、[数据结构/01-绪论](../数据结构/01-绪论.md)

**① 判定口诀**

1. **`B 树`定义**：m 阶 B 树非根结点关键字数 ∈ [⌈m/2⌉−1, m−1]，孩子数 = 关键字数 + 1；根关键字数 ∈ [1, m−1]；**所有失败结点在同一层**（"绝对平衡"）。
2. **`B 树`计数题**：按"根放几个关键字 ⇒ 剩下的关键字如何在各子树间分配"**枚举**，枚举时每个子树的规模必须满足上面的区间约束。
3. **图的性质判定**：
   - 顶点的**度** = 关联的边数（有向图分入度/出度，Σ入度 = Σ出度 = 边数）；
   - **无向连通图求"边权为 1"的最短路 ⇒ 直接用 `BFS`**（`Prim`/`Kruskal` 求的是生成树，`Dijkstra` 适合带权）；
   - **拓扑序列唯一** ⟺ 每步只有**一个**入度为 0 的顶点（否则有多种选择）；
   - 所有顶点度 ≥ 2 ⇒ 必有回路。
4. **复杂度只看"耦合关系"**：
   - `for(i=1; i*i<=n; i++) for(j=1; j<=i; j++)` ⇒ Σi ≈ n/2 ⇒ **O(n)**
   - `for(k=1; k<=n; k*=2)` ⇒ **O(log n)**（乘性递增）
   - 嵌套循环**先写总次数表达式再化简**，别凭感觉相乘。

**② 易混对比表**

| 场景 | 正确算法/结论 | 常见错解 |
| --- | --- | --- |
| 边权为 1 求最短路 | `BFS` | 用 `Prim`/`Kruskal`/`Dijkstra` |
| 求最小生成树 | `Prim`/`Kruskal` | 以为求最短路 |
| 拓扑序列唯一 | 每步只有一个入度 0 顶点 | 以为"入度为 0 即唯一" |
| i*i<=n 的双重循环 | O(n) | 直接判 O(n²) |
| `B 树`根结点 | 关键字数可少到 1 | 按非根结点的下界算 |

**③ 同类变式**

**变式 1.** 一棵高度为 3 的 5 阶 `B 树`，最少含多少个关键字？
> **答案 17 个**。根 1 个关键字、2 个孩子；第 2 层每个结点最少 2 个关键字、3 个孩子 ⇒ 第 3 层 6 个结点，每个最少 2 个关键字 ⇒ 1 + 2×2 + 6×2 = 17。

**变式 2.** 用 7 个不同关键字构造 4 阶 `B 树`，可能的形态有几种（只要求写出**分类思路**）？
> **答案思路**：4 阶树根的取值范围 1~3 个关键字。根 1 个关键字 ⇒ 剩 6 个分给 2 个子树，每子树 1~3 个关键字，可行分配 (3,3)；根 2 个关键字 ⇒ 3 个子树分 5 个关键字，需满足每子树 1~3：如 (1,2,2)、(2,1,2)…；根 3 个关键字 ⇒ 4 个子树分 4 个关键字 ⇒ (1,1,1,1)。逐类计数即得，**关键是"先定根、再按区间约束分配"**。

**变式 3.** 边权均为 1 的无向连通图，求顶点 v 到其余各顶点的最短路径长度，应使用（　）
A. `Prim` 算法　B. `Kruskal` 算法　C. `BFS`　D. 拓扑排序
> **答案 C**。边权相等时 BFS 的层次就是最短距离。

**变式 4.** 下列程序段的时间复杂度是（　）
```
for (i = 1; i * i <= n; i++)
    for (j = 1; j <= i; j++)
        x++;
```
A. O(log n)　B. O(n)　C. O(n log n)　D. O(n²)
> **答案 B**。外层 i ≤ √n，内层执行 i 次，总次数 = Σ_{i=1}^{√n} i ≈ n/2。

**变式 5.** 一个有向图的拓扑序列唯一，则该图（　）
A. 一定是一棵树　B. 每步只有一个入度为 0 的顶点　C. 一定不存在环　D. 每个顶点入度都为 1
> **答案 B**（C 也成立但"唯一性"的直接判据是 B；"每个顶点入度为 1"是错的，起点入度为 0）。

**④ 回链**：[数据结构/06-图](../数据结构/06-图.md)、[数据结构/07-查找](../数据结构/07-查找.md)、[数据结构/01-绪论](../数据结构/01-绪论.md)。

### 专项 9 · TCP / UDP / 应用层

> 对应错题：24-38、24-39、24-40、25-38、25-40 ｜ 回链：[计算机网络/05-传输层](../计算机网络/05-传输层.md)、[06-应用层](../计算机网络/06-应用层.md)

**① 判定口诀**

1. **TCP 时间账（按题目口径逐项加）**：建立连接 **1 RTT**（三次握手的前两次占 1 RTT）｜每次请求-响应 **1 RTT**（非流水线）｜释放连接 **1 RTT**（前两次挥手）+ **主动方等 `2MSL`**（若题目把 `2MSL` 计入，注意 `MSL` 常取给定值）。算之前先把这四项列出来，别凭印象。
2. **`2MSL` 的目的一句话**："确保最后 ACK 能到达 + 让本次连接的旧报文在网络中消失"。
3. **拥塞控制**：`cwnd` 初值 1 MSS；慢开始**每个 RTT 翻倍**（1→2→4→8…）到 `ssthresh` 后转拥塞避免（每 RTT +1）；**发送窗口 = min(cwnd, rwnd)**；若"已发送未确认 X 字节"，则**还能发 = 发送窗口 − X**。
4. **`UDP` 校验和**：计算时**校验和字段本身置 0**，加上**伪首部**（源/目的 IP、协议、UDP 长度）一起按 16 位反码求和；**IPv4 下可为 0（表示未计算）**，TCP 的校验和是必需的。
5. **应用层口径**：`HTTP/1.1` **默认持久连接**（`Connection: close` 显式关闭）；**非流水线 ⇒ 每个对象各 1 RTT**，流水线 ⇒ 一批请求 1 RTT；**`POP3` 只收不发、可一条 TCP 连接取多封邮件**；`SMTP` 只发不收。

**② 易混对比表**

| 项目 | 正确口径 | 常见错解 |
| --- | --- | --- |
| 建连耗时 | 1 RTT | 记成 2 RTT（把第三次握手另算） |
| 主动关闭方 | 发完最后 ACK 后等 `2MSL` | 以为立即关闭 |
| 慢开始增长 | 每 RTT 翻倍 | 每 RTT 加 1 |
| 还能发多少 | 窗口 − 已发未确认 | 直接用窗口 |
| UDP 校验和 = 0 | 表示未计算（IPv4 允许） | 以为校验和错误 |
| POP3 | 收邮件、可一次取多封 | 以为它也能发邮件 |

**③ 同类变式**

**变式 1.** 主机 A 分别用 `UDP` 和 `TCP` 向 B 发送一个 1000B 的数据块（忽略处理与传输时延），若 RTT = 8ms，两者各需约多少时间？
> **答案**：`UDP` **8ms**（1 个 RTT）；`TCP` **16ms**（握手 1 RTT + 数据 1 RTT）。

**变式 2.** 某 TCP 连接 `ssthresh = 16 MSS`、`rwnd = 32 MSS`，`cwnd` 从 1 MSS 开始慢开始，未发生超时。经过 3 个 RTT 后 `cwnd` 是多少？第 5 个 RTT 后呢？
> **答案**：cwnd 依次 1→2→4→8→16→17 ⇒ 3 个 RTT 后 **8 MSS**；第 5 个 RTT 后达到 16，触发拥塞避免，之后每 RTT +1 ⇒ 第 5 个 RTT 后为 **17 MSS**（发送窗口取 min(17,32) = 17）。

**变式 3.** 某时刻 `cwnd = 3000B`、`MSS = 1000B`，且已发送但未收到确认的数据共 1000B，则还能发送多少段？
> **答案 2 段**（3000 − 1000 = 2000B）。

**变式 4.** 下列关于 `UDP` 校验和的叙述中，正确的是（　）
A. `UDP` 校验和字段为 0 表示校验出错　B. IPv4 下 `UDP` 可以不计算校验和（置 0）　C. `UDP` 校验和只校验数据部分　D. `UDP` 校验和是必需的
> **答案 B**。0 表示"未计算"；校验范围含伪首部 + 首部 + 数据；IPv6 下才强制计算。

**变式 5.** 下列关于 `POP3` 的叙述中，正确的是（　）
A. 支持从用户代理向邮件服务器发送邮件　B. 支持一条 TCP 连接中收取多封邮件　C. 使用不可靠的传输层服务　D. 只能读取邮件而不能删除邮件
> **答案 B**。A 是 SMTP 的职责；C 错（POP3 基于 TCP）；D 错（POP3 可取走并删除）。

**④ 回链**：[计算机网络/05-传输层](../计算机网络/05-传输层.md)（拥塞控制/连接管理）、[06-应用层](../计算机网络/06-应用层.md)（HTTP/邮件协议）。

### 专项 10 · 总线 + 流水线

> 对应错题：24-20、25-20、23-19 ｜ 回链：[计组/06-总线](../计组/06-总线.md)、[计组/05-中央处理器](../计组/05-中央处理器.md)

**① 判定口诀**

1. **总线带宽 = 每次传送字节数 × 每秒传送次数**。
   - 地址/数据线 32 根 ⇒ 每次 4B；
   - **每个时钟周期传两次（双边沿 / DDR）⇒ 次数 ×2**；
   - `MT/s` 是**每秒传输次数**，不是时钟频率（DDR-3200 ⇒ 时钟 1600MHz、3200 MT/s）。
2. **突发传送（burst）**：一次给首地址，连续传多个数据 ⇒ **总线事务时间 = 1 个地址周期 + n 个数据周期**；非突发则每个数据都要地址周期（时间明显变长）。
3. **流水线**：k 段流水线执行 n 条指令 ⇒ 周期数 = **k + n − 1**；吞吐率 = n ÷ 总时间；加速比 = 串行时间 ÷ 流水时间。
4. **冒险三分**：结构冒险（资源冲突）、**数据冒险（RAW）——可用数据旁路/转发缓解**、**控制冒险（分支）——旁路无效，需延迟槽/预测/冲刷**。

**② 易混对比表**

| 项目 | 正确口径 | 常见错解 |
| --- | --- | --- |
| DDR 双边沿 | 每秒传送次数 ×2 | 忘记乘 2 |
| `MT/s` | 传输次数/秒 | 当成时钟频率 |
| 突发传送 | 1 个地址周期 + n 个数据周期 | 每个数据都算地址周期 |
| 流水线周期数 | k + n − 1 | n×k |
| 数据旁路 | 可消除 RAW 数据冒险 | 以为也能消除控制冒险 |

**③ 同类变式**

**变式 1.** 某同步总线数据线 4B 宽，时钟频率 100MHz，每个时钟周期传送 2 次数据（双边沿），求总线带宽。
> **答案 800MB/s**（4B × 100M × 2）。

**变式 2.** 某内存标称 `DDR-3200`，数据线 64 位，求其带宽。
> **答案 25.6 GB/s**（3200 MT/s × 8B）。

**变式 3.** 5 段流水线、无阻塞地执行 100 条指令，共需多少时钟周期？吞吐率是多少？
> **答案 104 个周期**（5 + 100 − 1）；吞吐率 ≈ 100/104 ≈ **0.96 条/周期**。

**变式 4.** 采用数据旁路（转发）技术后，仍无法消除的冒险是（　）
A. 写后读（RAW）数据冒险　B. 控制冒险（分支）　C. 结构冒险　D. 读后写（WAR）冒险
> **答案 B**（C 需增加资源/分离 Cache 解决）。

**变式 5.** 一次突发传送 8 个 32 位数据、总线时钟 100MHz，若地址与数据各占 1 个总线周期，则一次猝发事务需要多少时间？
> **答案 90ns**（1 个地址周期 10ns + 8 个数据周期 80ns）。

**④ 回链**：[计组/06-总线](../计组/06-总线.md)（带宽与总线事务）、[计组/05-中央处理器](../计组/05-中央处理器.md)（流水线冒险）。

### 专项 11 · 文件系统与 I/O 控制

> 对应错题：25-28、25-31、24-31 ｜ 回链：[操作系统/04-文件管理](../操作系统/04-文件管理.md)、[操作系统/05-输入输出管理](../操作系统/05-输入输出管理.md)

**① 判定口诀**

1. **`VFS`（虚拟文件系统）的作用**：向上提供**统一接口**（`open/read/write/close`），向下适配不同具体文件系统（`FAT`/`NTFS`/`ext4`…）⇒ **让程序与文件系统类型无关**。**不是**缓存、不是加速、不是磁盘划分。
2. **`FAT`（文件分配表）**：把"链式分配"的下块指针**集中存成一张表**；**表项数 = 磁盘块数**，每项记录下一块号；**空闲块可用特殊值标记** ⇒ 顺带充当外存空闲空间管理表。
3. **`inode` 与目录分工**：**文件名在目录项里**，`inode` 存"除文件名外的全部属性 + 数据块索引"；新建文件时要"分配 inode + 在目录中加目录项 + 分配数据块"，但**访问权限写在 inode，不写在目录文件中**。
4. **I/O 软件的层次与缓冲**：用户层 → 系统调用 → **设备无关软件（缓冲、缓存、设备分配、逻辑名→物理名映射）** → 设备驱动 → 中断处理 → 硬件；**引入内核缓冲区是为了缓和 CPU 与 I/O 设备的速度差、减少中断/I/O 次数**（不是为了"提高设备本身的传输速度"）。

**② 易混对比表**

| 项目 | 正确口径 | 常见错解 |
| --- | --- | --- |
| `VFS` | 统一接口、屏蔽差异 | 说成"缓存/加速" |
| `FAT` 表项数 | = 磁盘块数 | 以为是"文件数" |
| 文件名存放位置 | 目录项 | 以为在 inode |
| 访问权限存放位置 | `inode` | 以为在目录项 |
| 内核缓冲区作用 | 缓和速度差、减少中断次数 | 说成提高设备速率 |

**③ 同类变式**

**变式 1.** `VFS` 的主要作用是（　）
A. 提高磁盘读写速度　B. 为不同文件系统提供统一访问接口　C. 管理磁盘空闲空间　D. 实现文件的加密
> **答案 B**。

**变式 2.** 某磁盘块大小 1KB、共 2²⁰ 个块，采用 `FAT` 管理。`FAT` 表至少需要多少个表项？每个表项至少几位？
> **答案**：表项数 = **2²⁰**（一块一项）；块号需 20 位表示 ⇒ 每项至少 **20 位**（实际取整为 3B 或 4B）。

**变式 3.** 下列关于 `inode` 的叙述中，**错误**的是（　）
A. `inode` 中包含文件长度　B. `inode` 中包含文件占用的数据块索引　C. `inode` 中包含文件名　D. `inode` 中包含访问权限
> **答案 C**。文件名只在目录项中，`inode` 里没有文件名（这也是"硬链接"能共享 inode 的原因）。

**变式 4.** 在设备管理中引入内核缓冲区的主要目的是（　）
A. 提高 I/O 设备的传输速率　B. 缓和 CPU 与 I/O 设备速度不匹配的矛盾、减少中断次数　C. 提高磁盘容量利用率　D. 实现设备无关性
> **答案 B**。

**变式 5.** 逻辑设备名到物理设备名的映射属于 I/O 软件层次中的（　）
A. 用户层软件　B. 设备无关软件层　C. 设备驱动程序　D. 中断处理程序
> **答案 B**。

### 专项 12 · 差错控制与编码

> 对应错题：23-37、25-34、24-34 ｜ 回链：[计算机网络/03-数据链路层](../计算机网络/03-数据链路层.md)、[计算机网络/02-物理层](../计算机网络/02-物理层.md)

**① 判定口诀**

1. **最小汉明距离 d 的能力**：**检 e 位错需 d ≥ e+1**；**纠 t 位错需 d ≥ 2t+1**。
   - d = 4 ⇒ 检 3 位、纠 1 位；d = 5 ⇒ 检 4 位、纠 2 位。
   - 记法：**"纠 t 必能检 2t"**。
2. **`CRC`**：发送方用生成多项式做**模 2 除**，余数作校验位；接收方用同一多项式除，**余数为 0 ⇒ 无差错**。"模 2 运算 = 异或、无进位"。
3. **编码方式**：
   - `NRZ`：高低电平直接表示 0/1；`NRZI`：遇 1（或遇 0）翻转；
   - **曼彻斯特**：码元**中间必跳变**（自带同步），用跳变方向表示 0/1；**差分曼彻斯特**：看码元**开始处是否跳变**；
   - **`FSK`**：用**频率**变化表示数据；`ASK` 用幅度；`PSK` 用相位；`QAM` 幅相联合。
4. **两个极限公式**：无噪声 **`C = 2W log₂V`**（V = 码元种类，`16-QAM` ⇒ V = 16）；有噪声 **`C = W log₂(1 + S/N)`**，且 `SNR(dB) = 10 log₁₀(S/N)`。

**② 易混对比表**

| 项目 | 正确口径 | 常见错解 |
| --- | --- | --- |
| d=4 的能力 | 检 3 纠 1 | 说成"检 4 纠 2" |
| `CRC` 余数为 0 | 无差错 | 以为余数即错误位置 |
| 曼彻斯特 vs 差分曼彻斯特 | 前者看**中间**跳变，后者看**起始**跳变 | 两者混用 |
| `FSK` | 频率调制 | 说成相位调制 |
| 16-QAM 每码元 | log₂16 = 4 位 | 记成 2 位 |

**③ 同类变式**

**变式 1.** 某编码集的最小汉明距离为 5，则它最多能检出多少位错、纠正多少位错？
> **答案**：检 **4** 位、纠 **2** 位（d ≥ e+1 ⇒ e ≤ 4；d ≥ 2t+1 ⇒ t ≤ 2）。

**变式 2.** 接收方用生成多项式对收到的码字做模 2 除，余数不为 0，说明（　）
A. 一定发生了 1 位错　B. 检测到差错　C. 能定位并纠正差错　D. 一定是偶数位错
> **答案 B**。`CRC` 只能检错（且不能定位），不能纠错。

**变式 3.** 带宽 3kHz、无噪声，采用 16-QAM 调制，最高数据传输速率是多少？
> **答案 24 kbps**（`C = 2W log₂V = 2 × 3000 × 4`）。

**变式 4.** 带宽 3kHz、信噪比 30dB，按香农公式最高速率约为多少？
> **答案**：30dB ⇒ S/N = 1000 ⇒ `C = 3000 × log₂(1001) ≈ 3000 × 9.97 ≈ 29.9 kbps`。

**变式 5.** 下列调制方式中，通过**频率**变化携带信息的是（　）
A. `ASK`　B. `FSK`　C. `PSK`　D. `QAM`
> **答案 B**。

**④ 回链**：[计算机网络/03-数据链路层](../计算机网络/03-数据链路层.md)（`CRC`/汉明）、[计算机网络/02-物理层](../计算机网络/02-物理层.md)（编码与调制）。

### 专项 13 · 定点数与 `IEEE754`

> 对应错题：23-14、24-12 ｜ 回链：[计组/02-数据的表示和运算](../计组/02-数据的表示和运算.md)

**① 判定口诀**

1. **`IEEE754` 单精度三种情况（先看阶码 E）**：
   - **E = 0**：**非规格化数** ⇒ 真值 = (−1)^S × **0.M** × 2^(−126)（**不是 1.M！**）
   - 0 < E < 255：规格化数 ⇒ 真值 = (−1)^S × **1.M** × 2^(E−127)
   - E = 255：M = 0 ⇒ ±∞；M ≠ 0 ⇒ NaN
2. **类型转换**：
   - 长 → 短（`int`→`short`）：**截断**，只留低位；
   - 短 → 长（`short`→`int`）：**符号扩展**（把符号位补满高位）；
   - `short`(负) → `unsigned int`：先符号扩展，再按无符号解释 ⇒ 变成一个很大的正数。
3. **补码转真值**：最高位为 1 时，真值 = −(2ⁿ − 该补码值)；或"按位取反加 1 得原码"。
4. **溢出判断（硬件）**：`OF = Cₙ ⊕ Cₙ₋₁`（最高位进位与次高位进位异或）；**加法同号得异号 ⇒ 溢出**；**减法异号相减得与被减数异号 ⇒ 溢出**。

**② 易混对比表**

| 项目 | 正确口径 | 常见错解 |
| --- | --- | --- |
| E = 0 的尾数 | **0.M**（隐含 0） | 照抄 1.M |
| 非规格化数的阶 | 固定 **2⁻¹²⁶** | 用 2^(E−127) = 2⁻¹²⁷ |
| `int`→`short` | 截断低位 | 以为要四舍五入 |
| `short`→`int` | 符号扩展 | 零扩展 |
| 8 位补码 −8190 | 0xE002 | 直接写 −8190 的二进制 |

**③ 同类变式**

**变式 1.** 某数采用 `IEEE754` 单精度表示为 `80200000H`，其真值是多少？
> **答案 −2⁻¹²⁸**。阶码字段 E = 0 ⇒ 非规格化数；尾数 M = 0.01₂ = 1/4 ⇒ 真值 = −(1/4) × 2⁻¹²⁶ = **−2⁻¹²⁸**。

**变式 2.** `int` 型变量 `x = 0x0001FFFF`，将其赋给 `short` 型变量后值为多少？若 `x = 0x0000FFFF` 呢？
> **答案**：`0x0001FFFF` 截断低 16 位 = `0xFFFF` = **−1**；`0x0000FFFF` 也是 **−1**。

**变式 3.** 写出 16 位补码下 −8190 的机器数（十六进制）。
> **答案 0xE002**。8190 = 0x1FFE ⇒ 取反 0xE001 ⇒ +1 = **0xE002**。

**变式 4.** 8 位补码运算中，`0x7F + 0x01` 是否溢出？溢出标志 `OF` 为多少？
> **答案**：127 + 1 = 128 超出 8 位补码范围（−128~127）⇒ **溢出，OF = 1**（两个正数相加得负数）。

**变式 5.** `short x = −1; unsigned int y = x;` 则 y 的值是多少？
> **答案 4294967295（0xFFFFFFFF）**。−1 先符号扩展成 32 位全 1，再按无符号解释。

**④ 回链**：[计组/02-数据的表示和运算](../计组/02-数据的表示和运算.md) → `IEEE754` 一节 + "类型转换与溢出判断"。

### 专项 14 · 中断 / `DMA` + 网络性能指标

> 对应错题：24-21、23-33 ｜ 回链：[计组/07-输入输出系统](../计组/07-输入输出系统.md)、[计算机网络/01-计算机网络体系结构](../计算机网络/01-计算机网络体系结构.md)

**① 判定口诀**

1. **中断屏蔽字**：某个中断源的处理程序中，屏蔽字对应位为 **1 = 屏蔽（禁止）**，为 **0 = 允许**；**能屏蔽别人的优先级更高**；处理某级中断时，其屏蔽字屏蔽掉的是**优先级更低**的中断（含自身）。
2. **中断 vs `DMA` 的分工**：中断方式**每传一个单位（字/字节）都要 CPU 介入**；`DMA` **整块数据在主存与设备间直接传送**，只在开始/结束时打断 CPU；**`DMA` 请求的优先级高于中断请求**（要抢总线）。
3. **网络时延比较（存储转发）**：
   - **电路交换**：先建链（约 1 RTT 级固定开销）再传数据 ⇒ **短报文最慢、长报文可能最快**；
   - **报文交换**：整报文逐跳存储转发 ⇒ 时间 ≈ 跳数 × 报文发送时间；
   - **分组交换**：流水线效应 ⇒ 总时间 ≈ 首分组到达时间 + (分组数−1) × 单分组发送时间。
   - 口诀：**短文件 分组 < 报文 < 电路；长文件 电路 < 分组 < 报文**（分组要带额外首部开销）。

**② 易混对比表**

| 项目 | 正确口径 | 常见错解 |
| --- | --- | --- |
| 屏蔽字位 = 1 | 屏蔽该中断 | 以为"允许" |
| 谁能打断谁 | 优先级高的能打断低的 | 只看编号大小 |
| `DMA` 与中断优先级 | `DMA` 更高 | 以为中断更高 |
| 分组交换优势 | 流水线减少总时延 | 说成"线路利用率高"（那是另一回事） |
| 电路交换 | 建链开销固定 | 以为短报文也最快 |

**③ 同类变式**

**变式 1.** 某中断源的中断屏蔽字为 `1111`（4 个中断源），说明（　）
A. 它不能被任何中断打断，且能打断所有低优先级中断　B. 它可以被任何中断打断　C. 它只能打断同级中断　D. 屏蔽字与优先级无关
> **答案 A**。全 1 = 屏蔽所有其他中断，说明它是最高优先级。

**变式 2.** 关于 `DMA` 与中断方式的优先级，正确的是（　）
A. 中断优先级高于 `DMA`　B. `DMA` 优先级高于中断　C. 两者相同　D. 取决于设备速度
> **答案 B**。`DMA` 要占用总线，若被中断拖住会导致数据丢失。

**变式 3.** 主机甲经 1 个路由器向乙发送 8Mb 报文，两段链路速率均为 10Mbps。分别用**报文交换**与**分组交换（分组 10kb）**，总时间各是多少？
> **答案**：报文交换 800ms × 2 段 = **1600ms**；分组交换 = 800 个分组 ⇒ 800×1ms + 1ms = **801ms**。

**变式 4.** 下列关于三种交换方式时延的叙述中，正确的是（　）
A. 无论数据量大小，分组交换总是最快　B. 短报文时电路交换由于建链开销通常最慢　C. 报文交换的时延与跳数无关　D. 电路交换的时延随跳数线性增长
> **答案 B**。

**变式 5.** 分组交换相对报文交换的核心优势是（　）
A. 不需要首部开销　B. 流水线式转发，显著降低总时延　C. 不需要存储转发　D. 可以不用路由
> **答案 B**。

**④ 回链**：[计组/07-输入输出系统](../计组/07-输入输出系统.md)（中断/`DMA`）、[计算机网络/01-计算机网络体系结构](../计算机网络/01-计算机网络体系结构.md)（性能指标）。
