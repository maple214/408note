### 2.1 数据结构（第 1~11 题，22 分）

**1.** 已知程序如下：`int S(int n){ return n<=0 ? 0 : S(n-1)+n; }`，`main(){ S(1); }`。程序运行时用栈保存调用过程信息，自栈底到栈顶保存的信息依次对应的是（　）
A. main() → S(1) → S(0)　B. S(0) → S(1) → main()　C. main() → S(0) → S(1)　D. S(1) → S(0) → main()
> 【答案】A　【考点】栈与函数调用　【解析】调用顺序 main → S(1) → S(0)，先调用的在栈底。【坑】把栈顶栈底写反。

**2.** 先序序列为 a,b,c,d 的不同二叉树的个数是（　）
A. 13　B. 14　C. 15　D. 16
> 【答案】B　【考点】二叉树的形态计数　【解析】给定先序序列的不同二叉树个数 = **Catalan(n)**，n=4 时为 14（也可按左右子树划分逐层分解求和）。【坑】记成 2^(n-1)=8 之类的错公式。

**3.** 下列选项给出的是从根分别到达两个叶结点路径上的权值序列，能属于同一棵**哈夫曼树**的是（　）
A. 24,10,5 和 24,10,7　B. 24,10,5 和 24,12,7　C. 24,10,10 和 24,14,11　D. 24,10,5 和 24,14,6
> 【答案】D　【考点】哈夫曼树构造的约束　【解析】根到两个叶子的路径上，第二个结点的权值要么相等、要么之和等于根权值（24=10+14）；D 反推出叶子权值 5、5、6、8，满足哈夫曼构造。【坑】只看"和为 24"就选 B（24≠10+12）。

**4.** 现有一颗无重复关键字的 `AVL` 树，对其进行中序遍历可得到一个**降序**序列。下列关于该平衡二叉树的叙述中，正确的是（　）
A. 根结点的度一定为 2　B. 树中最小元素一定是叶结点　C. 最后插入的元素一定是叶结点　D. 树中最大元素一定无左子树
> 【答案】D　【考点】AVL / 二叉排序树的中序性质　【解析】**中序降序 ⇒ 左子树值大于根、右子树值小于根**，故最大元素必在"最左"，一定没有左子树。【坑】默认按"左小右大"来读题，把结论选成相反项。

**5.** 设有向图 G=(V,E)，V={V0,V1,V2,V3}，E={<V0,V1>,<V0,V2>,<V0,V3>,<V1,V3>}，从 V0 出发深度优先遍历，可能得到的不同遍历序列个数是（　）
A. 2　B. 3　C. 4　D. 5
> 【答案】D　【考点】DFS 序列枚举　【解析】共 5 种：V0V2V1V3、V0V2V3V1、V0V1V3V2、V0V3V2V1、V0V3V1V2。【坑】把"DFS 只有一种序列"当默认（无序图的邻接点访问顺序可变）。

**6.** 求下面带权图的最小（代价）生成树时，可能是 `Kruskal` 算法第 2 次选中但**不是** `Prim` 算法（从 V4 开始）第 2 次选中的边是（　）　⚠ 原卷含图
A. (v1,v3)　B. (v1,v4)　C. (v2,v3)　D. (v3,v4)
> 【答案】C　【考点】最小生成树的两种算法　【解析】Kruskal 按边权从小到大选，Prim 从 V4 出发按"到当前树的最近顶点"扩展，两者第 2 次选中的边可能不同（图中权值数据未获取，见 [CodeBrick 2015-06](https://www.codebrick.tech/exam-408/q/ds/2015/06)）。

**7.** 下列选项中，**不能**构成折半查找中关键字比较序列的是（　）
A. 500,200,450,180　B. 500,450,200,180　C. 180,500,200,450　D. 180,200,500,450
> 【答案】A　【考点】折半查找判定路径　【解析】折半查找中，每次比较后待查区间必须**单调收缩**；A 中第三次比较 450 说明待查值落在 200~450，第四次不可能再与 180 比较。

**8.** 字符串 S="abaabaabacacaabaabcc"，模式串 t="abaabc"，采用 `KMP` 算法匹配，第一次失配时 i=j=5，则下次开始匹配时 i 和 j 分别是（　）
A. i=1,j=0　B. i=5,j=0　C. i=5,j=2　D. i=6,j=2
> 【答案】C　【考点】KMP 的 `next` 数组　【解析】已匹配子串 "abaab" 的最长相等前后缀是 "ab"（长度 2）⇒ j=2，**主串指针 i 不回溯**（仍为 5）。【坑】选 D（以为要比较下一个字符）或 B（把 next 当 0）。

**9.** 下列排序算法中，元素的移动次数和关键字的初始排列次序**无关**的是（　）
A. 直接插入排序　B. 起泡排序　C. 基数排序　D. 快速排序
> 【答案】C　【考点】排序算法与初始序列的关系　【解析】基数排序靠"分配+收集"，不做关键字比较，移动次数只与位数和元素个数有关。

**10.** 已知小根堆为 8,15,10,21,34,16,12，删除关键字 8 之后需重建堆，在此过程中关键字之间的比较次数是（　）
A. 1　B. 2　C. 3　D. 4
> 【答案】C　【考点】堆的删除与调整　【解析】12 置堆顶后依次与 15、10（交换）、16 比较，共 3 次。

**11.** 希尔排序的组内排序采用的是（　）
A. 直接插入排序　B. 折半插入排序　C. 快速排序　D. 归并排序
> 【答案】A　【考点】`希尔排序`　【解析】按增量分组后各子序列内部做**直接插入排序**。

### 2.2 计算机组成原理（第 12~22 题，22 分）

**12.** 计算机硬件能够直接执行的是（　）Ⅰ. 机器语言程序　Ⅱ. 汇编语言程序　Ⅲ. 硬件描述语言程序
A. 仅Ⅰ　B. 仅Ⅰ、Ⅱ　C. 仅Ⅰ、Ⅲ　D. Ⅰ、Ⅱ、Ⅲ
> 【答案】A　【考点】计算机系统层次结构　【解析】只有机器语言可直接执行；汇编需汇编器翻译，硬件描述语言是"描述硬件"的语言。

**13.** 由 3 个"1"和 5 个"0"组成的 8 位二进制**补码**，能表示的最小整数是（　）
A. −126　B. −125　C. −32　D. −3
> 【答案】B　【考点】补码与原码的换算　【解析】最小负数取符号位为 1，其余两个 1 尽量放在低位：补码 1000 0011 = 原码 1111 1101 = **−125**。【坑】直接按"1000 0011 = −3"读。

**14.** 下列有关浮点数加减运算的叙述中，正确的是（　）
Ⅰ. 对阶操作不会引起阶码上溢或下溢　Ⅱ. 右规和尾数舍入都可能引起阶码上溢　Ⅲ. 左规时可能引起阶码下溢　Ⅳ. 尾数溢出时结果不一定溢出
A. Ⅱ、Ⅲ　B. Ⅰ、Ⅱ、Ⅳ　C. Ⅰ、Ⅲ、Ⅳ　D. Ⅰ、Ⅱ、Ⅲ、Ⅳ
> 【答案】D　【考点】浮点加减运算五个步骤　【解析】四条都正确；特别是 Ⅳ：浮点溢出由**阶码**决定，尾数溢出只会触发右规。

**15.** 假定主存地址 32 位、按字节编址，主存与 Cache 之间采用**直接映射**，主存块大小 4 个字、每字 32 位，采用**回写（Write Back）**方式，则能存放 4K 字数据的 Cache 的**总容量的位数**至少是（　）
A. 146K　B. 147K　C. 148K　D. 158K
> 【答案】**C（148K）**　【考点】Cache 总容量 = 数据 + 标记 + 有效位 + **修改位**　【解析】块数 = 4K字/4字 = 1K（索引 10 位），块内偏移 = 16B（4 位），标记 = 32−10−4 = 18 位；**回写方式每行还需 1 位修改位（脏位）**：(4×32 + 18 + 1 + 1) × 1K = **148K**。【坑】漏掉修改位得 147K（**圣才此处即错**，它选了 B）。

**16.** 假定编译器把 `x=x+3` 转换为指令 `add xaddt, 3`（xaddt 是 x 的存储单元地址），若该机采用页式虚拟存储管理并配有 `TLB`，且 Cache 使用**直写（Write Through）**方式，则完成该指令功能需要访问主存的次数**至少**是（　）
A. 0　B. 1　C. 2　D. 3
> 【答案】**B（1 次）**　【考点】TLB/Cache 命中与写策略　【解析】TLB 命中 ⇒ 地址转换不访存；取指与取数都命中 Cache ⇒ 不访存；但**直写方式每次写都要写主存** ⇒ 至少 **1 次**。【坑】把地址转换也算一次访存（圣才据此选 C=2，错）。

**17.** 下列存储器中，在工作期间需要**周期性刷新**的是（　）
A. SRAM　B. SDRAM　C. ROM　D. FLASH
> 【答案】B　【考点】`DRAM` 刷新　【解析】DRAM（SDRAM）靠电容存储电荷，必须定时刷新。

**18.** 某计算机使用 **4 体交叉存储器**，假定在存储器总线上出现的主存地址（十进制）序列为 8005,8006,8007,8008,8001,8002,8003,8004,8000，则**可能发生**访存冲突的地址对是（　）
A. 8004、8008　B. 8002、8007　C. 8001、8008　D. 8000、8004
> 【答案】D　【考点】低位交叉编址　【解析】4 体交叉时**体号 = 地址 mod 4**：8000 与 8004 的体号都是 0，且两者在序列中出现位置相近 ⇒ 可能冲突。【坑】只看地址差值，不算体号。

**19.** 下列有关总线定时的叙述中，错误的是（　）
A. 异步通信方式中，全互锁协议最慢　B. 异步通信方式中，非互锁协议的可靠性最差
C. 同步通信方式中，同步时钟信号可由多设备提供　D. 半同步通信方式中，握手信号的采样由同步时钟控制
> 【答案】C　【考点】总线定时　【解析】同步通信必须由**统一时钟**控制，不能由多设备各自提供。

**20.** 若磁盘转速 7200 转/分，平均寻道时间 8ms，每个磁道 1000 个扇区，则访问一个扇区的平均存取时间约为（　）
A. 8.1ms　B. 12.2ms　C. 16.3ms　D. 20.5ms
> 【答案】B　【考点】磁盘存取时间　【解析】8（寻道）+ 60/7200/2 ≈ 4.17（平均旋转延迟）+ 60/(7200×1000) ≈ 0.008（传输）≈ **12.2ms**。

**21.** 在采用中断 I/O 方式控制打印输出的情况下，CPU 和打印控制接口中的 I/O 端口之间交换的信息**不可能**是（　）
A. 打印字符　B. 主存地址　C. 设备状态　D. 控制命令
> 【答案】B　【考点】I/O 接口的功能　【解析】中断方式下 CPU 通过端口交换数据、状态和命令，不需要传主存地址（那是 DMA 才需要的）。

**22.** 内部异常（内中断）可分为故障（fault）、陷阱（trap）和终止（abort）三类。下列有关内部异常的叙述中，错误的是（　）

### 第 41 题（15 分 · 数据结构 · 单链表去重）

用单链表保存 m 个整数，结点结构为 `data | link`，且 `|data| ≤ n`（n 为正整数）。设计一个**时间复杂度尽可能高效**的算法：对于链表中 `data` 的**绝对值相等**的结点，仅保留第一次出现的结点，删除其余结点。
例如 head → 21 → 15 → −15 → −7 → 15∧，删除后为 head → 21 → 15 → −15 → −7∧。
要求：(1) 基本设计思想；(2) 用 C/C++ 给出结点数据类型定义；(3) 描述算法并注释；(4) 说明时间复杂度与空间复杂度。

**解题思路**

1. **抓住"|data| ≤ n"这个附加条件**：它把"取值"限定在 0~n 的小范围内，于是可以**用一个大小为 n+1 的辅助数组做"是否出现过"的标记**，从而只需对链表**一趟扫描**——这就是官方所说的"空间换时间"。
2. **为什么不用两重循环**：对每个结点再向前/向后扫描一遍是 O(m²)，虽然结果正确，但评分说明明确"按所实现算法的复杂度给分"，复杂度差会丢分。
3. **删除时的指针技巧**：保留时 `p = p->link`；删除时 `p` **不动**（只是把 `p->link` 指向被删结点的后继），否则会漏检下一个结点。
4. **绝对值处理**：`m = data > 0 ? data : -data;`，再用 `m` 作数组下标（这正是 |data| ≤ n 保证不越界的原因）。

**标准答案**

（1）设计思想：用空间换时间。因 `|data| ≤ n`，辅助数组大小为 n+1、初值全 0；依次扫描各结点，检查 `q[|data|]`：为 0 则保留该结点并置 1；否则从链表中删除该结点。
（2）数据类型定义：
```c
typedef struct node {
    int data;
    struct node *link;
} NODE;
typedef NODE *PNODE;
```
（3）算法实现：
```c
void func(PNODE h, int n) {
    PNODE p = h, r;
    int *q, m;
    q = (int *)malloc(sizeof(int) * (n + 1));      // 申请 n+1 个辅助空间
    for (int i = 0; i <= n; i++) *(q + i) = 0;     // 初值置 0（题库原文此行有 OCR 缺字）
    while (p->link != NULL) {
        m = p->link->data > 0 ? p->link->data : -(p->link->data);   // 取绝对值
        if (*(q + m) == 0) {                       // 该绝对值首次出现
            *(q + m) = 1;
            p = p->link;                           // 保留，p 后移
        } else {                                   // 重复出现：删除 p->link
            r = p->link;
            p->link = r->link;
            free(r);
        }
    }
    free(q);
}
```
（4）时间复杂度 **O(m)**（m 为链表长度，一趟扫描），空间复杂度 **O(n)**（辅助数组 n+1 个整型单元）。

**给分点**（官方评分说明）：① 算法满足功能要求且正确时，(1)(3) 按**所实现算法的时间复杂度**给分（细则表在原页未获取）；② 设计思想文字表述不清但算法实现正确，可参照①给分；③ 思想或实现部分正确，参照①酌情给分；④ 结点类型定义与题目形式不完全相同，酌情给分；⑤ 用 C++ 视同用 C。
**易错点**：① 忘记取绝对值，把 15 与 −15 当成不同值；② 删除时让 `p` 也后移，导致漏检；③ 辅助数组开成 n 而非 **n+1**（下标要覆盖 0~n）；④ 用二重循环（结果对但复杂度不达标，按复杂度给分会降档）；⑤ 该链表**带表头结点**，`p` 应从 head 开始、判断 `p->link` 而非 `p`。
**关联**：[数据结构/02-线性表](../数据结构/02-线性表.md)（链表删除 / 空间换时间）。

### 第 42 题（8 分 · 数据结构 · 邻接矩阵与路径计数）

已知含有 5 个顶点的图 G（原卷含图 ⚠）。请回答：(1) 写出图 G 的邻接矩阵 A（行、列下标均从 0 开始）；(2) 求 A²，说明 A² 中位于 **0 行 3 列**元素值的含义；(3) 若具有 n（n≥2）个顶点的图的邻接矩阵为 B，则 B^m（2≤m≤n）中非零元素的含义是什么？

**解题思路**

1. **(1) 邻接矩阵的写法**：A[i][j] = 1 表示顶点 i 与 j 之间有边，否则 0；无向图的邻接矩阵关于主对角线对称。
2. **(2) A² 的含义要回到乘法定义**：A²[i][j] = Σₖ A[i][k]·A[k][j]，**每一项 A[i][k]A[k][j] 恰是"经过中间顶点 k 的一条两步路径"**，所以求和就是"i 到 j 长度为 2 的路径条数"。题目给出 A²[0][3] = 3 ⇒ 从顶点 0 到顶点 3 长度为 2 的路径有 **3 条**（例如 0→1→3、0→2→3、0→4→3 这类）。
3. **(3) 推广**：B^m[i][j] 的非零元素表示"从 i 到 j 存在长度为 m 的路径"，其**数值**就是路径条数。

**标准答案**

(1) 按图 G 写出邻接矩阵 A（5×5，行列为 0~4；⚠ 原图数值未获取，考试时按图逐条边填 1）。
(2) **A² 中 0 行 3 列元素值为 3，表示从顶点 0 到顶点 3 之间长度为 2 的路径共有 3 条。**
(3) B^m（2≤m≤n）中位于 i 行 j 列的非零元素表示：**图中从顶点 i 到顶点 j 长度为 m 的路径条数**。

**给分点**（官方评分说明）：① 邻接矩阵中结点与行列的对应次序与参考答案不同、**只要正确同样给分**（但 (2) 中顶点编号必须与你自己的矩阵对应）；② A 与 A² 部分正确酌情给分；③ 若分别说明 B²、B³、…、B^n 中非零元素的含义，同样给分；④ B^m 含义部分正确酌情给分。

### 第 43 题（13 分 · 计组 · 单总线数据通路）

某 16 位计算机主存按字节编址、存取单位 16 位，采用 16 位定长指令字格式，CPU 采用**单总线结构**（原卷含框图 ⚠）。图中 R0~R3 为通用寄存器；T 为暂存器；SR 为移位寄存器，可实现直送(mov)、左移一位(left)、右移一位(right) 3 种操作，控制信号 SRop，输出由 SRout 控制；ALU 可实现 mova、add、sub、and、or、not、inc 共 **7 种**操作，控制信号 ALUop。请回答：
(1) 图中哪些寄存器是程序员可见的？为何要设置暂存器 T？
(2) 控制信号 ALUop 和 SRop 的位数至少各是多少？
(3) 控制信号 SRout 所控制部件的名称或作用是什么？
(4) 端点①~⑨中，哪些须连接到控制部件的输出端？
(5) 为完善单总线数据通路，需在端点①~⑨之间添加必要连线，写出起点与终点。
(6) 为什么二路选择器 MUX 的一个输入端是 2？

**解题思路**

1. **(1) 可见性**：程序员能用指令访问的才算"可见"——通用寄存器 **R0~R3** 与 **PC**；T、SR、MAR、MDR 等都是为数据通路服务的**透明部件**。**为何要 T**：单总线结构下 ALU 的 A、B 两个端口若都直接挂在总线上，同一时刻总线上只有一个数据，两个端口会拿到**同一个数据**，运算无法进行；用 T 先把一个操作数锁存起来即可解决。
2. **(2) 位数按"状态数取 2 的对数上取整"**：ALU 7 种操作 ⇒ ⌈log₂7⌉ = **3 位**；SR 3 种操作 ⇒ ⌈log₂3⌉ = **2 位**。
3. **(3)** 某部件要把内部信号送上共享总线，必须能"断开/接通"，否则会与其他部件冲突 ⇒ 需要一个**三态门**。
4. **(4)(5)** 属于数据通路连接问题：需要控制的端点就是那些"寄存器的输入/输出控制信号"端点（**①②③⑤⑧**）；通路缺口是 **⑥→⑨** 与 **⑦→④** 两处（评分说明：答案里若含 ④⑥⑦⑨ 中任意一个就不给分，要的是别的端点）。
5. **(6) 常量 2 的来源**：指令 16 位、按**字节**编址 ⇒ 一条指令占 **2 个内存单元**，顺序执行时下条指令地址 = (PC)+2 ⇒ MUX 的一个输入端接常量 **2**，专门用来做 (PC)+2。

**标准答案**

(1) 程序员可见的寄存器为**通用寄存器 R0~R3 和 PC**；因为采用单总线结构，若无暂存器 T，ALU 的 A、B 端口会同时获得两个相同的数据，数据通路不能正常工作。
(2) ALUop 至少 **3 位**（7 种操作）；SRop 至少 **2 位**（3 种操作）。
(3) SRout 控制的是**三态门**，用于控制移位器与总线之间数据通路的连接与断开。
(4) 端点 **①、②、③、⑤、⑧** 须连接到控制部件的输出端。
(5) 连线 1：**⑥→⑨**；连线 2：**⑦→④**。
(6) 每条指令 16 位、按字节编址 ⇒ 每条指令占 2 个内存单元，顺序执行时下条指令地址为 (PC)+2，MUX 一个输入端为 2 便于执行 (PC)+2 操作。

**给分点**（官方评分说明）：(1) 答通用寄存器 R0~R3 给分、答 PC 给分，部分正确酌情给分；T 的作用答"暂时存放 A 端口的数据"给分，其他酌情。(3) 只要答出**三态门**或"控制连接/断开"即给分。(4) 答案含 ④、⑥、⑦、⑨ 中任意一个**不给分**，不全酌情给分。(5) 答其他连线酌情给分。
**易错点**：① (1) 只答 R0~R3 漏 PC，或把 T/MAR/MDR 当可见寄存器；② (2) 写成"7 位/3 位"（把操作种类数当位数）；③ (3) 答"状态字寄存器"（圣才此处即错）；④ (4) 把 ④⑥⑦⑨ 这些**总线端点**误当成控制信号端点；⑤ (6) 只答"为了加 2"而说不出"16 位指令按字节编址占 2 个单元"这一层。
**关联**：[计组/05-中央处理器](../计组/05-中央处理器.md)（单总线数据通路 / 微操作控制信号）。

### 第 44 题（10 分 · 计组 · 指令格式与机器码）

承第 43 题的计算机：其部分指令执行过程的控制信号如题 44 图 a（⚠ 未获取），指令格式如题 44 图 b（⚠ 未获取）；该机支持**寄存器直接**和**寄存器间接**两种寻址方式（寻址方式位分别为 0 和 1），通用寄存器 R0~R3 编号分别为 0、1、2、3。请回答：
(1) 该机指令系统最多可定义多少条指令？
(2) 已知 inc、shl、sub 的操作码分别为 01H、02H、03H，写出下列指令的机器代码：① inc R1 ；② shl R2,R1 ；③ sub R3,(R1),R2
(3) 寄存器 x 的输入/输出控制信号记为 Xin/Xout（1 有效），存储器控制信号为 MEMop（read/write）。写出图 a 中标号①~⑧处的控制信号或取值。
(4) 指令 sub R1,R3,(R2) 与 inc R1 的执行阶段至少各需多少个时钟周期？

1. **(1)** 操作码 **7 位** ⇒ 最多 2⁷ = **128 条**指令。
2. **(2) 先把指令格式拆成位段**（由官方答案的位串反推）：`操作码(7) | 方式(1)+寄存器(2) | 方式(1)+寄存器(2) | 方式(1)+寄存器(2)`，共 7+3+3+3 = **16 位**；方式位 0 = 寄存器直接，1 = 寄存器间接。逐条拼：
   - `inc R1`：OP=0000001，第一操作数 0|01(R1)，其余补 0 ⇒ `0000001 0 01 0 00 0 00` = **0240H**

(3) ① **0**；② **mov**；③ **mova**；④ **left**；⑤ **read**；⑥ **sub**；⑦ **mov**；⑧ **SRout**。
(4) `sub R1,R3,(R2)` 执行阶段至少 **4** 个时钟周期；`inc R1` 至少 **2** 个。

**给分点**（官方评分说明）：(3) **答对两个给分**（其余小问原页未附评分说明，按问分步给分）。
**易错点**：① (1) 答 2⁷ 之外的数（如 128 之外写成 7 位能编 7 条）；② (2) 漏掉"寻址方式位占 1 位"，导致寄存器编号错位、机器码全错；③ 把 0488H 写成 0464H、06EAH 写成 06EEH（圣才此处即错）；④ (4) 低估 inc R1 的周期数（单总线下不可能 1 个周期完成，圣才写 8/1 属错）。

### 第 45 题（9 分 · 操作系统 · 信箱辩论的 PV 同步）

有 A、B 两人通过信箱辩论：每人都从自己的信箱中取对方的问题，把答案和新问题组成一个邮件放入对方信箱。A 的信箱最多放 **M** 个邮件，B 的信箱最多放 **N** 个邮件；初始时 A 的信箱中有 **x** 个邮件（题面被截断，由圣才补为 **0<x<M、0<y<N**，B 的信箱中有 y 个）。当信箱不为空时才能取邮件，否则等待；当信箱不满时才能放入新邮件，否则等待。请添加必要信号量并用 P、V 操作实现同步，写出完整过程并说明信号量含义与初值。

**解题思路**

1. **把它看成"两个方向相反的生产者-消费者"**：A 取自己的信箱 = 消费 A，A 往 B 放 = 生产 B；B 取自己的信箱 = 消费 B，B 往 A 放 = 生产 A。
2. **每个信箱需要一对信号量**：`Full_X`（信箱里有几封，可取）与 `Empty_X`（还能放几封）——**初值由题目给的初始邮件数决定**：`Full_A = x`、`Empty_A = M − x`、`Full_B = y`、`Empty_B = N − y`。
3. **两个信箱还要各自互斥**（同一信箱可能同时被读写）：`mutex_A = 1`、`mutex_B = 1`。
4. **P 的顺序**：先 P 同步信号量（`Full`/`Empty`）再 P 互斥锁 `mutex`，否则可能出现"拿着锁等资源"的死锁；取邮件时 `V(Empty)`（腾出空位）、放邮件时 `V(Full)`（增加可取数）。

**标准答案**

```c
semaphore Full_A  = x;      // A 的信箱中的邮件数量
semaphore Empty_A = M - x;  // A 的信箱中还可存放的邮件数量
semaphore Full_B  = y;      // B 的信箱中的邮件数量
semaphore Empty_B = N - y;  // B 的信箱中还可存放的邮件数量
semaphore mutex_A = 1;      // A 的信箱互斥
semaphore mutex_B = 1;      // B 的信箱互斥

CoBegin
A {
    while (TRUE) {
        P(Full_A);
        P(mutex_A);
        从 A 的信箱中取出一个邮件;
        V(mutex_A);
        V(Empty_A);
        回答问题并提出一个新问题;
        P(Empty_B);
        P(mutex_B);
        将新邮件放入 B 的信箱;
        V(mutex_B);
        V(Full_B);
    }
}
B {
    while (TRUE) {
        P(Full_B);
        P(mutex_B);
        从 B 的信箱中取出一个邮件;
        V(mutex_B);
        V(Empty_B);
        回答问题并提出一个新问题;
        P(Empty_A);
        P(mutex_A);
        将新邮件放入 A 的信箱;
        V(mutex_A);
        V(Full_A);
    }
}
CoEnd
```

**给分点**（官方评分说明）：① **每对信号量的定义及初值正确给分**；② 每个互斥信号量的 P、V 使用正确各给分；③ 每个同步信号量的 P、V 使用正确各给分；④ 其他答案酌情给分。
**易错点**：① 只用一对 `empty/full`，没意识到**两个信箱要各配一对**；② 初值写死成 0/M、0/N，**忽略题目给的初始邮件数 x、y**；③ 两个信箱只设一把互斥锁（应各自一把，因为 A、B 可同时操作各自的信箱）；④ `V` 的对象写反（取完应 `V(Empty)`、放完应 `V(Full)`）；⑤ 先 P 互斥锁再 P 资源信号量，形成死锁风险。
**关联**：[操作系统/02-进程与线程](../操作系统/02-进程与线程.md)（PV 操作 / 生产者-消费者变体）。

### 第 46 题（6 分 · 操作系统 · 二级页表）

某计算机系统按字节编址，采用二级页表的分页存储管理方式，虚拟地址格式为：**页目录号 10 位 | 页表索引 10 位 | 页内偏移量 12 位**。请回答：
(1) 页和页框的大小各为多少字节？进程的虚拟地址空间大小为多少页？
(2) 假定页目录项和页表项均占 4 个字节，则进程的页目录和页表共占多少页？要求写出计算过程。
(3) 若某指令周期内访问的虚拟地址为 0100 0000H 和 0111 2048H，则进行地址转换时共访问多少个二级页表？说明理由。

**解题思路**

1. **(1)** 页大小由**页内偏移位数**决定：2¹² B = **4KB**；页框（物理块）与页等大，也是 **4KB**。虚拟地址空间页数 = 2³²/2¹² = **2²⁰ 页**（即 1M 页）。
2. **(2) 分两部分算再相加**：
   - 页目录：页目录号 10 位 ⇒ 2¹⁰ 个页目录项，每项 4B ⇒ 4KB ⇒ 恰好 **1 页**；
   - 页表：页表索引 10 位 ⇒ 每个二级页表 2¹⁰ 项 = 4KB = 1 页，而**页目录项有 2¹⁰ 个 ⇒ 最多 2¹⁰ 个二级页表 ⇒ 2¹⁰ 页**；
   - 合计 **1 + 1024 = 1025 页**。
3. **(3) 判据是"页目录号是否相同"**：两个地址的最高 10 位（页目录号）都是 **4** ⇒ 走同一个页目录项 ⇒ 只访问**同一个二级页表**（共 1 个）。

**标准答案**

(1) 页和页框大小均为 **4KB**；进程虚拟地址空间大小为 2³²/2¹² = **2²⁰ 页**。
(2) (2¹⁰ × 4B)/4KB（页目录所占页数）+ (2²⁰ × 4B)/4KB（页表所占页数）= 1 + 1024 = **1025 页**。
(3) 共访问 **1 个**二级页表。因为虚拟地址 0100 0000H 与 0111 2048H 的**最高 10 位的值都是 4**，访问的是同一个二级页表。

**给分点**（官方评分说明）：用其他方法计算，**思路和结果正确同样给分**。
**易错点**：① (1) 把"虚拟地址空间大小"答成 2³² 字节而没换算成**页数** 2²⁰；② (2) 漏掉页目录那 1 页，或把页表页数算成 2¹⁰ 之外的数（把"页表项数"与"页表个数"混起来）；③ (3) 只比较地址是否在同一"页"（应比**页目录号**，即最高 10 位）；④ 写成"两个二级页表"（因两个地址的低位不同就误判）。
**关联**：[操作系统/03-内存管理](../操作系统/03-内存管理.md)（二级页表 / 地址变换）。

### 第 47 题（9 分 · 网络 · DHCP / ARP / 网关错配）

某网络拓扑如题 47 图所示（⚠ 未获取）：路由器内网接口、DHCP 服务器、WWW 服务器与主机 1 均采用**静态 IP**，主机 2~主机 N 通过 DHCP 动态获取配置。请回答：
(1) DHCP 服务器可为主机 2~主机 N 动态分配 IP 地址的最大范围是什么？主机 2 用 DHCP 获取地址的过程中，封装 DHCP Discover 报文的 IP 分组的源 IP 与目的 IP 分别是什么？
(2) 若主机 2 的 ARP 表为空，它访问 Internet 时发出的**第一个以太网帧**的目的 MAC 是什么？封装主机 2 发往 Internet 的 IP 分组的以太网帧的目的 MAC 又是什么？
(3) 若主机 1 的子网掩码和默认网关分别配置为 255.255.255.0 和 111.123.15.2，则该主机能否访问 WWW 服务器？能否访问 Internet？说明理由。

**由官方答案反推的图注数据**：路由器内网接口（即**正确**的默认网关）= **111.123.15.1**；其 MAC = **00-a1-a1-a1-a1-a1**；网段为 **111.123.15.0/24**，其中 .1~.4 被静态占用，故 DHCP 可分配 **111.123.15.5 ~ 111.123.15.254**。

**解题思路**

1. **(1) DHCP 地址池**：网段 111.123.15.0/24，除去网络地址、广播地址与已被静态占用的 .1~.4 ⇒ 可分配范围 **111.123.15.5~111.123.15.254**。Discover 是"我还不知道自己在哪"的广播：源 IP 用 **0.0.0.0**（本机未配置），目的 IP 用**受限广播地址 255.255.255.255**。
2. **(2) 两个 MAC 的区别是本题核心**：
   - 主机 2 的 ARP 表为空 ⇒ 它先要解析"默认网关的 MAC"，**ARP 请求是广播帧** ⇒ 第一个以太网帧的目的 MAC = **ff-ff-ff-ff-ff-ff**；

3. **(3) 掩码对、网关错**：掩码 255.255.255.0 正确 ⇒ 主机 1 与 WWW 服务器在同一子网，**可直接通信**（同子网不需要网关）；但默认网关被配成 111.123.15.2（正确应为 111.123.15.1）⇒ 发往 Internet 的分组被送到**错误的网关**，无法转发出去 ⇒ **不能访问 Internet**。

**标准答案**

(1) 最大范围：**111.123.15.5 ~ 111.123.15.254**；Discover 的源 IP = **0.0.0.0**，目的 IP = **255.255.255.255**。
(2) 第一个以太网帧的目的 MAC = **ff-ff-ff-ff-ff-ff**；封装发往 Internet 的 IP 分组的以太网帧目的 MAC = **00-a1-a1-a1-a1-a1**。
(3) 主机 1 **能**访问 WWW 服务器，**不能**访问 Internet。因为其子网掩码配置正确，同一子网内的 WWW 服务器可达；但默认网关 IP 被错误配置为 **111.123.15.2**（正确是 **111.123.15.1**），主机 1 访问 Internet 时发出的 IP 分组会被路由到错误的默认网关，从而无法到达目的主机。

**给分点**（N诺评分页给出的官方逐问配分）：**(1) 3 分 + (2) 2 分 + (3) 4 分 = 9 分**。其中 (1) 只答出上界 111.123.15.254、漏掉下界 111.123.15.5 **扣 1 分**；(3) 判断正确但理由未点明"默认网关配错（应为 111.123.15.1）"**扣 1 分**。
**易错点**：① (1) 只答"最大 IP 是 .254"（漏 .5 这个下界，评分明确扣分）；② Discover 的源 IP 写成主机自己的地址（应为 0.0.0.0）；③ (2) 把两个 MAC 都答成网关 MAC（ARP 请求必须广播）；④ (3) 只答"不能访问 Internet"却不说网关配错、更不说正确值；⑤ 误答"也不能访问 WWW 服务器"（同子网不受网关影响）。
**关联**：[计算机网络/04-网络层](../计算机网络/04-网络层.md)（DHCP/ARP/默认网关）、[03-数据链路层](../计算机网络/03-数据链路层.md)。
