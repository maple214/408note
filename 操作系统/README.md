## 0. 这套笔记怎么用

1. 一章一份，文件名 `01-` ~ `05-`。
2. 每份结构固定：**知识框架 → 概念详解 → 易混对比表 → 例题精练（3 道）→ 自测清单**。
3. VS Code 按 `Ctrl+Shift+V` 预览；公式写成**纯文本/行内代码**（如 `缺页率 = 缺页次数 / 访问总次数`），**故意不用 LaTeX**；`P`/`V` 操作与代码用 ```c 代码块。
4. 操作系统的特点是「概念不难、计算很密」：**能考大题的就那六七种算法，全部要能画表手推**。

---

## 1. 操作系统在 408 里的位置

| 项目 | 内容 |
| --- | --- |
| 分值 | **35 分** |
| 题量 | 约 10 题：8~9 道单选（每题 2 分）+ 1~2 道综合应用题（约 15 分） |
| 大题形态 | 计算类（调度、置换、银行家、磁盘、文件索引）+ 代码类（信号量 `P`/`V` 描述同步互斥） |

**六类必考大题，每一类都要练到"看到题目就知道画什么表"**：

1. 信号量与 `P`/`V` 操作（生产者-消费者、读者-写者、哲学家进餐、前驱图）
2. `CPU` 调度算法（`FCFS`、`SJF`、`HRRN`、时间片轮转、优先级、多级反馈队列）算周转时间与带权周转时间
3. 页面置换算法（`OPT`、`FIFO`、`LRU`、`CLOCK`）与缺页率、`Belady` 异常
4. 银行家算法（安全性检查、`Need` 矩阵、请求能否满足）
5. 磁盘调度算法（`FCFS`、`SSTF`、`SCAN`、`C-SCAN`）算磁头移动总距离
6. 文件系统（混合索引的最大文件长度、位示图、`FAT` 表项与簇号、目录检索）

## 3. 与计组的交叉点（两科一起记，省一半功夫）

| 交叉主题 | 计组侧 | 操作系统侧 |
| --- | --- | --- |

| 中断 | 中断隐指令、中断向量、多重中断 | 中断处理程序、系统调用入口、进程切换 |

| `DMA` | `DMA` 控制器与传送过程 | 设备驱动、`I/O` 软件层次、缓冲 |
