```

├── 基本概念

│   ├── 度、入度、出度 —— 握手定理（无向图度数之和 = 2e）
│   ├── 路径、回路、简单路径、简单回路

│   └── 子图、边与顶点的关系
├── 存储结构
│   ├── 邻接矩阵 —— 顺序存储，O(n^2)，适合稠密图；A^n 的含义
│   ├── 邻接表   —— 顺序 + 链式，O(n+e)，适合稀疏图；求入度难

│   └── 邻接多重表 —— 无向图专用，每条边只存一个结点
├── 遍历
│   ├── DFS：递归 / 显式栈；O(n^2)（矩阵）与 O(n+e)（邻接表）
│   └── BFS：队列；可求无权图单源最短路径；层次分层
└── 应用
    ├── 最小生成树（MST）：Prim（选点，O(n^2)）、Kruskal（选边，O(e log e)）
    ├── 最短路径：BFS（无权）、Dijkstra（单源，非负权）、Floyd（多源，三重循环）
    ├── 拓扑排序：AOV 网、入度为 0 出队、判有向图是否有环
    └── 关键路径：AOE 网、ve/vl、e/l、时间余量 = 0 即关键活动
```

**一句话串起来**：图先用**存储结构**把「点与点的关系」装进内存，再用**遍历**决定访问顺序；遍历的骨架 + 不同的贪心/递推策略，就长出**生成树、最短路径、拓扑排序、关键路径**四类应用。

**408 怎么考**：本章是最容易「背模板拿分」的一章。选择题集中在概念辨析（度、连通、存储结构选择、序列是否合法）；大题集中在 `Dijkstra` 表格法、拓扑序列、关键路径 `ve`/`vl` 手算，算法设计题常考邻接表上的 `DFS`/`BFS` 与判环。

## 二、概念详解

### 6.1 图的基本概念

#### 1. 有向图与无向图

- **无向图**：边没有方向，记作 `(v, w)`，是顶点的**无序对**。同一条边不重复出现。
- **有向图**：边有方向，叫**弧**，记作 `<v, w>`（`v` 是弧尾/起点，`w` 是弧头/终点），是顶点的**有序对**。`<v, w>` 与 `<w, v>` 是两条不同的弧。

**为什么这样定义**：图描述的是「多对多」关系。无向图表达对称关系（两个人是朋友），有向图表达非对称关系（A 关注了 B，B 不一定关注 A）。这也直接决定了两者在存储、度定义上的差别。

> **408 怎么考 / 常见坑**：题目常给边集让你判断能否构成图，或给顶点数求边数上界。注意「同一条边不重复」「无自环」是简单图的默认假设；408 讨论的一般都是**简单图**。

#### 2. 完全图、稠密图与稀疏图

- **无向完全图**：任意两个顶点之间都有一条边，边数 `e = n(n-1)/2`。
- **有向完全图**：任意两个顶点之间都有方向相反的两条弧，弧数 `e = n(n-1)`。
- **稠密图 / 稀疏图**：这是**相对概念**，没有绝对界限。通常把边数接近 `n(n-1)` 的叫稠密图，`e` 远小于 `n^2` 的叫稀疏图（王道常以 `e < n log n` 作经验界限）。

**怎么来的**：`n` 个顶点两两配对，从 `n` 个里选 2 个就是 `C(n,2) = n(n-1)/2`；有向图每对顶点有 2 个方向，再乘 2 得 `n(n-1)`。

> **408 怎么考 / 常见坑**：直接考结论。坑点是把无向完全图的边数写成 `n(n-1)`，或对有向图仍用 `n(n-1)/2`。稠密/稀疏判断决定你选邻接矩阵还是邻接表 —— 这是后面存储结构选择题的判据。

#### 3. 度、入度、出度（握手定理）

- **无向图**：顶点 `v` 的度 `TD(v)` 是依附于它的边数。
- **有向图**：入度 `ID(v)` 是以 `v` 为弧头的弧数，出度 `OD(v)` 是以 `v` 为弧尾的弧数，`TD(v) = ID(v) + OD(v)`。
- **无向图**：`Σ TD(v) = 2e`（每条边给两个端点各贡献 1）。
- **有向图**：`Σ ID(v) = Σ OD(v) = e`。

**为什么**：度的定义就是「关联的边数」，一条无向边连着两个顶点，所以被数了两遍；有向图每条弧恰好有一个弧头和一个弧尾，所以入度总和 = 出度总和 = 弧数。

> **408 怎么考 / 常见坑**：给度数序列反推边数，或判断「是否存在这样的无向图」（度序列可图化：度之和为偶数，且最大度小于 `n`）。高频坑是忘了「无向图度之和是边数的 **2 倍**」这个 `× 2`。

#### 4. 路径、回路、简单路径、简单回路

- **路径**：顶点序列 `v0, v1, ..., vk`，相邻顶点间都有边。
- **回路（环）**：第一个顶点和最后一个顶点相同的路径。
- **简单路径**：顶点不重复出现的路径。
- **简单回路**：除首尾顶点外，其余顶点不重复的回路。
- **路径长度**：路径上**边的数目**（不是顶点数）。带权图上是边权之和。

> **408 怎么考 / 常见坑**：最爱考的是路径长度的定义 —— 是边数不是顶点数。另外要区分「简单路径」和「简单回路」的判定范围（回路看除首尾外是否重复，路径看所有顶点是否重复）。

#### 5. 连通图、连通分量、强连通图、强连通分量

- **连通**（无向图）：顶点 `v` 到 `w` 有路径。
- **连通图**：无向图中任意两个顶点都连通。**非连通图**至少有两个连通分量。
- **连通分量**：无向图的**极大连通子图**。所谓「极大」是指：该子图连通，且再并入任何其他顶点就不连通了。
- **强连通图**（有向图）：任意两个顶点 `v`、`w` 之间，`v` 到 `w` 和 `w` 到 `v` **都有**路径。
- **强连通分量**：有向图的**极大强连通子图**。
- 重要结论：`n` 个顶点的连通图**至少有 `n-1` 条边**；`n` 个顶点的强连通图**至少有 `n` 条边**（构成一个环）。

**为什么「极大」而不是「最大」**：连通分量按每个点各自所属的连通块划分，每个块都撑到最大，所以叫极大连通子图。一个连通图只有一个连通分量（就是它自己）。

> **408 怎么考 / 常见坑**：高频选择题。给顶点数求「至少/至多几条边保证连通」。陷阱：`n-1` 条边**不一定**连通（可能是 `n-1` 条边分成两块），但 `n-1` 条边**加上连通条件**就是树。

#### 6. 生成树与生成森林

- **生成树**：含连通图**全部 `n` 个顶点**、只含 `n-1` 条边的**极小连通子图**。
- **生成森林**：非连通图中每个连通分量各取一棵生成树，合起来就是生成森林。

> **408 怎么考 / 常见坑**：`n` 个顶点的生成树恰好 `n-1` 条边 —— 这个数字是后面 `Prim`/`Kruskal` 结果校验的标尺。生成树可能不唯一，但边数一定相同。注意生成树是「极小连通子图」，去掉任一条边就不连通，加任一条边就有回路。

#### 7. 网（带权图）与子图

- **网**：边上带权值的图。权可以表示距离、代价、时间。
- **子图**：设 `G = (V, E)`，`G' = (V', E')`，若 `V' ⊆ V` 且 `E' ⊆ E`，则 `G'` 是 `G` 的子图。注意**必须同时是顶点集和边集的子集**，且 `E'` 中的边端点必须都在 `V'` 中。

> **408 怎么考 / 常见坑**：子图判断常以小图选项形式出现，坑在于「顶点少但边不属于原图」这种假子图。

### 6.2 图的存储及基本操作

#### 1. 邻接矩阵

**定义**：用一维数组 `vexs[n]` 存顶点，用二维数组 `Edge[n][n]` 存边。无向图中 `Edge[i][j] = 1` 表示 `(i,j)` 是边；有向图中 `Edge[i][j] = 1` 表示 `<i,j>` 是弧；带权图中存权值，无边用 `∞`（对角线用 `0`）。

```c
#define MAXV 100
#define INF  0x3f3f3f3f
typedef struct {
    char vexs[MAXV];            // 顶点表
    int  edge[MAXV][MAXV];      // 邻接矩阵
    int  n, e;                  // 顶点数、边数
} MGraph;
```

**性质与代价**：

| 性质 | 说明 |
| --- | --- |
| 空间复杂度 | `O(n^2)`，与边数无关（只跟顶点数有关）|
| 判断 `(i,j)` 是否有边 | `O(1)`，直接查 `edge[i][j]` |
| 求某顶点所有邻接点 | `O(n)`，要扫一整行 |
| 无向图 | 矩阵**一定对称**，可只存上三角省一半空间 |
| 有向图 | 矩阵**一般不对称**；第 `i` 行非零个数 = `OD(i)`，第 `j` 列非零个数 = `ID(j)` |
| 无向图求度 | 第 `i` 行之和 = `TD(i)` |
| 适用场景 | **稠密图**，或需要频繁判断两点间是否有边 |

**`A^n` 的含义**（高频考点）：设 `A` 为邻接矩阵，则 `A^n` 的第 `i` 行第 `j` 列元素 `a^n_ij` 等于**从顶点 `i` 到顶点 `j` 长度为 `n` 的路径（通路）数目**。特别地，`A^2` 的元素表示长度为 2 的路径条数，对角元 `a^2_ii` = 经过 `i` 的长度为 2 的回路数。

**为什么**：矩阵乘法 `a^n_ij = Σ_k a^(n-1)_ik · a_kj`，正好枚举了「第 `n-1` 步到 `k`，再从 `k` 一步到 `j`」，是在数路径条数。

> **408 怎么考 / 常见坑**：① `A^n` 的含义是「路径**条数**」而不是「是否存在路径」；② 别把无向图矩阵的对称性记错；③ 带权图里无边的表示：`∞` 表示不直接相连，对角线为 `0`；④ 邻接矩阵**唯一**（给定顶点编号后），这一点和邻接表相反。

#### 2. 邻接表

**定义**：顶点表是顺序存储（数组），每个顶点挂一条单链表，链表中每个结点代表一条依附于该顶点的边。有向图中，顶点 `i` 的链表存的是**以 `i` 为弧尾**的所有弧（出边）。

```c
typedef struct ArcNode {          // 边结点
    int adjvex;                   // 该边指向的顶点下标
    struct ArcNode *next;         // 下一条边
    int weight;                   // 网中才有：权值
} ArcNode;

typedef struct VNode {            // 顶点结点
    char data;
    ArcNode *first;               // 第一条边的指针
} VNode, AdjList[MAXV];

typedef struct {
    AdjList vertices;
    int n, e;
} ALGraph;
```

**无向图 vs 有向图的表结构差异**：

- **无向图**：每条边 `(i,j)` 在 `i` 的表和 `j` 的表中各出现一次，所以**边结点总数 = 2e**。
- **有向图**：每条弧 `<i,j>` 只出现在 `i` 的表中，所以**边结点总数 = e**。于是有向图邻接表**出度易求**（数第 `i` 条链表的结点个数），**入度难求**（要遍历整张表）。

**性质与代价**：

| 性质 | 说明 |
| --- | --- |
| 空间复杂度 | 无向图 `O(n + 2e)`，有向图 `O(n + e)`，统一写作 `O(n+e)` |
| 求某顶点所有邻接点 | `O(该顶点的度)`，很高效 |
| 判断 `(i,j)` 是否有边 | `O(该顶点的度)`，要遍历链表，最坏 `O(n)` |
| 有向图求入度 | `O(n+e)`，需要遍历整张表 |
| 唯一性 | **不唯一**，取决于边结点的插入顺序 |
| 适用场景 | **稀疏图**，以及需要频繁遍历某点所有邻接点的算法（`DFS`/`BFS`）|

> **408 怎么考 / 常见坑**：① 邻接表**不唯一**，所以「图的邻接表存储是唯一的」是错话；② 无向图边结点数是 `2e` 不是 `e`，常考；③ 题目常给一个邻接表图让你数出度、入度、判断连通性；④ 逆邻接表是「以 `i` 为弧头」的链表，专门为求入度设计。

#### 3. 十字链表（有向图）

**解决的问题**：邻接表求入度要 `O(n+e)`。十字链表把**出边表和入边表合并**，让有向图的出度和入度都是 `O(1)` 级别可查。

**结构**：每个**弧结点**有 5 个域 —— `tailvex`（弧尾）、`headvex`（弧头）、`hlink`（指向弧头相同的下一条弧）、`tlink`（指向弧尾相同的下一条弧）、`info`（权值）。每个**顶点结点**有 3 个域 —— `data`、`firstin`（第一条入弧）、`firstout`（第一条出弧）。

**关键结论**：

- 每条弧**只有一个结点**，所以总空间 `O(n+e)`。
- 顺着 `firstout` 走即出边，顺着 `firstin` 走即入边。
- **邻接表和逆邻接表的结合体**，是有向图存储的「完备」形式。

> **408 怎么考 / 常见坑**：主要考「十字链表用于有向图，求入度和出度都方便」这一结论，以及结点域的含义。注意它**不用于无向图**（无向图用邻接多重表）。

#### 4. 邻接多重表（无向图）

**解决的问题**：无向图用邻接表存，每条边出现两次。若要对边做操作（如删除一条边、标记边已访问），得同时改两处，麻烦。邻接多重表让**每条边只有一个结点**。

**结构**：每个**边结点**有 6 个域 —— `ivex`、`jvex`（边的两个端点）、`ilink`（指向依附于 `ivex` 的下一条边）、`jlink`（指向依附于 `jvex` 的下一条边）、`info`（权值）、`mark`（访问标记）。每个**顶点结点**有 2 个域 —— `data`、`firstedge`。

**关键结论**：

- 边结点数 = `e`（不再是 `2e`），空间 `O(n+e)`。
- 删除一条边或标记一条边，只改一个结点，`O(1)` 定位。
- 适合**无向图**（含无向网）。

> **408 怎么考 / 常见坑**：最高频的一句话是「邻接多重表**只适用于无向图**，每条边只存一个结点」。常与十字链表配对出「下列说法正确的是」型选择题。

#### 5. 四种存储结构对比与选型

| 维度 | 邻接矩阵 | 邻接表 | 十字链表 | 邻接多重表 |
| --- | --- | --- | --- | --- |
| 适用图类型 | 有向、无向均可 | 有向、无向均可 | **仅有向图** | **仅无向图** |
| 空间复杂度 | `O(n^2)` | `O(n+e)` | `O(n+e)` | `O(n+e)` |
| 边结点/矩阵元个数 | `n^2` | 无向 `2e`，有向 `e` | `e`（每弧一结点）| `e`（每边一结点）|
| 判断边 `(i,j)` 是否存在 | `O(1)` | `O(度)`，最坏 `O(n)` | `O(出度)` | `O(度)` |
| 求某点全部邻接点 | `O(n)` | `O(度)` | `O(出度)` | `O(度)` |
| 求有向图入度 | `O(n)`（数列）| 难，`O(n+e)` | **易** | 不适用 |
| 求有向图出度 | `O(n)`（数行）| 易，`O(出度)` | **易** | 不适用 |
| 表示是否唯一 | **唯一** | 不唯一 | 不唯一 | 不唯一 |
| 典型适用 | **稠密图**、频繁判边 | **稀疏图**、频繁遍历邻接点 | 有向图需频繁查入/出度 | 无向图需频繁处理边 |

> **408 怎么考 / 常见坑**：选型题的判断逻辑是「稠密 → 矩阵；稀疏 → 邻接表；要同时方便求入度出度（有向）→ 十字链表；无向图按边操作 → 邻接多重表」。

### 6.3 图的遍历

**共同点**：`DFS` 和 `BFS` 都需要一个 `visited[]` 数组标记已访问顶点，且都要处理**非连通图** —— 对每个未访问顶点各调用一次遍历，才能覆盖全部连通分量。

#### 1. 深度优先搜索（`DFS`）

**思想**：类似于树的先根遍历。从顶点 `v` 出发，访问 `v`，然后选一个未访问的邻接点 `w` 深入下去，直到无路可走再**回退**（回溯）到最近的有未访问邻接点的顶点。

**递归实现**（以邻接表为例，矩阵版只需换内层循环）：

```c
int visited[MAXV];                        // 全局访问标记

void DFS(ALGraph G, int v) {
    visited[v] = 1;
    visit(v);                             // 访问顶点 v
    for (ArcNode *p = G.vertices[v].first; p; p = p->next)
        if (!visited[p->adjvex])
            DFS(G, p->adjvex);            // 递归深入
}

void DFSTraverse(ALGraph G) {
    for (int i = 0; i < G.n; i++) visited[i] = 0;
    for (int i = 0; i < G.n; i++)
        if (!visited[i]) DFS(G, i);       // 处理非连通图
}
```

**非递归（显式栈）实现**：把递归换成手动压栈。注意一个细节 —— 压栈时可以不立即标记 `visited`，但必须在**出栈访问时**标记，否则同一顶点会被多次压栈。更稳妥的写法是「入栈即标记」：

```c
void DFS_NonRec(ALGraph G, int v) {
    int st[MAXV], top = -1;
    visited[v] = 1; visit(v);
    st[++top] = v;
    while (top >= 0) {
        int x = st[top];
        ArcNode *p = G.vertices[x].first;
        while (p && visited[p->adjvex]) p = p->next;   // 找第一个未访问邻接点
        if (p) {                                       // 找到就深入
            visited[p->adjvex] = 1;
            visit(p->adjvex);
            st[++top] = p->adjvex;
        } else {
            top--;                                     // 没有则回退
        }
    }
}
```

> 代码里的 `visit()` 表示「访问顶点」的具体动作（打印、计数等），考试时替换成题目要求的操作。

**复杂度**：

| 存储结构 | 时间复杂度 | 说明 |
| --- | --- | --- |
| 邻接矩阵 | `O(n^2)` | 每个顶点都要扫一整行 `n` 个位置 |
| 邻接表 | `O(n+e)` | 每个顶点访问一次，每条边被检查常数次 |
| 空间（递归栈） | 最坏 `O(n)` | 退化成一条链时递归深度为 `n` |

**性质**：

- 对连通图调用一次 `DFS` 得到一棵**深度优先生成树**；对非连通图得到**深度优先生成森林**。
- `DFS` 序列**不唯一**（取决于邻接表中邻接点的顺序，也取决于起点）。
- 由 `DFS` 生成的生成树**不唯一**。

> **408 怎么考 / 常见坑**：① 复杂度必须**分存储结构**答，写「`O(n+e)`」而不提邻接表会丢分；② 给定邻接表，让你写出从某点出发的 `DFS` 序列 —— 这类题必须**严格按邻接表中链表的顺序**走，不能自己挑邻接点；③ 用栈实现 `DFS` 时记得「回退」这一步。

#### 2. 广度优先搜索（`BFS`）

**思想**：类似于树的层序遍历。从顶点 `v` 出发，先访问 `v`，再依次访问 `v` 的所有未访问邻接点，然后按「先被访问的顶点其邻接点先被访问」的次序继续 —— 用**队列**保证层次顺序。

**实现**：

```c
void BFS(ALGraph G, int v) {
    int q[MAXV], front = 0, rear = 0;
    visited[v] = 1; visit(v);
    q[rear++] = v;                                // 入队
    while (front != rear) {
        int x = q[front++];                       // 出队
        for (ArcNode *p = G.vertices[x].first; p; p = p->next) {
            int w = p->adjvex;
            if (!visited[w]) {                    // 未访问才入队
                visited[w] = 1;                   // 入队时就标记，防止重复入队
                visit(w);
                q[rear++] = w;
            }
        }
    }
}
```

**复杂度**：与 `DFS` 相同 —— 邻接矩阵 `O(n^2)`，邻接表 `O(n+e)`；队列空间最坏 `O(n)`。

**重要应用：求无权图单源最短路径**。`BFS` 的层次特性使得：顶点 `w` 第一次被访问时所在的层数，就是从起点 `v` 到 `w` 的**最短路径长度**（边数最少）。只需在入队时把距离记为「前驱距离 + 1」：

```c
int dist[MAXV];                        // dist[w] = 从 v 到 w 的最少边数
for (int i = 0; i < G.n; i++) dist[i] = -1;
dist[v] = 0; q[rear++] = v; visited[v] = 1;
while (front != rear) {
    int x = q[front++];
    for (ArcNode *p = G.vertices[x].first; p; p = p->next)
        if (dist[p->adjvex] == -1) {          // 等价于未访问
            dist[p->adjvex] = dist[x] + 1;
            q[rear++] = p->adjvex;
        }
}
```

**性质**：

- 由 `BFS` 得到**广度优先生成树**（连通图）或**广度优先生成森林**（非连通图）。
- `BFS` 序列**不唯一**（邻接点顺序、起点都可变）。
- 层次分层：`BFS` 天然把顶点按「离起点的最短距离」分层。

> **408 怎么考 / 常见坑**：① 「无权图单源最短路径用 `BFS`，带权图必须用 `Dijkstra`」是常考点；② `BFS` 判重必须在**入队时**做，只在出队时判重会导致重复入队、复杂度退化；③ `BFS` 大题常考「按层次输出」「求最短路径并打印路径（用 `path[]` 记录前驱）」。

#### 3. `DFS` 与 `BFS` 对比

| 维度 | `DFS`（深度优先）| `BFS`（广度优先）|
| --- | --- | --- |
| 辅助数据结构 | **栈**（递归隐式栈或显式栈）| **队列** |
| 类比树的遍历 | 先根遍历 | 层序遍历 |
| 访问次序 | 一条路走到底再回退 | 由近及远，逐层扩散 |
| 时间复杂度（邻接矩阵）| `O(n^2)` | `O(n^2)` |
| 时间复杂度（邻接表）| `O(n+e)` | `O(n+e)` |
| 空间复杂度 | 最坏 `O(n)`（递归深度）| 最坏 `O(n)`（队列）|
| 典型应用 | 求连通分量数、判环、拓扑排序、求割点 | **无权图单源最短路径**、层次遍历、判二分图 |
| 生成树/森林 | 深度优先生成（森林）| 广度优先生成（森林）|
| 序列唯一性 | 不唯一 | 不唯一 |

> **408 怎么考 / 常见坑**：两者复杂度**相同**是常考陷阱（「`BFS` 比 `DFS` 快」是错的）。区别在**辅助结构**与**适用场景**：求无权最短路一定选 `BFS`。

### 6.4 图的基本应用

#### 1. 最小（代价）生成树（MST）

**问题**：在带权连通无向图（网）中，找一棵生成树，使**各边权值之和最小**。

**关于 MST 必须记住的三条性质**：

1. **MST 是生成树**：恰好 `n-1` 条边、含全部 `n` 个顶点。
2. **MST 可能不唯一**：当图中存在权值相同的边时，可能有多个不同的最小生成树。
3. **权值之和唯一**：无论哪棵 MST，边的权值总和**一定相同**。「生成树可能不唯一，但最小生成树的代价唯一」是高频判断句。

**贪心思想**：MST 算法都是贪心 —— 每一步选一条当前「最安全」的边（不会形成回路，且权值最小）。`Prim` 从**点集**角度贪，`Kruskal` 从**边集**角度贪。

##### `Prim` 算法（选点法，适合稠密图）

**思路**：从任一顶点出发，维护一个已并入生成树的顶点集合 `U`。每次从「一端在 `U` 中、另一端不在 `U` 中」的所有边里选**权值最小**的一条，把新顶点并入 `U`。重复 `n-1` 次。

**为什么正确**：这是 MST 的切割性质（cut property）—— 对任意一种把顶点分成两半的切割，横跨切割的最小权边一定属于某棵 MST。

**实现要点**：用 `lowcost[v]` 记录 `V-U` 中顶点 `v` 到 `U` 的最小边权，`closest[v]` 记录这条边在 `U` 中的端点。

| 项目 | 说明 |
| --- | --- |
| 时间复杂度 | `O(n^2)`，与边数无关 |
| 适合 | **稠密图**（`e` 接近 `n^2`）|
| 与边数关系 | 只依赖顶点数，边多也不变慢 |
| 不适用 | 不要求图连通；非连通图只能得到最小生成森林 |

> **408 怎么考 / 常见坑**：给邻接矩阵表格，让你写每一步选了哪条边、并入哪个顶点。坑点：① 起点不同得到的过程不同但**总权值相同**；② 有等权边时选哪条都算对；③ `O(n^2)` 与边无关，别写成 `O(e log e)`。

##### `Kruskal` 算法（选边法，适合稀疏图）

**思路**：把所有边按权值**从小到大排序**，依次考察每条边：若它的两个端点当前属于**不同的连通分量**，就选入生成树并把两个分量合并；否则（会成回路）丢弃。选够 `n-1` 条边即结束。

**为什么正确**：同属切割性质 —— 全局最小的边，其两端点间的切割上它最小，必属某棵 MST。

**实现要点**：用**并查集**（`Union-Find`）维护连通分量，`Find(x)` 判两个端点是否同集合，`Union(x,y)` 合并。判回路就是判「两点是否已在同一集合」。

| 项目 | 说明 |
| --- | --- |
| 时间复杂度 | `O(e log e)`，主要花在边排序上 |
| 适合 | **稀疏图**（`e` 远小于 `n^2`）|
| 关键辅助结构 | 并查集 + 排序 |
| 边的考察顺序 | 严格按权值升序；等权边顺序可变，但结果权值不变 |

> **408 怎么考 / 常见坑**：① 时间复杂度是 `O(e log e)`，考排序；② 「按边权排序」是 `Kruskal` 的招牌动作，别和 `Prim` 混；③ `Kruskal` 需要判断是否成环（并查集），`Prim` 天然不成环；④ 只适用于**无向连通图**。

##### `Prim` 与 `Kruskal` 对比

| 维度 | `Prim` | `Kruskal` |
| --- | --- | --- |
| 贪心角度 | 选**顶点**（扩展点集）| 选**边**（按权排序）|
| 时间复杂度 | `O(n^2)` | `O(e log e)` |
| 依赖量 | 只与**顶点数**有关 | 与**边数**有关（排序）|
| 适合图 | **稠密图** | **稀疏图** |
| 关键辅助结构 | `lowcost[]` / `closest[]` | 并查集 |
| 判环方式 | 不产生环（新顶点未在 `U` 中）| 并查集判两端点是否同集合 |
| 起点影响 | 有起点，过程随起点变化 | 从最小边开始，无起点概念 |
| 结果权值 | 唯一 | 唯一（树可能不唯一）|

> **408 怎么考 / 常见坑**：选择题最爱问「稠密图选哪个，稀疏图选哪个」。记忆口诀：**`Prim` 看点数，Kruskal 看边数；点密用 Prim，边稀用 Kruskal**。

#### 2. 最短路径

**问题分类**：

- **单源最短路径**：求一个源点到其余所有顶点的最短路径 —— `BFS`（无权）、`Dijkstra`（非负权）。
- **多源（每对顶点间）最短路径**：求任意两点间的最短路径 —— `Floyd`。

##### `BFS` 求无权图单源最短路径

无权图可以把每条边看成权值为 1，于是「最短路径」等价于「最少边数」。`BFS` 按层扩散，第一次到达某点即为最短。复杂度 `O(n+e)`（邻接表）。

> **408 怎么考 / 常见坑**：带权图**不能**用 `BFS` 求最短路（除非所有边权相同）。

##### `Dijkstra` 算法（单源，非负权）

**思路（贪心）**：维护已确定最短路径的顶点集合 `S`。每次从 `V-S` 中选**当前 `dist` 最小**的顶点 `u` 并入 `S`，然后用 `u` 去**松弛**（relax）它的邻接点：若 `dist[u] + w(u,v) < dist[v]`，则更新 `dist[v] = dist[u] + w(u,v)`，并记 `path[v] = u`。

**为什么要求「非负权」**：`Dijkstra` 的正确性建立在「一旦某顶点被选入 `S`，它的 `dist` 就是最终最短距离」之上。若存在负权边，后面可能通过一条负权边绕回来把已定型的距离变小，贪心前提被破坏。

**逐步表格法**（408 大题标准写法）：手算时画表，行是每一轮迭代，列是各顶点的 `dist` 和 `path`，被并入 `S` 的顶点加圈或标 `√`。

| 项目 | 说明 |
| --- | --- |
| 时间复杂度（邻接矩阵）| `O(n^2)` |
| 时间复杂度（邻接表 + 优先队列）| `O((n+e) log n)` |
| 适用 | 单源、**边权非负**的有向图或无向图 |
| 不适用 | **含负权边**的图 |
| 结果 | `dist[]` 数组 + `path[]` 前驱数组 |

> **408 怎么考 / 常见坑**：① 「`Dijkstra` 不能处理负权边」几乎年年以某种形式出现 —— 注意是**不能**，不是「可以但不优」；② 每轮选择的顶点顺序、`dist` 更新过程是采分点，要写清楚哪一轮选谁、松弛了谁；③ 手算时容易忘记「用新并入顶点松弛全部邻接点」，只更新了一部分；④ 求的是**单源**到所有点，不是两点间。

##### `Floyd` 算法（多源，允许负权，不允许负权回路）

**思路（动态规划）**：设 `A^(k)[i][j]` 表示「只允许经过编号 `1..k` 的顶点作为中间点」时，`i` 到 `j` 的最短路径长度。递推：

```
A^(k)[i][j] = min( A^(k-1)[i][j],  A^(k-1)[i][k] + A^(k-1)[k][j] )
```

初始 `A^(-1)` 就是邻接矩阵（`A[i][i] = 0`，无边为 `∞`）。经过 `n` 轮后，`A^(n-1)[i][j]` 即 `i` 到 `j` 的最短路径长度。

```c
void Floyd(int A[][MAXV], int n) {
    for (int k = 0; k < n; k++)            // 中间点 k 必须是最外层循环！
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (A[i][k] + A[k][j] < A[i][j])
                    A[i][j] = A[i][k] + A[k][j];
}
```

**为什么 `k` 必须在最外层**：`k` 是「阶段」。`A^(k)` 只能从 `A^(k-1)` 推出，把 `k` 放内层就等于在同一轮里混用了不同阶段的状态，结果可能不是最短。

| 项目 | 说明 |
| --- | --- |
| 时间复杂度 | `O(n^3)` |
| 空间复杂度 | `O(n^2)` |
| 适用 | **多源**（每对顶点）；**允许负权边** |
| 不适用 | **含负权回路**的图（会产生 `-∞`，无最短路）|
| 实现特点 | 三重循环，代码极短 |

> **408 怎么考 / 常见坑**：① 三重循环变量顺序（`k` 在最外）是经典考点；② `Floyd` 允许负权但**不允许负权回路**，注意与 `Dijkstra` 的区别；③ 每轮更新后要写出矩阵，是常见大题形态。

##### `Dijkstra` 与 `Floyd` 对比

| 维度 | `Dijkstra` | `Floyd` |
| --- | --- | --- |
| 求解问题 | **单源**到所有点 | **每对**顶点之间 |
| 算法思想 | 贪心 | 动态规划（插点法）|
| 时间复杂度 | `O(n^2)` | `O(n^3)` |
| 空间复杂度 | `O(n)` | `O(n^2)` |
| 负权边 | **不允许** | **允许** |
| 负权回路 | 不允许 | 不允许 |
| 核心语句 | 选最小 `dist` + 松弛 | `A[i][j] = min(A[i][j], A[i][k]+A[k][j])` |
| 输出 | `dist[]`、`path[]` | 距离矩阵 `A`、路径矩阵 `path` |

> **408 怎么考 / 常见坑**：记牢「**一个源 `Dijkstra`，所有源 `Floyd`；`Dijkstra` 怕负权，`Floyd` 怕负环**」。

#### 3. 拓扑排序

**背景 —— `AOV` 网**：用顶点表示活动的有向图（Activity On Vertex）。弧 `<i,j>` 表示「活动 `i` 必须先于活动 `j` 完成」。`AOV` 网中**不允许有回路**，否则说明活动互为前提，工程无法进行。

**拓扑排序的定义**：把 `AOV` 网的全部顶点排成一个线性序列，使得对图中任意一条弧 `<i,j>`，`i` 在序列中都排在 `j` 之前。

**算法（基于入度 + 队列）**：

1. 统计所有顶点的入度，把**入度为 0** 的顶点入队。
2. 出队一个顶点并输出；把它的所有直接后继的入度**减 1**。
3. 若某个后继入度变成 0，则入队。
4. 重复直到队空。若输出的顶点数 **小于 `n`**，说明图中**存在回路**（环）。

```c
int TopoSort(ALGraph G, int topo[]) {      // 返回 1 表示拓扑序列存在
    int indeg[MAXV] = {0}, q[MAXV], front = 0, rear = 0, cnt = 0;
    for (int v = 0; v < G.n; v++)          // 统计入度
        for (ArcNode *p = G.vertices[v].first; p; p = p->next)
            indeg[p->adjvex]++;
    for (int v = 0; v < G.n; v++)
        if (indeg[v] == 0) q[rear++] = v;  // 入度为 0 者入队
    while (front != rear) {
        int v = q[front++];
        topo[cnt++] = v;                   // 输出
        for (ArcNode *p = G.vertices[v].first; p; p = p->next)
            if (--indeg[p->adjvex] == 0)   // 后继入度减 1
                q[rear++] = p->adjvex;
    }
    return cnt == G.n;                     // 小于 n 则有环
}
```

**`DFS` 版本**：对图做 `DFS`，在**退栈前（后序位置）**把顶点压入栈；`DFS` 结束时从栈顶到栈底就是一个逆拓扑序列（`DFS` 完成时间越晚越靠前）。本质上就是「有向无环图的后序遍历逆序」。

**关键性质**：

- 拓扑序列**通常不唯一**。当某一时刻有**多个入度为 0** 的顶点时，它们之间的相对顺序任意。
- 拓扑序列**唯一**的充分条件：每一步都**恰好只有一个**入度为 0 的顶点（或者说，图中存在一条贯穿所有顶点的有向哈密顿路径）。这只是充分条件，不是必要条件。
- 拓扑排序可用于**判断有向图是否有环**：能排出全部 `n` 个顶点则无环（是 `DAG`），否则有环。

> **408 怎么考 / 常见坑**：① 给图求一个合法拓扑序列，或判断某序列是否合法 —— 判据是「序列中任意顶点，其所有前驱都排在它前面」；② 「拓扑序列唯一」是易错点，见对比表；③ 复杂度：邻接表 `O(n+e)`，邻接矩阵 `O(n^2)`；④ 用 `BFS`（队列）实现得到的是正向拓扑序，用 `DFS` 得到的是逆拓扑序；⑤ 只有 **`DAG`（有向无环图）**才有拓扑序列。

#### 4. 关键路径

**背景 —— `AOE` 网**：用**边**表示活动、用**顶点**表示事件的有向带权图（Activity On Edge）。权值表示活动持续时间。只有一个**源点**（入度为 0，开始事件）和一个**汇点**（出度为 0，结束事件）。

**要算的六个量**：

| 量 | 含义 |
| --- | --- |
| `ve(v)` | 事件 `v` 的**最早**发生时间 |
| `vl(v)` | 事件 `v` 的**最晚**发生时间（不推迟整个工期）|
| `e(a)` | 活动 `a` 的**最早**开始时间 |
| `l(a)` | 活动 `a` 的**最晚**开始时间 |
| `d(a) = l(a) - e(a)` | 活动 `a` 的**时间余量**（松弛时间）|
| 关键活动 | `d(a) = 0` 的活动，即 `l(a) = e(a)` |

**计算步骤（408 大题标准流程）**：

1. **正推求 `ve`**：按**拓扑序**，源点 `ve(源) = 0`；其余 `ve(v) = max{ ve(u) + w(u,v) }`，对所有入边 `<u,v>` 取最大。
2. **逆推求 `vl`**：按**逆拓扑序**，汇点 `vl(汇) = ve(汇)`（总工期）；其余 `vl(u) = min{ vl(v) - w(u,v) }`，对所有出边 `<u,v>` 取最小。
3. **求活动的最早开始 `e`**：若活动 `a` 对应弧 `<u,v>`，则 `e(a) = ve(u)`（弧尾事件的最早发生时间）。
4. **求活动的最晚开始 `l`**：`l(a) = vl(v) - w(u,v)`（弧头事件的最晚发生时间减去活动持续时间）。
5. **求时间余量**：`d(a) = l(a) - e(a)`。
6. **找关键活动**：所有 `d(a) = 0` 的活动；把它们连起来就是**关键路径**。

**关键性质（对应试必背）**：

- **关键路径 = 从源点到汇点的最长路径**，其长度就是完成整个工程的**最短工期**。
- **关键路径可能不唯一**。当有多条关键路径时，只缩短其中一条上的活动，总工期不一定缩短。
- **缩短关键活动不一定缩短总工期**：如果存在多条关键路径，或该活动被缩短后变成了非关键活动，总工期可能不变。要缩短总工期，必须**同时缩短所有关键路径**上的活动。
- 关键活动的时间余量一定为 0；时间余量为 0 的活动一定是关键活动。
- 关键路径上所有活动都是关键活动；关键活动一定在某条关键路径上。

> **408 怎么考 / 常见坑**：① `ve` 用 `max` 正推、`vl` 用 `min` 逆推，别搞反；② `e` 取**弧尾**的 `ve`，`l` 取**弧头**的 `vl` 减权 —— 这是最容易错的一步；③ 「关键路径唯一」错误，「总工期缩短」需要多路径同时缩短；④ 要按拓扑序/逆拓扑序计算，不能跳步。

## 四、例题精练（3 道）

### 例题 1（选择题）

**题目**：下列关于图的存储结构和基本性质的说法中，**正确**的是（　　）

A. 用邻接表存储无向图时，边结点的个数等于图中边的条数 `e`
B. 邻接矩阵存储的图，其邻接矩阵一定是沿主对角线对称的
C. 邻接多重表适用于无向图的存储，且每条边只用一个边结点表示
D. 有向图的邻接矩阵中，第 `i` 列非零元素的个数等于顶点 `i` 的出度

**答案**：C

**逐项解析**：

- **A 错**。无向图的每条边 `(i,j)` 要同时挂在 `i` 和 `j` 两条链上，所以边结点总数是 `2e`，不是 `e`。只有**有向图**的邻接表边结点数才等于弧数 `e`。这是王道课后原题级别的坑点。
- **B 错**。只有**无向图**的邻接矩阵才一定对称（因为 `(i,j)` 与 `(j,i)` 是同一条边）。有向图存的是弧 `<i,j>`，`edge[i][j]` 与 `edge[j][i]` 相互独立，一般不相等。选项用「一定」把无向图的结论推广到了所有图，因此错误。
- **C 对**。邻接多重表正是为无向图设计的：每个边结点含 `ivex`、`jvex`、`ilink`、`jlink`、`info`、`mark`，一条边只对应一个结点（而不是两个），便于对边做删除、标记等操作。这解决了邻接表存储无向图时「同一条边存两遍、操作要改两处」的问题。
- **D 错**。有向图邻接矩阵中，第 `i` **行**非零元素个数才是 `OD(i)`（出度），第 `i` **列**非零元素个数是 `ID(i)`（入度）。D 把行、列的含义说反了。

> **采分点与常见坑**：本题四个选项各对应一个高频易混点 —— 无向图边结点 `2e`、矩阵对称性只对无向图成立、邻接多重表只用于无向图、矩阵行=出度列=入度。考场上遇到「一定」「都」这类绝对化表述，先想反例。

### 例题 2（计算题）

**题目**：已知带权连通无向图 `G` 的顶点集 `V = {A, B, C, D, E, F}`，边及权值如下：

```
A-B: 6    A-C: 1    A-D: 5
B-C: 5    B-E: 3
C-D: 5    C-E: 6    C-F: 4
D-F: 2
E-F: 6
```

（1）用 **`Prim` 算法**（从顶点 `A` 出发）求最小生成树，写出每一步选择的边和并入的顶点，并给出最小生成树的边集与总权值。
（2）用 **`Kruskal` 算法**求最小生成树，写出选边的顺序，并给出总权值。
（3）以此例说明「最小生成树可能不唯一，但最小生成树的权值之和唯一」是否正确。

**解答**：

**（1）`Prim` 算法（起点 `A`）**

维护 `lowcost[]`：`V-U` 中各顶点到当前已选点集 `U` 的最小边权（`∞` 表示无边相连）。

初始：`U = {A}`，`lowcost = [B:6, C:1, D:5, E:∞, F:∞]`

| 轮次 | 当前 `U` | 各候选顶点的 `lowcost`（最小边）| 选中的边 | 并入顶点 |
| --- | --- | --- | --- | --- |
| 1 | `{A}` | `B:6(A)`, `C:1(A)`, `D:5(A)`, `E:∞`, `F:∞` | **A-C (1)** | `C` |
| 2 | `{A,C}` | `B:5(C)`, `D:5(A)`, `E:6(C)`, `F:4(C)` | **C-F (4)** | `F` |
| 3 | `{A,C,F}` | `B:5(C)`, `D:2(F)`, `E:6(C)` | **F-D (2)** | `D` |
| 4 | `{A,C,D,F}` | `B:5(C)`, `E:3(B→仍∞，E 只连 C、B、F)` | **B-C (5)** | `B` |
| 5 | `{A,B,C,D,F}` | `E:3(B)` | **B-E (3)** | `E` |

> 第 4 轮说明：`E` 的候选边只有 `C-E (6)`（因为此时 `B` 还不在 `U` 中），而 `B` 的候选是 `B-C (5)`，`5 < 6`，所以先并入 `B`。第 5 轮 `B` 并入后，`E` 的候选更新为 `B-E (3)`，小于 `C-E (6)`，选 `B-E`。

**最小生成树的边集**：`{A-C(1), C-F(4), F-D(2), B-C(5), B-E(3)}`
**总权值**：`1 + 4 + 2 + 5 + 3 = 15`
**验证**：6 个顶点对应 5 条边，符合生成树要求。

**（2）`Kruskal` 算法**

把所有边按权值升序排列：

```
A-C:1    D-F:2    B-E:3    C-F:4    A-D:5   B-C:5   C-D:5   A-B:6   C-E:6   E-F:6
```

依次考察，用并查集判是否成环：

| 顺序 | 边 | 权 | 两端点是否已连通 | 处理 |
| --- | --- | --- | --- | --- |
| 1 | `A-C` | 1 | 不同集合 | **选入**，合并 `{A,C}` |
| 2 | `D-F` | 2 | 不同集合 | **选入**，合并 `{D,F}` |
| 3 | `B-E` | 3 | 不同集合 | **选入**，合并 `{B,E}` |
| 4 | `C-F` | 4 | `{A,C}` 与 `{D,F}` 不同 | **选入**，合并 `{A,C,D,F}` |
| 5 | `A-D` | 5 | 同在 `{A,C,D,F}` | 丢弃（成环）|
| 6 | `B-C` | 5 | `{B,E}` 与 `{A,C,D,F}` 不同 | **选入**，合并为全体 |
| — | 已有 5 条边 | | | **结束** |

**选边顺序**：`A-C(1)`、`D-F(2)`、`B-E(3)`、`C-F(4)`、`B-C(5)`
**总权值**：`1 + 2 + 3 + 4 + 5 = 15`

**（3）结论**

本题中 `Prim` 与 `Kruskal` 得到的是**同一棵**生成树。但注意第 5 顺位有三条权值为 5 的边 `A-D`、`B-C`、`C-D`：`Kruskal` 只选了 `B-C` 就凑够了 5 条边；若中途换成先考察 `C-D`（同样权 5，同样不成环），得到的边集会不同，却仍是 5 条边、总权值仍是 15。此外，若从 `B` 或 `D` 出发运行 `Prim`，得到的过程和树也可能不同。

所以：**最小生成树可能不唯一（当存在等权边时），但最小生成树的权值之和一定唯一**。这句话正确。原因在于 MST 的总权值由图的切割性质决定，与算法的选择次序无关。

> **采分点与常见坑**：① `Prim` 必须写出「每轮选谁、松弛后各候选值怎么变」，只写最终边集会丢过程分；② `Kruskal` 必须体现「按权排序 + 判环」，展示被丢弃的边；③ 结论句要落到「树不唯一、权值和唯一」上，这是标准答案的固定表述。

### 例题 3（算法设计题）

**题目**：设有向图 `G` 采用**邻接表**存储（顶点数 `n`，边数 `e`）。请设计一个算法，**判断该有向图是否存在回路（环）**。要求：

（1）写出算法的基本思想；
（2）用 C 语言写出函数（可只写核心函数，不必写完整的输入输出）；
（3）分析时间复杂度和空间复杂度。

**（1）基本思想**

方法：**基于拓扑排序判环**（也可用 `DFS` 三色标记法）。

利用「有向图有拓扑序列 ⟺ 图中无环」这一结论。统计所有顶点的入度，把入度为 0 的顶点入队；每次出队一个顶点并计数，同时把它所有直接后继的入度减 1，减到 0 的后继入队。若最终**出队计数的顶点数等于 `n`**，说明所有顶点都能被拓扑排序，图中**无环**；否则**有环**。

直觉：环上的顶点入度永远降不到 0（环内总有一条边指着它），所以永远进不了队列，也就出不了队。

**（2）C 语言实现**

```c
#define MAXV 100

typedef struct ArcNode {
    int adjvex;                 // 弧头顶点下标
    struct ArcNode *next;       // 下一条弧
} ArcNode;

typedef struct VNode {
    char data;
    ArcNode *first;
} VNode, AdjList[MAXV];

typedef struct {
    AdjList vertices;
    int n, e;
} ALGraph;

/* 判断有向图是否有环：有环返回 1，无环返回 0 */
int HasCycle(ALGraph G) {
    int indeg[MAXV] = {0};
    int queue[MAXV], front = 0, rear = 0;
    int count = 0;                          // 已"拓扑输出"的顶点数
    int i;

    /* 1. 统计各顶点入度：遍历所有顶点的出边，给弧头累加 */
    for (i = 0; i < G.n; i++) {
        ArcNode *p = G.vertices[i].first;
        while (p != NULL) {
            indeg[p->adjvex]++;
            p = p->next;
        }
    }

    /* 2. 入度为 0 的顶点入队 */
    for (i = 0; i < G.n; i++)
        if (indeg[i] == 0)
            queue[rear++] = i;

    /* 3. 反复出队，并把后继入度减 1 */
    while (front != rear) {
        int v = queue[front++];
        count++;                            // 该顶点被"拓扑输出"
        ArcNode *p = G.vertices[v].first;
        while (p != NULL) {
            if (--indeg[p->adjvex] == 0)    // 后继入度减 1，减到 0 则入队
                queue[rear++] = p->adjvex;
            p = p->next;
        }
    }

    /* 4. 输出的顶点数不足 n，说明有顶点留在环上 */
    return (count < G.n) ? 1 : 0;
}
```

**替代解法（`DFS` 三色标记法，也可得分）**：用 `color[]` 标记 —— `0` 未访问、`1` 正在当前递归栈中、`2` 已完成。对顶点 `u` 的所有邻接点 `v`：若 `color[v] == 1`，说明遇到了一条指向「祖先」的边（回边），**存在环**；若 `color[v] == 0` 则递归访问。若都无回边则无环。这个版本同样需要处理非连通图（对每个未访问顶点各启动一次 `DFS`）。

**（3）复杂度分析**

- **时间复杂度**：`O(n + e)`。统计入度要遍历全部边结点，`O(e)`；初始化入度为 0 的顶点，`O(n)`；拓扑过程中每个顶点恰好出队一次、每条弧恰好被检查一次，`O(n + e)`。若用**邻接矩阵**存储，则每条边的检查变成扫描整行，复杂度退化为 `O(n^2)`。
- **空间复杂度**：`O(n)`。`indeg[]` 与 `queue[]` 各占 `O(n)`，辅助指针为常数级。（`DFS` 三色版本的空间为递归栈 `O(n)`。）

> **采分点与常见坑**：① 判环的**依据**必须写清楚（「有环 ⟺ 无拓扑序列」），只写代码不写思想会扣分；② 必须**显式处理非连通图** —— 拓扑法天然覆盖全图，但 `DFS` 法必须在外层再套一个循环遍历所有未访问顶点，这是最常见的失分点；③ 复杂度要写邻接表下的 `O(n+e)`；④ 注意题目给的是**有向图**；无向图判环用并查集或 `DFS` 判「是否访问到已访问的非父结点」，思路不同。

## 六、简便方法与易错口诀（速算 · 防错）

> 本节把本章能"省时间"和"防掉坑"的招集中在一处：二轮复习与考前只看这一节。每条都写清**适用条件**。

### 6.1 速算招式

| 场景 | 常规做法（慢/繁） | 简便做法（快/稳） | 为什么成立 / 适用条件 |
| --- | --- | --- | --- |
| 求边数、由度序列反推边数 | 对着图一条条数边 | 无向图 `ΣTD = 2e`；有向图 `ΣID = ΣOD = e`。度数总和除以 2 就是无向图边数 | 每条无向边给两个端点各贡献 1 度，`2e` 是"数了两遍"；每条弧恰好贡献一个出度和一个入度。**适用条件**：简单图（无自环）；度数和必须是偶数，否则题目数据有误 |
| 完全图边数 | 画图数边 | 无向完全图 `n(n-1)/2` 条；有向完全图 `n(n-1)` 条 | 从 `n` 个点里无序选 2 个是 `C(n,2) = n(n-1)/2`；有向图每对点再加一条反向弧，乘 2 |
| 由边数直接判连通 / 判环 | 逐个连通分量搜 | 无向简单图：`e ≥ n` ⟹ **必有环**；`e ≤ n-2` ⟹ 必不连通；`e ≥ (n-1)(n-2)/2 + 1` ⟹ **必连通** | 极值来自两个最省边的结构：无环图最多 `n-1` 条边（树），不连通图最多把 `n-1` 个点凑成完全图 |
| 生成树 / 生成森林边数 | 先画出树再数 | 连通图生成树恰 `n-1` 条边，要删掉 `e-(n-1)` 条；非连通图有 `k` 个连通分量，生成森林恰 `n-k` 条边 | 树是"最小的连通无环图"。**订正提示**：删 `e-(n-1)` 条**必须删得让图仍然连通**（等价于每个基本回路各删一条），随便删够条数可能把图删断；非连通图要删的是 `e-(n-k)` 条 |
| 数两点间路径条数 | 画图逐条枚举 | 算出 `A^k`，`A^k[i][j]` 就是从 `i` 到 `j` 长度恰为 `k` 的**通路条数** | 矩阵乘法定义恰好是"长度 `k-1` 的通路再接一条边"。**适用条件**：数的是允许重复经过顶点和边的通路，不是简单路径；要判可达就把 `A` 到 `A^n` 累加，看对应位置是否非零 |
| 邻接表边结点数、矩阵求度 | 凭印象写 | 邻接表：无向图共 `2e` 个边结点，有向图共 `e` 个；邻接矩阵：第 `i` 行非零数 = 出度，第 `j` 列非零数 = 入度 | 无向图一条边要挂在两个表头上；矩阵的行对应"从 `i` 出发"，列对应"进入 `j`" |
| 存储结构选型 | 两个都背一遍 | 稠密图（`e` 接近 `n^2`）用**邻接矩阵**；稀疏图（王道经验线 `e < n log n`）用**邻接表**；频繁求有向图入度用**十字链表**；无向图要删边用**邻接多重表** | 矩阵空间 `O(n^2)` 只与点数有关，表空间 `O(n+e)` 只与边数有关 |
| 最小生成树的算法选型 | 两种都手推一遍 | 稠密图选 `Prim`（`O(n^2)`，**与边数无关**）；稀疏图选 `Kruskal`（`O(e log e)`，靠**并查集**判环） | `Prim` 每轮扫 `lowcost[]` 是 `O(n)`，共 `n` 轮；`Kruskal` 的瓶颈是排序 `O(e log e)`，选够 `n-1` 条边即可提前结束 |
| 手推 `Dijkstra` | 凭记忆试凑 | 列表格：每轮"从未确定的点里选 `dist` 最小的**确定**它 → 用它**松弛**邻居 → 抄写整行"。已确定的点不再参与比较，也不再被修改 | 贪心正确性依赖非负权：一旦确定就不可能有更短的路。**适用条件**：边权全部非负；有负权边必须换算法 |
| 手推 `Floyd` | 直接照着背代码 | 三重循环 **`k` 放最外层**，`D[i][j] = min(D[i][j], D[i][k] + D[k][j])`；`D` 初值取邻接矩阵（无边为 ∞，自己为 0） | `k` 表示"允许中转的顶点编号 ≤ k"，是阶段变量必须在外层；放到内层会把同阶段的中间结果当下一阶段用，答案会错 |
| 判有向图是否有环 | 在图上满图找环 | 反复"输出入度为 0 的顶点并删掉它的出边"，**输出顶点数 < n ⟺ 有环**；或 `DFS` 三色标记，遇到灰点（回边）即有环 | 环上顶点的入度永远降不到 0。`DFS` 三色法**必须**对每个未访问顶点各启动一次，否则非连通图会漏判 |
| 关键路径手算 | 把每条路径都试一遍 | 正推 `ve` 取 `max`，逆推 `vl` 取 `min`；活动 `<i,j>` 有 `e = ve(i)`、`l = vl(j) - w`，`l - e = 0` 即关键活动，串起来就是关键路径 | `ve` 是所有前驱都必须完成的最早时刻（取大）；`vl` 是不能拖累后继的最晚时刻（取小）。**注意**：关键路径可能不唯一，此时只压一条并不缩短工期 |
| `BFS` 求无权图最短路 | 用 `Dijkstra` 表格法硬算 | `BFS` 中顶点第一次被访问时的层次就是单源最短距离 | 队列保证按距离非递减出队。**适用条件**：无权图，或各边权都相等的图；带不同权就必须换 `Dijkstra` |

### 6.2 口诀与记忆钩子

- **握手定理**：「无向握手**两倍边**，有向进出**各自都是边**」——`ΣTD = 2e`，`ΣID = ΣOD = e`。
- **完全图**：「**组合选二**是无向，**方向翻倍**是有向」——`n(n-1)/2` 与 `n(n-1)`。
- **树与森林**：「**连通树 `n-1`，删边 `e-n+1`；分量有 `k` 个，森林 `n-k` 条**」。
- **存储选型**：「**稠密矩阵、稀疏表；入度难求上十字，无向删边用多重**」。
- **最小生成树选型**：「**点多边密用 `Prim`，边少权杂用 `Kruskal`**」。
- **`Floyd`**：「**`k` 站门外管中转，`i` `j` 随便排**」——`k` 必须最外层。
- **`Dijkstra`**：「**选最小、定下来、松邻居、抄全行**」，再补一句「**负权不碰 `Dijkstra`**」。
- **拓扑判环**：「**入度为零就出队，出不完就是有环**」——输出顶点数 `< n` 即有环。
- **关键路径**：「**正推取大得 `ve`，逆推取小得 `vl`；`e` 用起点 `ve`，`l` 用终点 `vl` 减权，余量归零是关键**」；再加一句「**关键路径未必独一份，压一条不一定省工期**」。

### 6.3 反例黑名单（这些"简便法"是错的）

- ❌ 「无向图所有顶点度数之和等于边数 `e`」：正确做法是 `ΣTD = 2e`（度数是被数了两遍的），只有**有向图**才有点度数与边数相等，且要分成 `ΣID = ΣOD = e`。
- ❌ 「`n` 个顶点 `e` 条边，删掉 `e-(n-1)` 条边就一定得到生成树」：正确做法是这条只对**连通图**成立，而且删的边必须保证剩下的图仍连通（每个基本回路各删一条）；非连通图要删 `e-(n-k)` 条才得到生成森林。
- ❌ 「`Floyd` 的三重循环 `i`、`j`、`k` 随便排，结果都一样」：正确做法是 **`k` 必须放最外层**，因为 `k` 表达"允许中转的点集"这一阶段；放内层会用同一阶段的中间结果去更新，答案错误——这是改错题的高频陷阱。
- ❌ 「`Dijkstra` 只是不能判负环，加个判断就能处理负权边」：正确做法是有负权边就**必须换算法**（如 `Bellman-Ford`），`Dijkstra` 的贪心把已确定的点"锁死"，负权会破坏这个前提。
- ❌ 「`A^k[i][j]` 数的是 `i` 到 `j` 的**简单路径**条数」：正确做法是它数的是长度恰为 `k` 的**通路条数**，允许重复经过顶点和边；要数简单路径只能枚举或回溯。
- ❌ 「从任意一个顶点出发跑一遍 `DFS` 就能判断有向图有没有环」：正确做法是**对每个未访问过的顶点各启动一次 `DFS`**（配三色标记），否则非连通图会漏判。
- ❌ 「`n` 个顶点 `e` 条边，只要 `e ≥ n-1` 就一定连通」：反例是"一个三角形加一个孤立点"（`n = 4`、`e = 3 = n-1`）却不连通；必连通的正判据是 `e ≥ (n-1)(n-2)/2 + 1`。
- ❌ 「缩短任意一条关键活动就能缩短总工期」：正确做法是当**关键路径不唯一**时，只压其中一条并不缩短总工期，必须把所有关键路径共同覆盖的活动一起压才有效。
