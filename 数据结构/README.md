## 0. 这套笔记怎么用

1. 一章一份，文件名 `01-` ~ `08-`，顺序就是王道书的章序。
2. 每份结构固定：**知识框架 → 概念详解 → 易混对比表 → 例题精练（3 道）→ 自测清单**。
3. 用法：先看骨架 → 读概念 → **合上书做例题** → 看「采分点与常见坑」→ 用「自测清单」打勾。
4. VS Code 按 `Ctrl+Shift+V` 预览。公式一律写成**纯文本/行内代码**（如 `ASL = Σ pi × ci`），**故意不用 LaTeX**；算法代码用 ```c 代码块。
5. 只写「大纲要求 + 王道书讲到的」；超纲或大纲已删除的内容会标注。

## 1. 数据结构在 408 里的位置

| 项目 | 内容 |
| --- | --- |
| 分值 | **45 分**（与计组并列最高） |
| 题量 | 约 11 题：8~10 道单选（每题 2 分）+ **2 道综合应用题**（合计约 23 分） |
| 大题形态 | 一道通常是**算法设计题**（用 C/C++ 写出函数，并说明思路、给出时间复杂度与空间复杂度），另一道是树/图/查找/排序的计算或应用题 |

**这门课的性格**：选择题靠理解，大题靠模板。算法设计题是 408 里**唯一能靠背模板稳拿分**的大题，但阅卷看「关键步骤」，所以模板要背到能默写。

**八大高频算法设计模板**（按章散落在各笔记的例题里，建议单独誊抄成一张纸）：

1. 单链表就地逆置 / 头插法重建
2. 链表找倒数第 `k` 个结点 / 找中间结点（快慢指针）
3. 顺序表或链表删除某类元素（双指针原地删除）
4. 二叉树求高度 / 求 `WPL` / 判完全二叉树（层序遍历）
5. 二叉树求最近公共祖先 / 输出某层结点
6. 图：邻接表上的 `DFS`/`BFS`、判断有向图是否有环
7. 查找：判断是否为 `BST` / 求 `BST` 中第 `k` 小
8. 排序：一趟划分（快排 `Partition`）、堆的调整 `SiftDown`、归并思想求逆序对
