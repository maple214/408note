## 一、本章知识框架

这一章在 408 里干一件事：**把"数"变成"电路能处理的 01 序列"，再把这套 01 序列的运算规则全讲完。**

整章逻辑链：

1. **数制与编码**：现实中写的是十进制，机器里只有二进制 → 怎么互相转换（数制转换）→ 正负号怎么塞进去（原/反/补/移码）。
2. **运算方法和运算电路**：机器只会做加法 → 减法、乘、除全都要"变成加法"→ 加法器、`ALU`、标志位、乘除电路。
3. **整数的表示和运算**：把上面的规则具体到"无符号"和"带符号"两类数上，核心是**溢出判断**。
4. **浮点数的表示和运算**：小数怎么表示（`IEEE 754`）→ 两个浮点数怎么相加（对阶、尾数运算、规格化、舍入、溢出判断）。

一句话记忆：**定点整数靠补码把减法变加法，浮点数靠"阶码 + 尾数"把范围和小数精度分开管。**

## 二、概念详解

### 2.1 进位计数制及其相互转换

**是什么/为什么**：`r` 进制数每一位的权重是 `r` 的幂，写成通式：

`(N)r = Σ di × r^i`（i 从高位到低位，小数点左边从 0 开始递增，右边从 -1 开始递减）

比如 `(1101.01)2 = 1×8 + 1×4 + 0×2 + 1×1 + 0×0.5 + 1×0.25 = 13.25`。

**关键点**：

- **任意进制 → 十进制**：按权展开求和，最稳的方法，不会错。
- **十进制整数 → `r` 进制**：**除 `r` 取余，逆序读**（短除法）。因为要不断剥离最低位。
- **十进制小数 → `r` 进制**：**乘 `r` 取整，顺序读**。因为要不断把最低位移到整数位。注意：**可能出现无限循环，需要按精度截断**，这是选择题最爱设的坑。
- **二 ↔ 八 ↔ 十六：位组法（分组法）**，不用算除法。
  - 八进制 = 3 位二进制一组，十六进制 = 4 位二进制一组。
  - **以小数点为界，向两边分组，不足的位补 0**。整数部分在**最高位左边补 0**，小数部分在**最低位右边补 0**。
  - 例：`(1011011.1011)2` → 十六进制：整数补成 `0101 1011` = `5B`，小数补成 `1011` = `B`，得 `5B.B`。
  - 例：`(36.25)10 = (100100.01)2` → 八进制：整数 `100 100` = `44`，小数 `010` = `2`，得 `44.2`。

**408 怎么考/常见坑**：

- 最爱考"十进制小数转二进制"的过程本身，让你写出转换步骤或判断第几位是 1。
- 补 0 补错边是最高频错误：`0.1` 二进制是 `0.0001100110011...`，八进制分组时小数部分要**向右补 0**。
- 十六进制前缀 `0x`、后缀 `H`；二进制后缀 `B`、八进制后缀 `O`（或 `Q`）；十进制 `D`。408 题干里常混用，别被符号绕晕。
- 十六进制一位 = 4 位二进制 = 1 个"半字节"（nibble），八进制一位 = 3 位；**八进制和十六进制之间不要直接换算，先回二进制**。

### 2.2 定点数的编码表示（原码、反码、补码、移码）

**为什么需要**：机器里只有 0/1，没有"负号"。所以要专门拿一位当符号位（约定 `0` 表示正、`1` 表示负），并且要让**减法能用加法电路完成**，于是有了下面四种编码。设字长为 `n` 位，其中 1 位符号位，`n-1` 位数值位。

**（1）原码（`[X]原`）**：符号位 + 绝对值的二进制。

- 例：`X = +13`，8 位 → `0000 1101`；`X = -13` → `1000 1101`。
- **0 有两种表示**：`+0 = 0000 0000`，`-0 = 1000 0000`。
- 表示范围（`n` 位）：`-(2^(n-1) - 1) ~ +(2^(n-1) - 1)`。
- 缺点：加减法要判符号、比大小、选做加法还是减法，电路复杂。

**（2）反码（`[X]反`）**：正数同原码；负数 = **原码符号位不变，数值位按位取反**。

- 例：`-13` 的反码 = `1111 0010`。
- **0 也有两种表示**：`0000 0000` 和 `1111 1111`。
- 反码是"原码转补码"的中间桥梁，本质上是**模 `2^n - 1` 的运算**。

**（3）补码（`[X]补`）—— 本章绝对核心**：

- 正数同原码；负数 = **反码末位加 1**，即 `补码 = 反码 + 1`。
- 更快的做法：**从右往左找到第一个 1，这个 1 及其右边的 0 全保持不变，左边的数值位全部取反**（符号位保持 1）。
- 例：`X = -13`，原码 `1000 1101` → 反码 `1111 0010` → 补码 `1111 0011`。用速算法验算：`1000 1101` 从右数第一个 1 是末位，左边数值位 `000 110` 取反成 `111 001`，加上保留的 `1`，得 `1111 0011`，一致。

**用"模运算"直观理解补码（重点，务必读懂）**：

- 把编码看成一个**钟表**：`n` 位二进制一共只有 `2^n` 个状态，转一圈回到原点，所以一切运算都是**模 `2^n`** 意义下的运算。
- 在这个钟面上，`-13` 和 `2^n - 13` 是**同一个位置**。8 位时 `2^8 - 13 = 256 - 13 = 243 = 1111 0011`，正好就是 `-13` 的补码。
- 所以补码的数学定义是：`[X]补 = X + 2^n`（当 `X < 0` 时）；这就是"**补码 = 模 - |X|**"。
- 为什么减法能变加法：`A - B = A + (2^n - B) = A + [B]补`（在模 `2^n` 下），**最高位溢出的那一位进位直接丢掉**，结果天然正确。这就是"**减法电路 = 加法电路 + 求补电路**"的根本原因。
- 推论：`X` 的补码再求一次补码就回到 `X`（求补是自逆运算）；`-X` 的补码 = 把 `[X]补` **连同符号位一起全部取反再加 1**（注意：这个"连同符号位"和"原码转补码"的规则不一样，极易混）。

**（4）移码（增码）**：`[X]移 = X + 偏置值`，通常 `偏置值 = 2^(n-1)`。

- **移码和补码的关系：符号位相反，数值位完全相同**。也就是说 `[X]移` 就是把 `[X]补` 的符号位取反（这是 8 位、偏置 `2^(n-1)` 时的结论）。
- 例：`-13` 的补码 `1111 0011` → 移码 `0111 0011`；`+13` 的补码 `0000 1101` → 移码 `1000 1101`。
- **移码的作用**：把有符号数映射成"**无符号数大小顺序不变**"的形式，这样**比较大小可以直接按无符号数比较**，硬件实现"比大小"极简单。这是它被用在**浮点数阶码**上的唯一原因。
- **移码的 0 表示唯一**：`1000 0000`。
- 移码表示范围：`-2^(n-1) ~ +(2^(n-1) - 1)`，注意**移码没有 `-0`**。

**补码的两条"特权"（必背）**：

1. **0 的表示唯一**（`0000 0000`），所以省下来的 `1000 0000` 被规定为 **`-2^(n-1)`**，使补码比原码/反码**多表示一个最小负数**。
2. 表示范围（`n` 位）：`-2^(n-1) ~ +(2^(n-1) - 1)`，**正负不对称**：负数比正数多一个。

**408 怎么考/常见坑**：

- 常考"已知 `[X]补` 求 `-X` 的补码"：**全部位（含符号位）取反加 1**；若只对数值位取反加 1 就错了（那是原码转补码）。
- 常考"`1000 0000` 作为补码是多少"：是 `-128`，**不是 `-0`**；作为原码才是 `-0`。
- 常考"哪个编码 0 唯一"：**补码和移码唯一**，原码和反码不唯一。
- 常考"补码表示的 `-1`"：8 位是 `1111 1111`（全 1），16 位是 16 个 1，**位数变了要跟着变**。
- 移码偏置值不是死记 `2^(n-1)`：`IEEE 754` 里偏置值是 `2^(n-1) - 1`（单精度 127），两个场景要分开记。

### 2.3 基本运算部件：加法器与 `ALU`

**为什么**：机器最基础的运算就是"两个 01 序列相加"。所有其他运算（减、乘、除）最终都归约成加法 + 移位，所以加法器是 CPU 运算部件的基石。

**（1）一位全加器 `FA`**

- 三个输入：`Ai`、`Bi`、低位进位 `Ci-1`；两个输出：本位和 `Si`、本位向高位的进位 `Ci`。
- `Si = Ai ⊕ Bi ⊕ Ci-1`（三个输入里 1 的个数为奇数时和为 1）
- `Ci = Ai·Bi + (Ai ⊕ Bi)·Ci-1`（"两个加数都是 1"或"有一个是 1 且低位有进位"就产生进位）
- 记忆点：`Si` 是三个量的异或；`Ci` 是"多数表决"逻辑。

**（2）串行进位（行波进位）加法器**

- 把 `n` 个 `FA` 串起来，低位进位接到高位。
- 优点：结构简单、器件少。缺点：**进位像波浪一样逐级传递，`n` 位加法要等 `n` 级进位延迟**，`n` 越大越慢。
- 这就是"**进位延迟是整个加法器速度瓶颈**"的由来。

**（3）并行进位（先行进位 / 超前进位）加法器 `CLA`**

- 思想：**不等低位进位，直接由 `Ai`、`Bi` 算出本位能否"产生进位"和能否"传递进位"**，从而让所有位的进位**同时（并行）**得到。
- 定义两个中间量：
  - `Gi = Ai·Bi`（进位生成函数，本位天生产生进位）
  - `Pi = Ai ⊕ Bi`（进位传递函数，本位能把低位进位传给高位）
- 于是 `Ci = Gi + Pi·Ci-1`，逐层展开：
  - `C1 = G1 + P1·C0`
  - `C2 = G2 + P2·G1 + P2·P1·C0`
  - `C3 = G3 + P3·G2 + P3·P2·G1 + P3·P2·P1·C0`
  - 可见**每个 `Ci` 都只与 `Gi`、`Pi` 和最低位 `C0` 有关，不再互相等待**，这就是"先行进位"。
- 优缺点刚好和串行相反：**速度快，但电路复杂、成本高**。实际 CPU 用**分组并行进位**（组内并行、组间串行或再并行）折中。

**（4）`ALU`（算术逻辑部件）**

- `ALU` 是**组合逻辑电路**，核心是一个多功能加法器：**既能做算术运算（加、减、加 1、减 1），又能做逻辑运算（与、或、非、异或）**。
- 靠一个**操作控制端**（多位功能选择码）来选择当前做哪种运算。
- 有**两个数据输入端**（`A`、`B`）和**一个结果输出端**（`F`）。
- 输出侧还附带**标志位**（`ZF`、`SF`、`CF`、`OF`）供程序判断。
- `ALU` **本身不存数据**，输入输出都是瞬时组合出来的；靠寄存器暂存操作数与结果。写微指令时若同一节拍既要读又要写同一寄存器会冲突，就是因为 `ALU` 无存储能力。

**408 怎么考/常见坑**：

- 考"串行进位 vs 并行进位"的速度/成本权衡，属于必背对比。
- 考 `Gi`、`Pi` 的含义，以及 `Ci` 展开式里 `C0` 的系数是 `P3·P2·P1` 这种细节。
- 考" `ALU` 是组合逻辑，不含寄存器/触发器"，常与"寄存器堆""移位器"混在一起设选项。
- 注意：`ALU` 通常**不做乘除**，乘除由专门的乘商寄存器 + 加法器循环迭代完成（或由乘法部件完成）。

### 2.4 加/减运算与标志位生成

**（1）补码加减法公式**

- `[A + B]补 = [A]补 + [B]补`
- `[A - B]补 = [A]补 + [-B]补`，而 `[-B]补` = `[B]补` **连同符号位一起取反加 1**。
- 实现：把减法器做成"加法器 + 一个异或门阵列"。当 `Sub = 1` 时，`B` 的每一位与 `Sub` 异或实现取反，同时 `Sub` 作为最低位进位 `C0 = 1` 完成"加 1"。**一个加法器同时充当加减法器。**
- **符号位和数值位一起参加运算，符号位产生的进位直接丢弃**（这是补码运算的规定，不是错误）。

**（2）四个标志位（`ZF`、`SF`、`CF`、`OF`）——必考**

| 标志 | 名称 | 含义 | 生成方式 |
| --- | --- | --- | --- |
| `ZF` | 零标志 | 结果是否为 0 | 结果各位全为 0 时 `ZF = 1` |
| `SF` | 符号标志 | 结果的符号 | 直接取结果的**最高位**：`SF = Fn-1` |
| `CF` | 进位/借位标志 | **无符号数**运算是否溢出 | 加法时 `CF = 最高位产生的进位 Cout`；减法时 `CF = Cout ⊕ 1`（即借位） |
| `OF` | 溢出标志 | **带符号数**运算是否溢出 | `OF = 最高位进位 Cn ⊕ 次高位进位 Cn-1` |

**为什么 `OF` 是"最高位进位 ⊕ 次高位进位"**：最高位是符号位。符号位不该被数值运算"带出"进位，也不该"吃进"一个不该有的进位。只有**这两次进位不一致**时，符号位才被错误改写，即发生溢出。等价判据：**两个同号数相加，结果变号 → 溢出**。

**为什么减法时 `CF = Cout ⊕ 1`**：减法 `A - B` 实际算的是 `A + (-B)`，加法器给出的 `Cout = 1` 表示"没有借位"，`Cout = 0` 才表示"发生了借位"。所以取反。记忆口诀：**`CF` 管无符号，`OF` 管有符号，两者互不相干**。

**（3）溢出的三种判断方法（都要会）**

1. **进位异或法**：`OF = Cn ⊕ Cn-1`（硬件自动生成，最常用）。
2. **双符号位法（变形补码）**：用两位符号位 `00`（正）/ `11`（负）参加运算。
   - 结果 `00` → 正数，无溢出；`11` → 负数，无溢出；
   - `01` → **正溢出**（上溢）；`10` → **负溢出**（下溢）。
   - 记忆：**两个符号位不同就是溢出，且最高位是"真实符号"**。
3. **同号相加变号法**：只有同号数相加/异号数相减才可能溢出；结果符号与操作数符号不一致即溢出。

**（4）移位运算**

- **算术移位**：用于带符号数，**符号位不变，只移数值位**。
  - 左移：末位补 0；**左移一位相当于 ×2**，若移出的位与新的符号位不同则溢出。
  - 右移：原码补 0，**补码左补符号位（正补 0、负补 1）**，反码负数补 1；**右移一位相当于 ÷2（向下取整）**。
  - 记忆：**补码右移补符号位**，这是与逻辑右移的核心区别。
- **逻辑移位**：用于无符号数，**所有位一起移，空位一律补 0**。
- **循环移位**：移出的位补到另一端。
  - **带进位循环（大循环）**：把 `CF` 一起拉进循环，`CF` 参与首尾相接。
  - **不带进位循环（小循环）**：只有数据位自己首尾相接，`CF` 不参与。

**408 怎么考/常见坑**：

- 最爱考"给两个数相加，问 `CF`、`OF` 各是多少"：**先把两个数列成二进制竖式，标出 `Cn` 和 `Cn-1`**，再套公式。别凭感觉。
- 坑：**`CF = 1` 不代表结果错**，只代表"按无符号数看溢出了"；`OF = 1` 才是按带符号数看错了。
- 坑：减法时 `CF` 是"借位标志"，`CF = 1` 表示**不够减、发生了借位**（借位标志和进位标志取值相反）。
- 坑：**补码算术右移补符号位，左移补 0，但符号位本身不动**；逻辑移位连符号位一起动。
- 坑：双符号位法里，`01` 是正溢、`10` 是负溢，别把顺序记反。
- 坑：**乘法不会溢出**这个说法错；结果位数不够照样溢出，408 会考"两个 `n` 位数相乘需要 `2n` 位保存才不丢精度"。

### 2.5 乘/除运算的基本原理与电路结构

**核心思想（一句话）**：**机器只会加法和移位，所以乘法 = 循环"加 + 左移"，除法 = 循环"减 + 左移"。**

**（1）原码一位乘法**

- 原码乘法：**符号位单独处理**（结果符号 = 两数符号异或），**数值位用无符号乘法**。
- 过程（`n` 位数值位）：每次取**乘数最低位**判断：
  - 该位为 1 → 部分积加被乘数；
  - 该位为 0 → 部分积加 0；
  - 然后**部分积和乘数一起逻辑右移一位**（`n` 次移位）。
- 需要 `n` 次加法 + `n` 次移位，得到 `2n` 位积。
- 关键部件：被乘数寄存器 `X`、部分积寄存器（累加器 `ACC`）、乘数寄存器 `MQ`、计数器 `Cx`。
- 为什么要"右移"而不是"左移"：把乘数逐位从低位"挤出去"，同时把部分积的低位逐位沉淀到 `MQ` 中，最后 `ACC + MQ` 拼起来正好是 `2n` 位积。

**（2）补码一位乘法（Booth 算法）**

- 动机：原码法要单独处理符号，来回转码麻烦。补码法让**符号位和数值位一起参加运算**。
- 判据（Booth 编码）：在乘数末尾**附加一位 `y(n+1) = 0`**，每次看**相邻两位 `yn yn+1`**：

| `yn yn+1` | 操作 |
| --- | --- |
| `00` | 部分积 +0 |
| `01` | 部分积 + `[X]补` |
| `10` | 部分积 + `[-X]补` |
| `11` | 部分积 +0 |

- 每一步之后**算术右移一位**（部分积、乘数、附加位一起移）。
- `n` 位乘数做 `n` 次，**最后一步不移位**（共 `n` 次加法、`n-1` 次移位，不同教材表述略有差异，按王道书的表走）。
- 优点：**符号位一起算，不用单独求积的符号**；且遇到连续的 0 或连续的 1 可以跳过运算，效率更高。

**（3）除法：恢复余数法**

- 思想：**先试探着减，减完看结果**。
  - `被除数/余数 - 除数`：结果 ≥ 0 → 商上 1，保留这个差；
  - 结果 < 0 → 商上 0，并且**把除数加回去恢复原来的余数**（这就是"恢复余数"名字的来源）。
- 之后 `余数左移一位` 继续下一位。
- 缺点：**上 0 时白做一次加法，步数不固定**，控制复杂、速度慢。

**（4）除法：加减交替法（不恢复余数法）**

- 优化：既然上 0 后立刻要把除数加回来，不如**不加回来，直接让下一步加除数**，等价效果。
- 规则（设余数为 `R`）：
  - `R ≥ 0` → 商上 1，下一步做 `R - 除数`；
  - `R < 0` → 商上 0，下一步做 `R + 除数`。
- 所以叫"**加减交替**"：**余数符号决定下次是加还是减**，步数固定（`n` 步），不需要恢复。实际机器多用这一种。
- 商的符号：**同号相除为正，异号相除为负**（余数符号跟随被除数）。

**（5）除法电路的基本结构**

- 核心部件：被除数/余数寄存器 `R`（也叫累加器）、除数寄存器 `X`、商寄存器 `MQ`、计数器 `Cx`。
- 每次循环：`R` 与 `X` 做加/减 → 结果符号（`R` 的最高位/符号位）决定商位 → `R` 与 `MQ` **联合左移一位**，把商位挤入 `MQ` 最低位。
- 可见除法电路 = **加法器 + 移位通路 + 商寄存器**，与乘法电路高度相似（乘法右移、除法左移）。

**408 怎么考/常见坑**：

- 常考"手写乘法/除法过程表"（给被乘数、乘数，写出每步的部分积、乘数、`MQ`），王道课后题风格。**务必按表格一步步来，别跳步**。
- 坑：原码乘法**符号位不参与运算**，先算出数值部分再补符号；补码乘法**符号位参与**。
- 坑：Booth 法判断的是 `yn yn+1` 这对**相邻位**，且 `yn` 是"当前最低位"、`yn+1` 是"附加位/刚移出的位"，顺序写反就全错。
- 坑：恢复余数法"商上 0 就要恢复余数"这一步不能省；加减交替法的规则与它相反（不恢复，直接交替加减）。
- 坑：**除法可能除不尽**，会产生余数；`n` 位除 `n` 位结果可能超出 `n` 位，需要判断"商的位数不够"的溢出。
- 大纲只要求"基本原理和电路基本结构"，**不必深挖时序细节和具体门电路连线**，把握"用加法与移位实现"的思想即可。

### 2.6 整数的表示和运算（无符号 / 带符号）

**（1）无符号整数**

- 全部 `n` 位都是数值位，没有符号位，表示范围 `0 ~ 2^n - 1`。
- 最小数 0（全 0），最大数全 1。
- 运算：按二进制直接加减，**只看 `CF` 判断是否超出范围**（`OF` 对无符号数无意义）。
- 用途：地址、长度、计数、ASCII 码等非负量。

**（2）带符号整数**

- 用补码表示（现代机器一律用补码），`n` 位范围 `-2^(n-1) ~ +2^(n-1) - 1`。
- 常用字长对照（必背）：

| 类型 | 位数 | 无符号范围 | 带符号（补码）范围 |
| --- | --- | --- | --- |
| `char` / 字节 | 8 | `0 ~ 255` | `-128 ~ +127` |
| `short` | 16 | `0 ~ 65535` | `-32768 ~ +32767` |
| `int` / 字 | 32 | `0 ~ 4294967295`（约 4.29×10^9） | `-2147483648 ~ +2147483647`（约 ±2.1×10^9） |

**（3）零扩展与符号扩展（必考）**

- **零扩展**：把短无符号数变长，**高位全部补 0**。例：8 位 `1111 1111`（255）→ 16 位 `0000 0000 1111 1111`。
- **符号扩展**：把短带符号数变长，**高位全部复制原符号位**。例：8 位 `1111 1111`（补码表示 -1）→ 16 位 `1111 1111 1111 1111`（还是 -1）。
- 为什么符号扩展要复制符号位：补码是模运算，要保持数值不变，高位必须与符号位一致，否则值就变了。

**（4）有无符号数的转换与"陷阱"（408 高频）**

- **同一串 01，按无符号还是按带符号解释，数值完全不同**。例：`1111 1111` 按无符号是 255，按补码是 -1。
- 比较运算要区分：**`int` 与 `unsigned` 混合比较时，`int` 会被隐式转成 `unsigned`**，于是 `-1 > 0u` 竟然成立（-1 被解释成 4294967295）。这是 C 语言经典坑，也是 408 爱考的点。
- 运算结果的判断：**同一条加法指令，判断"是否出错"要看程序把它当无符号还是当带符号用**：无符号看 `CF`，带符号看 `OF`。

**408 怎么考/常见坑**：

- 常考"给定 8/16/32 位补码，求对应的十进制真值"：**先看符号位**，为 1 时按 `-(2^n - 该编码的无符号值)` 算最稳。例：`1111 0011` → `-(256 - 243) = -13`。
- 常考"最大/最小整数 + 1 会变成什么"：`+127 + 1` 在 8 位带符号下变 `-128`（溢出），无符号下变 `128`（正常）。
- 坑：**补码最小负数的负数**无法表示：8 位里 `-(-128)` 仍是 `-128`，这是唯一的溢出特例。
- 坑：`0xFFFFFFFF` 到底是 -1 还是 4294967295，**取决于类型声明**，题干一定会给类型，别漏看。

### 2.7 浮点数的表示（`IEEE 754` 标准）

**为什么需要浮点数**：定点数无法同时兼顾"范围极大"和"精度很小"。浮点数用**科学计数法的二进制版**：把"数值大小（阶）"和"有效数字（尾数）"分开存，范围由阶码决定，精度由尾数位数决定。

**（1）一般格式**

`浮点数 = (-1)^S × M × r^E`

- `S`：符号位；`M`：尾数（决定精度）；`E`：阶码（决定范围）；`r`：阶码的基数（隐含，通常为 2）。

**（2）`IEEE 754` 单精度（32 位）与双精度（64 位）格式**

- 布局（从高位到低位）：**1 位符号 + 阶码 + 尾数**
- 32 位 = `1 符号位 + 8 阶码 + 23 尾数`
- 64 位 = `1 符号位 + 11 阶码 + 52 尾数`

| 参数 | 单精度（32 位） | 双精度（64 位） |
| --- | --- | --- |
| 符号位 `S` | 1 位 | 1 位 |
| 阶码位数 | 8 位 | 11 位 |
| 尾数位数 | 23 位 | 52 位 |
| 偏置值 | `2^(8-1) - 1 = 127` | `2^(11-1) - 1 = 1023` |
| 真阶 `E` 与阶码字段 `e` | `E = e - 127` | `E = e - 1023` |
| 阶码有效范围 | `1 ~ 254`（`E` 为 `-126 ~ +127`） | `1 ~ 2046`（`E` 为 `-1022 ~ +1023`） |
| 尾数有效精度 | 24 位（含隐藏位） | 53 位（含隐藏位） |

**（3）规格化与隐藏位（最关键的"为什么"）**

- 约定尾数写成 `1.xxxxx` 的形式（**规格化**），既然小数点前**必然是 1**，那就**不用存了**，省下一位精度 —— 这就是**隐藏位**。
- 所以单精度实际精度是 `23 + 1 = 24` 位，双精度是 `52 + 1 = 53` 位。
- **真值公式**（阶码字段 `e` 在 `1 ~ 254` 范围，即规格化数时）：
  - 单精度：`值 = (-1)^S × 1.M × 2^(e-127)`
  - 双精度：`值 = (-1)^S × 1.M × 2^(e-1023)`
- **为什么偏置值是 `127` 而不是 `128`**：希望阶码字段 `e` 的 `1 ~ 254` 能表示 `E = -126 ~ +127` 的范围内**两侧都留出全 0 和全 1 两个特殊编码**给 0/非规格化数/无穷/NaN，同时让"比较阶码大小"可以直接按无符号比较（移码的思想）。偏置取 `2^(n-1) - 1` 而不是 `2^(n-1)`，是为了让阶码的**正负范围大致对称**。

**（4）特殊值的约定（必背表）**

| 阶码字段 `e` | 尾数 `M` | 含义 |
| --- | --- | --- |
| 全 0 | 全 0 | `±0`（`S` 决定正负零） |
| 全 0 | 非 0 | **非规格化数**（`±0.M × 2^(-126)`），用于表示比最小规格化数还小的数 |
| `1 ~ 254` | 任意 | 规格化数（正常浮点数） |
| 全 1 | 全 0 | `±∞`（`S` 决定正负无穷） |
| 全 1 | 非 0 | **`NaN`**（非数，Not a Number） |

- 注意：**非规格化数的隐含位是 0**（不是 1），阶码固定按 `-126`（单精度）解释，这样才能从最小规格化数**平滑过渡到 0**，避免下溢时突然蹦到 0。
- `NaN` 的特点：**与任何数（包括自己）比较都不相等**，`NaN != NaN` 为真。
- `±0` 有两位编码但数学上相等；`+0` 全 0，`-0` 最高位为 1。

**（5）十进制与 `IEEE 754` 的互相转换（综合题核心）**

**十进制 → `IEEE 754` 单精度的四步**：

1. 把十进制写成二进制（整数除 2 取余、小数乘 2 取整）。
2. **规格化成 `1.xxxx × 2^E`** 的形式，读出真阶 `E`。
3. `e = E + 127`，转成 8 位二进制。
4. 去掉小数点前的 `1`，把 `xxxx` 补足 23 位（不足右侧补 0），前面接符号位。

**`IEEE 754` → 十进制的三步**：

1. 拆出 `S`（1 位）、`e`（8 位）、`M`（23 位）。
2. 判断 `e` 是否为全 0 / 全 1（是则按特殊值表处理）。
3. 否则按 `值 = (-1)^S × 1.M × 2^(e-127)` 计算。

**408 怎么考/常见坑**：

- 常考"16 进制 IEEE 754 编码 ↔ 十进制"互转，写成 `0x41A00000` 这种形式，先展开成 32 位二进制再拆字段。
- 坑：**偏置值是 `2^(阶码位数-1) - 1`**，单精度 127、双精度 1023，别写成 128、1024。
- 坑：**隐藏位只有规格化数才有**；非规格化数隐含位是 0。
- 坑：`e` 的取值范围是 `1 ~ 254`（单精度），**全 0 和全 1 是特殊值专用**，不能拿来当普通阶码。所以单精度能表示的最大规格化数是 `(2 - 2^-23) × 2^127`，而不是 `× 2^128`。
- 坑：区分"**尾数位数**"（单精度 23）与"**有效精度**"（24，含隐藏位），考题专门设这种选项。
- 坑：`float` 不能精确表示所有十进制小数（如 0.1），因为二进制是有限位截断，所以浮点比较不能用 `==`。

### 2.8 浮点数的加/减运算（五步法，必背）

**为什么这么麻烦**：两个浮点数的阶码不一样，`1.1×2^3` 和 `1.0×2^1` 的尾数小数点位置不对齐，**不能直接把尾数相加**。所以必须先对齐小数点，再加减，再收拾结果。

**五步法**：

**第一步：对阶（求阶差、小阶向大阶看齐）**

- 求阶差 `ΔE = E被 - E除`（或被操作数 - 操作数）。
- **小阶的尾数向右移 `ΔE` 位，同时阶码加 `ΔE`**，直到两数阶码相等。
- **原则：小阶向大阶看齐**。为什么？如果反过来让大阶向小阶看齐，大阶数的尾数要**左移**，左移会**丢掉最高有效位**，误差极大；小阶数右移只丢低位，误差小。
- **尾数右移时符号位不动，移出的低位被舍去**（这是误差的主要来源）。
- 注意：右移可能把尾数全移没了（变成 0），此时该数当作 0 处理。

**第二步：尾数加减**

- 对阶完成后，**尾数按定点补码加减法**运算（含符号位），阶码保持不变。

**第三步：规格化**

- 尾数运算结果可能不是 `1.xxxx` 形式，要修正。**左规和右规方向相反，判断依据是尾数最高位的"溢出"**：
  - **左规**：结果尾数最高位不是有效位（如 `0.0xxx` 或 `1.1xxx` 的补码形式，即 `00.0...` / `11.1...`），需要**尾数左移、阶码减**，直到最高位是 `1`。**左移一次，阶码减 1**。左规可能做多次。
  - **右规**：尾数定点加减**溢出**（双符号位为 `01` 或 `10`），说明尾数绝对值 ≥ 2，需要**尾数右移一位、阶码加 1**。**右规最多一次**（因为两个规格化尾数相加，绝对值最多不到 4）。
- 记忆：**左规减阶、右规加阶**。

**第四步：舍入**

- 右规和右移对阶都会丢低位，需要按舍入规则补偿。常见三种：
  - **就近舍入（0 舍 1 入）**：移出的最高位为 1 就进 1。简单但可能带来偏差。
  - **恒置 1 法**：只要丢掉了位，就把结果末位**恒置为 1**。实现最简单。
  - **就近舍入到偶数（`IEEE 754` 默认）**：尾数移出部分"小于一半舍、大于一半入、**正好一半时向偶数舍入**（末位为 0 就不进，为 1 就进位）"，使误差无偏。
- 舍入可能再次造成溢出，**需要再判一次**。

**第五步：溢出判断**

- 判的是**阶码是否超出可表示范围**：
  - **阶码上溢**：结果阶码 > 最大阶码 → 溢出，按 `±∞` 处理（`IEEE 754` 中并不产生异常终止，标 `OF`）。
  - **阶码下溢**：结果阶码 < 最小阶码 → 当作 `0`（`IEEE 754` 中可以用非规格化数表示到更小）。
- **注意：尾数溢出不是浮点溢出**，右规一次就能修正；**只有阶码溢出才是真正的浮点溢出**。这是最爱考的辨析点。

**一条完整示例（帮助记忆顺序）**：
计算 `1.100 × 2^2 + 1.010 × 2^1`（阶码差 1）：

1. 对阶：小阶 `2^1` 的尾数右移 1 位得 `0.101 × 2^2`，两数阶码都是 `2`。
2. 尾数加：`1.100 + 0.101 = 10.001`。
3. 规格化：结果溢出（`10.001`），右规一位 → `1.0001 × 2^3`，阶码加 1 变 3。
4. 舍入：若尾数位宽只保留 3 位，`1.0001` 要舍入，按 0 舍 1 入得 `1.001 × 2^3`。
5. 溢出判断：阶码 `3` 在范围内，无溢出。

**408 怎么考/常见坑**：

- 大题常给两个数的 `IEEE 754` 编码，要求写出五步过程并给出结果编码，**步骤分很重，一定写清楚每一步**。
- 坑：**对阶一定是小阶向大阶看齐、尾数右移**，写反直接零分。
- 坑：**左规减阶、右规加阶**，方向记反是经典错误。
- 坑：对阶时**移出的位不要马上扔，要在舍入步骤一起考虑**（尤其"就近舍入到偶数"需要知道移出部分是"正好一半"还是大于/小于）。
- 坑：**浮点加减不满足结合律**（`(a+b)+c ≠ a+(b+c)`），因为中间结果会舍入丢精度。这也是"为什么浮点不能用 `==` 比较"的根本原因。
- 坑：题目问"结果是否溢出"时，**先看阶码**，不要看到尾数进位就喊溢出。

### 2.9 校验码（奇偶校验、海明码、`CRC`）（大纲未列条目，了解即可 / 二轮可略过）

> 说明：本章大纲条目只有"进位计数制及其转换""定点数的编码表示"两条，**校验码没有单列**。但王道书 2.1.3 有这一节，且它与第 3 章存储器、第 5 章总线关系密切，这里只讲清计算思路，**二轮可略过，冲刺阶段若时间紧优先放弃**。

**（1）奇偶校验**

- 思想：在数据后加 1 位校验位，使**整个码字中 1 的个数为奇数（奇校验）或偶数（偶校验）**。
- 计算：把所有数据位异或起来，得到的就是偶校验位（异或结果为"1 的个数是否为奇数"）。
- 能力：**只能检错，不能纠错**；且**只能发现奇数个位出错**，偶数个位同时出错检测不出来。
- 用在：内存读写的简单检错、串口通信。

**（2）海明码**

- 思想：用**多个校验位**构成多组奇偶校验，每组覆盖不同的数据位组合，**出错时哪几组校验失败就唯一确定了出错位置**，从而实现**纠一位错、检两位错**（`SEC-DED`）。
- 计算步骤（必须会算）：
  1. 确定校验位个数 `k`：满足 `2^k ≥ n + k + 1`（`n` 为数据位数）。例：`n = 8` 时 `k = 4`（因为 `2^4 = 16 ≥ 8 + 4 + 1 = 13`）。
  2. 校验位放在 **`2^0、2^1、2^2、...` 即第 1、2、4、8... 位**（海明码的位号从 1 开始）。
  3. 每组校验位负责**位号二进制表示中对应位为 1 的所有位置**的偶校验。例如 `P1`（第 1 位）负责所有位号最低位为 1 的位置（1、3、5、7、9、11...）；`P2` 负责次低位为 1 的位置（2、3、6、7、10、11...）。
  4. 接收端重新计算各组校验，把**失败组的编号相加**得到"指误字"，其值就是出错位的位号；为 0 则无错。**把出错位取反即完成纠错**。
- 海明码的码距为 3，能纠 1 位错；加一位总校验位后码距 4，能纠 1 位错并检 2 位错。

**（3）`CRC`（循环冗余校验）**

- 思想：把数据看成一个二进制多项式，**除以一个约定的生成多项式 `G(x)`，得到的余数就是校验位**。接收端用同样的除法验证余数是否为 0。
- 计算步骤：
  1. 生成多项式 `G(x)` 的阶为 `r`，则校验位有 `r` 位。
  2. **数据后面补 `r` 个 0**（相当于左移 `r` 位、乘 `x^r`）。
  3. 用**模 2 除法**（**减法即异或，不借位**）除以 `G(x)` 的系数序列，得到的 `r` 位余数就是 `CRC` 校验码。
  4. 把余数接到原数据后面，形成最终发送的码字。
- 能力：**检错能力强，实现用移位寄存器 + 异或门即可，硬件极简单**，广泛用于网络（以太网帧校验 `FCS`）和磁盘。
- 记忆点：**全程模 2 运算，加减都是异或**，没有进位借位。

**408 怎么考/常见坑**：

- 这一节**不在大纲条目里**，408 直接考的年份很少；若考，多为"海明码需要几位校验位""`CRC` 模 2 除法求余数"这类小计算。
- 坑：**海明码位号从 1 开始**，校验位放 `2` 的幂次位置，别从 0 开始排。
- 坑：`CRC` 里**每一步做的是异或，不是普通的减法**，写竖式时不要借位。
- 建议：一轮先读懂思想，若目标分数已经吃紧，**优先保证 2.1~2.8 全部掌握**。

## 四、例题精练（3 道）

> 说明：以下题目为**自编或按 408 风格改编**，不声称是历年真题，仅用于训练解题步骤与踩点。

### 例题 1（选择题，四选项 + 逐项解析）

**题目**：某机器字长为 8 位，用补码表示带符号整数。若 `X = -128`，则下列说法中**正确**的是（　　）

A. `X` 无法用 8 位补码表示，因为 8 位补码的最小值是 `-127`
B. `[X]补 = 1000 0000`，且 `[-X]补` 仍然是 `1000 0000`
C. `[X]补 = 1000 0000`，且 `[-X]补 = 0000 0000`
D. `[X]原 = 1000 0000`，`[X]补 = 1111 1111`

**逐项解析**：

- **A 错**：8 位补码的范围是 `-2^(8-1) ~ +(2^(8-1) - 1)`，即 `-128 ~ +127`。补码因为 0 的表示唯一，把省出来的编码 `1000 0000` 规定为 `-128`，**所以 `-128` 能表示**，最小值是 `-128` 而不是 `-127`。（`-127` 是原码和反码的最小值。）
- **B 对**：`-128` 怎么得到 `1000 0000`？可以这样推：`-128 = -127 - 1`，而 `-127` 的补码是 `1000 0001`，减 1 得 `1000 0000`，正好就是规定的 `-128`。另外也可以用"补码 = 模 - |X|"验证：`256 - 128 = 128 = 1000 0000`。而 `[-X]补 = [+128]补`，但 `+128` **超出 8 位补码上限 127**，发生了溢出，按"连同符号位取反加 1"的规则算：`1000 0000` 全部取反得 `0111 1111`，加 1 得 `1000 0000`，**结果又回到自己**。这正是"补码最小负数的相反数无法表示"这一特例（负溢出），所以 `[-X]补` 仍是 `1000 0000`，B 描述正确。
- **C 错**：`[-X]补 = 0000 0000` 意味着 `-X = 0`，即 `X = 0`，与 `X = -128` 矛盾。而且 `X` 与 `-X` 不可能同时对（模运算下 `2X ≡ 0 mod 256` 只有 `X = 0` 或 `X = 128 ≡ -128`，此处属于溢出特例）。
- **D 错**：原码的 `-128` 无法表示（8 位原码范围 `-127 ~ +127`，`1000 0000` 在原码里表示的是 `-0`）。所以 `[X]原` 这一说法本身不成立，后面的 `[X]补 = 1111 1111` 算出来是 `-1` 的补码。

**答案：B**

**采分点与常见坑**：

- **采分点**：能说出 8 位补码范围是 `-128 ~ +127`；能指出 `1000 0000` 在补码里是 `-128`（不是 `-0`）；能意识到 `-128` 的相反数不可表示。
- **常见坑**：把补码最小值写成 `-127`（错，那是原码/反码）；把 `1000 0000` 当成 `-0`（错，补码里 `-0` 不存在）；以为"取反加 1"一定得到相反数（对最小负数不成立）。

### 例题 2（计算题：十进制 ↔ `IEEE 754` 单精度互转）

**题目**：已知某浮点数采用 `IEEE 754` 单精度格式（32 位）。请回答：

（1）把十进制数 `-12.5` 转换为 `IEEE 754` 单精度编码（用十六进制表示）。

（2）已知某单精度浮点数的十六进制编码为 `0x41200000`，求它表示的十进制真值。

（3）该单精度格式能表示的最大正规格化数是多少（用带指数的形式表达即可）？为什么不是 `× 2^128`？

**解答（1）：`-12.5` → `IEEE 754`**

- **第一步，转二进制**：
  - 整数部分：`12 = 8 + 4 = 1100`（除 2 取余逆序读：12→6 余 0，6→3 余 0，3→1 余 1，1→0 余 1 → `1100`）。
  - 小数部分：`0.5 × 2 = 1.0`，取整得 `1`，小数为 0 停止 → `0.1`。
  - 合并：`12.5 = 1100.1`。
- **第二步，规格化**：`1100.1 = 1.1001 × 2^3`（小数点左移 3 位）。所以**真阶 `E = 3`**，尾数部分为 `1001`。
- **第三步，求阶码字段**：`e = E + 127 = 3 + 127 = 130`。`130 = 128 + 2 = 1000 0010`。
- **第四步，拼装**：
  - 符号位 `S = 1`（负数）。
  - 阶码 `1000 0010`。
  - 尾数：`1001` 后面补 0 补足 23 位 → `100 1000 0000 0000 0000 0000`。
- **拼接**：`1 10000010 10010000000000000000000`
- **转十六进制**（每 4 位一组）：`1100 0001 0100 1000 0000 0000 0000 0000`
  - `1100` = `C`，`0001` = `1`，`0100` = `4`，`1000` = `8`，其余为 0。
- **答案：`-12.5 = 0xC1480000`**

**解答（2）：`0x41200000` → 十进制**

- 展开为二进制：`0100 0001 0010 0000 0000 0000 0000 0000`
- 拆字段：
  - `S = 0` → 正数。
  - `e = 1000 0010` = 130。
  - `M = 010 0000 0000 0000 0000 0000`（23 位）。
- 阶码不全 0 也不全 1 → 规格化数，隐含位为 1。
- 真阶 `E = e - 127 = 130 - 127 = 3`。
- 尾数 = `1.010 0000...`（二进制）= `1.01`（后面都是 0）。
- `1.01 × 2^3 = 1010`（二进制，小数点右移 3 位）= `8 + 2 = 10`。
- **答案：`0x41200000` 表示十进制数 `10`。**

**解答（3）：最大正规格化数**

- 单精度阶码字段 `e` 有 8 位，有效范围是 `1 ~ 254`（全 0 和全 1 留给特殊值）。
- 所以最大真阶 `E = 254 - 127 = 127`。
- 尾数全 1 时最大：`1.111...1`（23 个 1）= `2 - 2^-23`。
- **最大正规格化数 = `(2 - 2^-23) × 2^127`**。
- **为什么不是 `× 2^128`**：`e = 255`（全 1）被约定用于表示 `±∞` 和 `NaN`，**不能作为普通阶码使用**，所以真阶最大只能到 127。

**采分点与常见坑**：

- **采分点**：① 正确把十进制转成二进制（整数除 2 取余、小数乘 2 取整）；② 规格化形式写对，读出正确的 `E`；③ 偏置值用 **127**（不是 128）；④ 尾数去掉隐含位 `1` 并**右补 0 补足 23 位**；⑤ 拼接顺序是"符号 + 阶码 + 尾数"，十六进制按 4 位分组。
- **常见坑**：
  - 偏置值写错（用 128 或 256），导致阶码整体错 1，全题崩。
  - **尾数左侧补 0**（应为右侧补 0，因为尾数高位在前）。
  - 忘记去掉隐含位 `1`，把 24 位塞进 23 位。
  - 十六进制分组时**从最高位开始每 4 位一组**，不要从中间随意切。
  - 第（3）问答成 `× 2^128`，忽略了全 1 阶码是特殊值的约定。

### 例题 3（综合题：浮点数加减五步，含 `CF`/`OF` 无关判读）

**题目**：设某浮点数格式为：**阶码 4 位（含 1 位阶符，用移码表示）、尾数 8 位（含 1 位尾符，用补码表示）**，阶码偏置值按该格式约定为 `2^(4-1) = 8`（即移码 = 真阶 + 8）。现有两个规格化浮点数：

`A = 0.1101 × 2^3`，`B = -0.1010 × 2^2`

（为方便书写，尾数用真值形式给出，中间保留足够位数。）请用**浮点加减五步法**计算 `A + B`，并写出：

（1）对阶后的两个操作数；

（2）尾数相加减的结果；

（3）规格化与舍入后的最终尾数与阶码；

（4）判断是否发生浮点溢出（说明理由）。

**解答**

**第一步：对阶**

- 求阶差：`ΔE = 3 - 2 = 1`。
- 规则：**小阶向大阶看齐**，所以把 `B` 的**尾数右移 1 位**，同时 `B` 的阶码加 1。
- `B = -0.1010 × 2^2` → 尾数 `-0.1010` 算术右移一位 → `-0.01010`（右移时符号位不变，低位保留以便舍入）；阶码 `2 + 1 = 3`。
- 对阶后：
  - `A = 0.1101 × 2^3`（`A` 是大阶，不动）
  - `B = -0.01010 × 2^3`
- **注意**：这里 `B` 的尾数右移时，原来最低位的 `0` 被移出，**这个移出位要保留着供后续舍入判断**，不能随手扔掉。

**第二步：尾数加减**

- 阶码统一为 `3`，尾数做补码加法：`0.1101 + (-0.01010)`。
- 为对齐位数（都取 5 位小数）：`A = 0.11010`，`B = -0.01010`。
- 相加：`0.11010 - 0.01010 = 0.10000`。
- 结果：`0.10000`，阶码仍为 `3`。

**第三步：规格化**

- 检查结果尾数 `0.10000`：最高有效位是 `0`（即不是 `0.1xxxx` 的规格化形式？这里要按格式约定判断）。
- 该格式要求规格化尾数形如 `0.1xxxx`（正数）或 `1.0xxxx`（负数），即**小数点后第一位必须与符号位不同**。
- `0.10000` 的小数点后第一位是 `1`，而符号位是 `0`，**两者不同，满足规格化要求**，所以**不需要左规**。
- 验证：`0.10000 = 0.1 × 2^0`（按二进制看，小数点后第一位是 1，已经是规格化形式）。
- 因此尾数为 `0.10000`，阶码仍为 `3`。

**第四步：舍入**

- 本格式尾数只有 8 位（含 1 位尾符），即可放 7 位数值位。
- 结果 `0.10000` 只有 5 位有效值，**没有产生被舍去的位**，因此**无需舍入，结果精确**。
- （若对阶时右移丢掉了非零低位，则需按"0 舍 1 入"或"就近舍入到偶数"处理，本题恰好未受影响。）

**第五步：溢出判断**

- 结果的阶码为真阶 `3`。该格式阶码 4 位用移码、偏置 8，可表示的真阶范围是 `-8 ~ +7`。
- `3` 在 `-8 ~ +7` 范围内 → **无阶码上溢/下溢**。
- 尾数 `0.10000` 也**没有溢出**（未出现 `1.xxxx` 这种绝对值 ≥ 1 的情况）。
- **结论：`A + B = 0.10000 × 2^3 = 0.1 × 2^3 = 100 (二进制) = 4 (十进制)`，结果无溢出。**
- 验算：`A = 0.1101 × 2^3 = 110.1 (二进制) = 6.5`；`B = -0.1010 × 2^2 = -10.10 (二进制) = -2.5`；`6.5 + (-2.5) = 4`，与结果一致 ✓。

**（如果改成 `A + 2.0` 的变式，会出现对阶后尾数相消、需要左规多次的情况，考试更爱考这种，练习时建议自己再算一遍 `A` 与 `-A` 附近值的相加。）**

**采分点与常见坑**：

- **采分点**：
  1. 能正确求出阶差 `ΔE = 1`，并**明确写出"小阶向大阶看齐、小阶尾数右移、阶码加 1"**；
  2. 尾数加减时**按补码运算、含符号位**，并对齐位数；
  3. 能判断是否需要规格化，并**写清"左规减阶 / 右规加阶"**；
  4. 舍入规则说明清楚（本题说明无需舍入）；
  5. 溢出判断**看阶码**，并给出可表示范围与理由；
  6. 最后**代回十进制验算**，能显著提高正确率。
- **常见坑**：
  - 对阶方向写反（让大阶向小阶看齐、尾数左移），直接把高有效位丢掉，结果全错。
  - 尾数加减时**漏掉符号位**，或者把 `-0.01010` 当成 `0.01010` 直接相减。
  - 规格化时把"左规/右规"和"阶码加/减"配错（记住：**左规减阶、右规加阶**）。
  - 把"尾数产生进位"误判为浮点溢出（尾数进位只需右规一次即可修正，**只有阶码溢出才是真溢出**）。
  - 忘记本题是**自编格式**（阶码 4 位、偏置 8），把 `IEEE 754` 单精度的 127 套进来。
  - 舍入时把对阶阶段移出的低位**提前丢弃**，导致"就近舍入到偶数"无法判断。

## 六、简便方法与易错口诀（速算 · 防错）

> 本节把本章能"省时间"和"防掉坑"的招集中在一处：二轮复习与考前只看这一节。每条都写清**适用条件**。

### 6.1 速算招式

| 场景 | 常规做法（慢/繁） | 简便做法（快/稳） | 为什么成立 / 适用条件 |
| --- | --- | --- | --- |
| 求 `-x` 的补码 | 先判符号，再"取反加一"分两步算 | 把 `[x]补` **含符号位**整体按位取反、末位加 1，一步得到 `[-x]补` | 求补是自逆运算（`[x]补` 再求补就回到 `x`），模 `2^n` 下 `-x` 与 `2^n - x` 在钟面上同一位置。**例外**：`x` 是最小负数（8 位的 `-128`）时 `-x` 超出表示范围，取反加一后仍是 `1000 0000`，必须单独说明"溢出、结果仍是自身" |
| 求 `-x` 的补码（省掉一次加 1） | "取反加 1"要处理整条进位链，最易连错 | 从 `[x]补` **最右边第一个 1 起**：该 1 及其右边的所有位不变，左边（**含符号位**）逐位取反 | 与"取反加 1"严格等价（低位全是 0，加 1 只影响右起第一个 1）。例：`0000 1101 (+13)` → `1111 0011 (-13)`。同样不适用于最小负数 `1000 0000`（左边没有可反的位，结果仍是自身） |
| 由补码读真值（选择/填空） | 先用"取反加一"还原绝对值，再加负号 | 符号位是 1 时，把符号位当权值 `-(2^(n-1))`，其余各位照常按 `2^k` 相加 | 补码本身就是"最高位负权 + 其余位正权"的加权和。例：8 位 `1111 0011` = `-128 + 64 + 32 + 16 + 2 + 1 = -13`，比取反加一快且少一次进位风险 |
| 短数据送长寄存器（8 位 → 16 位） | 逐位抄写、手工补 0 补 1，容易补错方向 | 补码直接**复制符号位**：正数左边补 `0`，负数左边补 `1`，数值部分原样照抄，真值不变 | 按位权展开时高位补符号位不改变真值。**适用条件**：补码（带符号整数）用**符号扩展**；**无符号数必须零扩展**（左边一律补 0），两者不能混用 |
| 移码 ↔ 补码、比大小 | 每次按 `X + 偏置值` 重算一遍 | 偏置为 `2^(n-1)` 时，`[X]移` = `[X]补` **只把符号位取反**；比较两个移码大小**直接当无符号数比** | 移码把"有符号序"映射成"无符号序"，硬件只要一个无符号比较器，这正是浮点阶码用移码的原因。**例外**：`IEEE 754` 阶码偏置是 `2^(n-1) - 1`（单精度 127），阶码字段 = `e + 127`，比"偏置 128 的移码"小 1，不能直接套"只翻符号位" |
| 乘/除 `2^n` | 列竖式做乘法、除法 | `x × 2^n` = 左移 `n` 位（低位补 0）；`x ÷ 2^n` = **算术右移** `n` 位（高位补符号位） | 二进制位权就是 `2` 的幂。**条件**：左移丢的是**高位**，左移后符号位一变就是溢出；右移丢的是低位，只损失精度；且负数算术右移等价于**向下取整**（`-5 >> 1 = -3`，不是 `-2`） |
| 加减法溢出判断 | 先算出结果，再和表示范围比大小 | ① 双符号位法看结果：`01` = 正溢、`10` = 负溢、`00`/`11` = 正常；② `最高位进位 ⊕ 次高位进位 = 1` 即溢出 | 两个判据等价：只有"最高位想进位却进不上 / 不该进位却进了"才溢出，也就是"两个同号数相加，结果变成异号"。**条件**：只用于补码加减；`CF` 判的是无符号溢出，与 `OF` 无关，别混着写 |
| 十进制 → `IEEE 754` 单精度编码 | 对着 32 位格式一位一位硬凑 | 两步法：① 先把真值写成 `1.xxxx × 2^e` 的规格化形式；② 阶码字段 = `e + 127`，尾数直接抄小数点后各位、右侧补 0 到 23 位 | 隐藏位省掉了小数点前的 `1`，所以尾数只存小数部分。**条件**：规格化数（阶码字段 `1 ~ 254`）；双精度改成 `e + 1023`、补到 52 位；**非规格化数（阶码全 0）不适用**，那时值 = `0.M × 2^-126` |
| 由 `IEEE 754` 反推真值 | 逐位列出权值再算幂，容易数错位 | 阶码字段减偏置得 `e`，尾数前面补回隐藏位得到 `1.M`，真值 = `± 1.M × 2^(e-127)` | 尾数各位权值是 `2^-1, 2^-2, 2^-3, ...`，识别出来直接相加即可。**条件**：单精度减 `127`、双精度减 `1023`；自编格式（如 4 位阶码偏置 8）必须按题目给的偏置算，别套 127 |
| `IEEE 754` 特殊值判读 | 逐条背含义，考场上一紧张就串 | 只盯两个位置："阶码字段是否全 0 / 全 1" 和 "尾数是否全 0"：全 0 + 尾全 0 = `±0`；全 0 + 尾非 0 = 非规格化数；全 1 + 尾全 0 = `±∞`；全 1 + 尾非 0 = `NaN` | 阶码全 0 / 全 1 是两端的边界编码，专门留给 0、非规格化数与无穷、`NaN`，所以规格化数的阶码字段只有 `1 ~ 254`。符号位只决定 `±`，`NaN` 不分正负 |
| 浮点加减手算 | 五步混着做，边对阶边丢低位 | 固定顺序：对阶（**小阶向大阶看齐、小阶尾数右移**）→ 尾数加减（按补码、含符号位）→ 规格化（**左规减阶、右规加阶**）→ 舍入 → 判溢出（**只看阶码**） | 对阶移出的低位要留到舍入步再处理，不能提前丢；结果尾数不是 `1x.xxx`（或 `0.0...`）形式才需要右规/左规。**条件**：阶码溢出才是真溢出；尾数相加进位只需右规一次即可修正 |
| 十进制小数 ↔ 二进制小数 | 拿计算器硬除、硬乘 | 十进制 → 二进制：小数部分反复"**乘 2 取整**"，取出的整数**按顺序**排在小数点后；二进制 → 十进制：按 `2^-1, 2^-2, 2^-3, ...` 各位权重直接相加 | 每乘一次 2，就把当前最高小数位"抬"到整数位。**条件**：十进制小数不一定能精确表示（如 `0.1` 会无限循环），必须按题目要求截断位数并舍入 |
| 补码一位乘法（`Booth`）判据 | 把 4 种情况逐一讨论，容易漏项 | 附加位 `y(n+1)` 先置 0，从低位到高位看 `yn y(n+1)` 两位：`00`/`11` 不加不减，`01` 加 `[x]补`，`10` 加 `[-x]补`，然后部分积**算术右移一位**，重复 `n` 次（以所用教材为准，最后一次不移位） | `01` 是"低位由 0 变 1"，等价于 `+x`；`10` 等价于 `-x`；用算术右移是因为部分积本身就是补码。**条件**：补码一位乘法，符号位参与运算，结果天然带符号 |

### 6.2 口诀与记忆钩子

- **"连同符号位取反加一求相反数，符号位不动只动数值位求补码"**：`[-x]补` 与"原码转补码"是两个不同操作；下笔前先问自己"我求的是 `x` 的补码，还是 `-x` 的补码"。
- **"右起第一个 1，1 和右边都不动，左边全反"**：求 `-x` 的补码的口诀版；顺手记住"`1000 0000` 是个孤独的坑"——最小负数取反加一之后还是它自己。
- **"符号位当负权"**：补码转真值直接把符号位当 `-(2^(n-1))` 相加，比取反加一更快，选择题首选。
- **"左移丢高位会溢出，右移丢低位只丢精度（负数右移向下取整）"**：一句话同时管住溢出判断和 `-5 >> 1 = -3` 这类陷阱。
- **"同号相加变号即溢出；`01` 正溢、`10` 负溢；最高位进位异或次高位进位为 1 则溢出"**：三条判据其实是同一件事，任挑一条验算即可。
- **"小数点前必有 1，所以 1 不用存；阶码加偏置，移码好比大小"**：前半句解释隐藏位与 24/53 位有效精度，后半句解释阶码为什么用移码、为什么能按无符号数比较。
- **浮点五步口诀："对阶（小向大）、尾数加减、规格化（左规减阶、右规加阶）、舍入、判阶码"**：收尾一定要补一句"只有阶码溢出才是真溢出"。
- **特殊值口诀："阶码全 0 尾全 0 是零，阶码全 0 尾非 0 是非规格；阶码全 1 尾全 0 是无穷，阶码全 1 尾非 0 是 NaN"**。

### 6.3 反例黑名单（这些"简便法"是错的）

- ❌ **求 `-x` 的补码时只对数值位取反加 1（符号位不动）**：正确做法是**连同符号位**一起取反加 1；只动数值位那是"**原码转补码**"，两个操作混用必错。
- ❌ **对最小负数套用"取反加一"求相反数**：8 位下 `[-128]补 = 1000 0000`，取反加一后还是 `1000 0000`（仍是 `-128`），因为 `+128` 超出 8 位补码范围。正确做法：**先判是否为最小负数**，是则直接说明"溢出，无法表示"。
- ❌ **把 `IEEE 754` 阶码当成"补码只翻符号位"**：那是偏置为 `2^(n-1)`（8 位阶码即 128）的移码；`IEEE 754` 偏置是 `127`，正确做法是 `阶码字段 = e + 127`（双精度 `e + 1023`），二者恰好差 1。
- ❌ **负数算术右移按"向零取整 / 直接把小数扔掉"理解**：补码算术右移等价于**向下取整**，`-5 >> 1 = -3`（不是 `-2`）。正确做法：高位补符号位后按位右移，必要时代回真值验算。
- ❌ **负数补码做符号扩展时左边补 0**：`-13` 的 8 位补码 `1111 0011` 扩成 16 位必须补 `1`（`1111 1111 1111 0011`），补 0 会变成 `+243`。正确做法：**补码复制符号位，只有无符号数才零扩展**。
- ❌ **尾数相加产生进位就判"浮点溢出"**：尾数进位只需**右规一次**（尾数右移一位、阶码加 1）即可修正。正确做法：**只看阶码是否溢出**，阶码没超范围就不是真溢出。
- ❌ **把"左移丢的是低位"记反**：左移 `n` 位丢的是**高位**，符号位一改变就是溢出；右移丢的才是低位，只损失精度。正确做法：左移前先判断移位后是否超出表示范围。
- ❌ **认为移码的 0 不唯一、存在 `-0`**：8 位时 `[0]移 = 1000 0000`，**移码 0 唯一且没有 `-0`**，只有原码和反码才有两种 0。正确做法：被问"哪种编码 0 唯一"直接答"**补码和移码**"。
