## 0. 这套笔记怎么用

1. **一份一章**，文件名以 `01-` ~ `07-` 开头，顺序就是大纲顺序，也就是王道书的章节顺序。
2. 每份的结构固定：**知识框架 → 概念详解 → 易混对比表 → 例题精练（3 道）→ 自测清单**。
3. 用法：先看「知识框架」把骨架记住 → 读「概念详解」补肉 → **合上书做例题** → 对答案看「采分点与常见坑」→ 最后用「自测清单」打勾。
4. VS Code 里按 `Ctrl+Shift+V` 预览即可。笔记里的公式一律写成**纯文本/行内代码**（例如 `带宽 = 数据线位数 × 总线频率`），**故意不用 LaTeX**，这样不装插件也能正常显示。想要更好看可以装 `Markdown Preview Enhanced`。
5. 笔记只写「大纲要求 + 王道书讲到的」内容；大纲已删除的内容会明确标注「大纲已不要求，了解即可」。

## 1. 计组在 408 里的位置

| 项目 | 内容 |
| --- | --- |
| 卷面 | 满分 150 分，180 分钟，闭卷笔试 |
| 内容结构 | 数据结构 45 + **计算机组成原理 45** + 操作系统 35 + 计算机网络 25 |
| 题型结构 | 单项选择题 40 小题 × 2 分 = 80 分；综合应用题共 70 分 |
| 计组题量 | 约 11 题：一般 8~10 道单选 + 1~2 道综合应用题 |

**计组的性格**：概念多但成体系，**计算题密度最高、最容易拿分也最容易算错**。历年大题集中在这几个方向：

- `Cache` 与主存的映射（直接/全相联/组相联）+ 命中率、平均访问时间
- 指令流水线（吞吐率、加速比、冒险引起的停顿）
- `CPU` 数据通路与微操作序列（给指令写微操作）
- 浮点数 `IEEE 754` 表示与加减运算
- 虚拟存储器地址转换（虚地址 → 实地址，`TLB` + `Cache` 综合访存）
- 磁盘存取时间、总线带宽（更偏选择/小计算）

## 3. 关于「总线这部分删了什么」

这是每年都有人问的点，结论如下（有明确出处）：

- **现行大纲对「总线」只要求三条**：
  1. 总线的基本概念
  2. 总线的组成及性能指标
  3. 总线事务和定时
- **被删掉的是**（自 2022 年那轮大纲改版起）：
  - **总线仲裁**：集中式仲裁（链式查询、计数器定时查询、独立请求）与分布式仲裁 —— 整块删除；
  - **总线标准**：`ISA`、`PCI`、`PCIe`、`USB` 等具体标准 —— 整块删除。
- **同时发生的结构调整**：原「第六章 总线」与「第七章 输入输出系统」**合并为一章**，原来的「外部设备」内容**移到操作系统的 I/O 管理**部分。
- **2025 → 2026 大纲计组无变化**（王道官方口径：26 大纲与 25 大纲比较没有变动）；所以如果你的书是最新版，「总线」章里剩下的大纲要求就只有上面三条。

**所以复习时的取舍**：

- 必须会：`总线带宽 = 数据线位数 × 总线频率`（注意「一个总线周期 = k 个时钟周期」的坑）、同步定时 / 异步定时（不互锁、半互锁、全互锁）/ 半同步定时的区别、数据线宽度 ↔ 带宽、地址线宽度 ↔ 寻址范围。
- 知道名词即可，**不要背**：链式查询/计数器定时查询/独立请求的仲裁流程、各总线标准的速率与参数。
